## 风格依据

沿用项目现有主界面按钮 3.2 的 SVG：石墨灰 `#343A3B`、象牙白 `#ECEBDA`、工程黄 `#DDC063`，面板线宽 1.5、图标在 64 单位画布下线宽 4.2。输入框沿用双层细描边、完整圆角轮廓和侧边刻线。

大面积面板直接复用 Frontier31 原有深色底纹和纸面纹理。信息、成功、错误仅添加小面积灰蓝、橄榄绿和砖红语义辅色；警告、焦点和等待使用原有工程黄。状态同时使用不同图标及文字，不只依靠颜色。

文字不烘焙进贴图。审批预览使用项目已有微软雅黑字体，正式静态文案仍归场景或预制体所有。

## Unity 使用

所有 PNG 为 2 倍导出，透明背景，`Sprite (2D and UI)` 单图模式，`Pixels Per Unit = 200`。随附 `.meta` 已设置切片边距；`manifest.json` 中 `border` 顺序为左、下、右、上，单位是导出像素。

面板、提示条、输入框、菜单条目和开关轨道使用 `Image.Type.Sliced`；图标、复选框整图、指向箭头及滑块手柄使用 `Simple` 并保持比例。图标建议显示为 20–32 逻辑像素；控件目标点击区域可以大于装饰图。

- 输入框与下拉框：共用 `input-*`；箭头独立叠放，状态文字由界面组件显示。
- 开关：`switch-track-*` 与 `switch-thumb-*` 组合，手柄在两端移动，轨道图片不含手柄。
- 等待：`spinner-*` 可持续旋转，建议约 1.1 秒一圈；不使用等待状态冒充确定进度。
- 进度：仅在业务有真实完成比例时使用；复用滑块轨道和填充，设置相应填充宽度。
- 提示条：图标独立叠放，可按语义色设置 `Image.color`。左侧色条位于固定切片区域内。
- 输入控件最小建议逻辑高度 40；输入框原稿 48，提示条 88。项目实际尺寸可由编辑器调整。

本包未新增运行时控制器，也未调用界面生成器。网页内的模拟状态不连接真实游戏或房间服务，不构成 Unity 运行验证。

```powershell
python ArtSource/UI/FrontierSupplementV1/build_assets.py
```

需要 Pillow 与 PyMuPDF；当前本机已有。导出仅写本包自身文件和对应的新图片目录，不重建或保存场景。审批后应保留实际选定图片；不要把重新导出当作修改现有预制体的授权。
