日期：2026-10-09。状态：V2.1 全部完成，已通过用户复核，不替换既有场景、预制体及 V1。

## 项目背景

本项目模拟《游城拓荒：铸基者》基础版。官网描述企业家在哥伦比亚拓荒运动中探索源石矿区、占领资源并建设城市。这次制作以这一背景为依据，不采用其他游戏的科技 HUD 作为模板。

- [《游城拓荒》官网](https://ak.hypergryph.com/boardgame_nomadcity)
- [PRTS 制品与资料索引](https://prts.wiki/w/游城拓荒：铸基者)

## V1 到 V2 的差异

原卡图在本轮制作中从 `Presentation/Resources/CardImages` 迁移到了 `StreamingAssets/Content/core/artwork`。上述两条已更新为当前路径；审批页使用 `references` 中的独立副本，避免后续素材迁移造成参考失效。底板提示词仍保留生成时的原始输入记录。本轮不参与或还原这批迁移。

- V1 主要匹配按钮配色与圆角；V2 把移动城市装甲、工程纸档案与调度状态融入构件本身。
- 通用圆角改为克制的切角，滑块与开关采用拨片轮廓；图标保持易识别的标准语义。
- 通知和表单采用浅纸底、深色字，不再全部使用深色矩形。
- 大底板新生成；控件几何用可编辑 SVG，复用项目既有纸纹，不把文字烘焙进 PNG。
- 黄色用于交互焦点、确认和警告；成功、信息、错误仍有各自图标和文字，不能只靠颜色区分。

## 所有权与交付边界

新 PNG 与 `.meta` 放在 `Assets/YC/Presentation/CommonUi/Sprites/FrontierSupplementV2`。源码、参考记录、审批 HTML 和截图放在本目录。已有 Unity 界面不接入、不重建、不保存覆盖。V1 保留作为历史稿。

组合预览中的表单、消息、房间编号与按钮为静态样例或浏览器本地演示，不连接 Steam，不宣称真实对局实现了这些新控件。本包已通过用户复核；正式采用仍需明确具体接入目标。
