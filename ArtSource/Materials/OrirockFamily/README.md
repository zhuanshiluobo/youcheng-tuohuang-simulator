## 造型与材质依据

- 固源岩组：不规则后部高岩、左中倾斜薄断片、中间横向搭接和右侧破断岩；灰褐连续断面取代旧随机斑块。内部基岩只在裂隙露出，全部分件闭合。
- 提纯源岩：三个同向正六棱柱形成高低错落、向下嵌合的连续岩体，保留浅崩口和统一黄褐石材；以上方最新修订记录为准。

图标圆环不属于模型。背景直接沿用现有稀有度映射，不重新取色。

收藏室的强聚光灯会使普通 Standard 非金属材质顶面过曝，因此这四种材料独立使用 `YC/Collection/OrirockMatte`：限制直射响应、提供中性哑光漫反射，保留岩质贴图与法线，不添加自发光、不染背景色、不改公共灯光。Blender 源仍保留可编辑的 Principled 材质。
