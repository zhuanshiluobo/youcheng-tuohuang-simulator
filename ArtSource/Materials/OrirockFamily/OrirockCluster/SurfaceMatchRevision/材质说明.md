# 固源岩组 04：石质材质接入说明

本模块参考本地 `ArtSource/Materials/OrirockFamily/reference/OrirockCluster_PRTS.png` 的灰青矿芯、乳白切面、赭色风化皮与橄榄灰顶面。配色是材质起点，图标的光照明暗不直接当作基础色，也不把圆环、背景或整张参考图投射到模型。

## 调用与面分配

唯一公开入口为 `build_face_material(name, rgb, weather_rgb=None, weather_amount=0.12, scale=1.0)`，返回新建的 `bpy.types.Material`。所有 RGB 参数为 0–255 sRGB，模块按标准分段曲线转换为线性值；调用者不要预先转换。默认风化色为 `(147, 128, 82)`。

主代理在 Blender 中导入本模块后，按已有真实几何面的材质槽分配即可；不为分色另建面片、壳层或独立几何。模块仅创建材质与节点，不操作对象、UV、几何、场景、灯光、地板、保存或渲染。同名调用会由 Blender 创建带编号后缀的新材质，接入时保存并复用返回值即可。

建议先采用下列参数。`scale=1` 的频率适合边长约 1 的物体局部坐标；下表不是视觉验收结论。

| 真实面用途 | 材质名建议 | rgb | weather_rgb | weather_amount | scale |
| --- | --- | --- | --- | --- | --- |
| 灰青矿芯与较暗侧面 | `04_灰青矿芯` | `(72, 85, 86)` | `(147, 128, 82)` | `0.09` | `1.00` |
| 乳白切面 | `04_乳白切面` | `(224, 220, 201)` | `(155, 135, 89)` | `0.16` | `1.00` |
| 赭色风化皮面 | `04_赭色风化皮` | `(139, 119, 78)` | `(112, 96, 62)` | `0.22` | `1.00` |
| 橄榄灰顶面 | `04_橄榄灰顶面` | `(104, 111, 87)` | `(143, 127, 84)` | `0.10` | `1.00` |

```python
core = build_face_material("04_灰青矿芯", (72, 85, 86),
                           weather_rgb=(147, 128, 82), weather_amount=0.09)
cut = build_face_material("04_乳白切面", (224, 220, 201),
                          weather_rgb=(155, 135, 89), weather_amount=0.16)
```

## StoneFace 与烘焙 UVMap 的双 UV 约定

源材质使用名为 `StoneFace` 的普通 UV 层。每个原始立方体面分别映射完整的 `(0,0)`、`(1,0)`、`(1,1)`、`(0,1)`；同面三角化后保持共享坐标，不把三角线当成风化边界。各面的 UV 可以重叠，不是整图投影，也不是把全部面挤进一个图集。

另一个名为 `UVMap` 的 UV 层留给最终实体的 `smart_project` 打包及烘焙，岛之间不重叠。主代理将其设为烘焙使用的活动 UV 层，并按既有流程设置目标 Image Texture。材质的 `ShaderNodeUVMap.uv_map` 始终显式指定为 `StoneFace`，不使用 TexCoord 默认 UV；切换活动 UV 或重新打包 `UVMap` 不会移动源材质的风化位置。主代理在合并与最终实体准备时保留 `StoneFace`，只对 `UVMap` 执行烘焙图集打包。本模块不创建或修改这两个 UV 层。

白面 `V=0` 必须对应其物理下边，`V=1` 对应上边。下部斑驳在 `V<0.42` 渐隐，其他面不用这个下部分支。倒角带如需显露风化，应延续相邻原始面的 UV；若把每个倒角小面也重置为完整 0..1，会产生重复边框。

风化用 `min(U, 1-U, V, 1-V)` 的真实面边缘距离，叠加二维噪声改变带宽，形成不均匀侵入。`weather_amount` 表示相对于面宽的带宽尺度，不是整体染色百分比：`0` 关闭 UV 风化；暗芯先用 `0.06–0.12`，白面先用 `0.12–0.18`，皮面先用 `0.18–0.25`。数值在模块内限制到 `0–0.5`，建议沿用上述较窄范围保留面内底色。边缘最大混色为白面 `0.72`、其他面 `0.62`，仍保留底色与颗粒。白面下部另用 Object 粗斑打散局部风化，强度为 `weather_amount × 1.15`。

UV 掩膜仅进入基础色，不连接粗糙度、凹凸或位移；几何轮廓、平面和顶点位置不会被风化边缘改变。

## 连续的石质纹理

细粒、中粒、粗斑与少量褐裂纹使用 Object 坐标，在同一物体的正面、侧面、背面连续。默认频率分别为 `175 × scale`、`43 × scale`、`4.2 × scale`；UV 风化带扰动为 `9 × scale`，裂纹为 `11 × scale`。`scale` 越大颗粒越密，带宽不随它改变。同一实体的各面材质使用相同 `scale`，以保持跨面纹理坐标和微表面一致。若真实局部边长是 `L`，可从 `scale≈1/L` 开始；过密导致颗粒不可读时将该实体各面一起降至起点的 `0.75–0.9` 倍，过粗时一起升至 `1.15–1.35` 倍。

暗灰青面在局部粗斑内混入 `(105, 123, 130)` 灰蓝色，最大混色 `0.38`，其余区域保留矿芯底色。浅面将粗斑混色降至 `0.07`，主要依靠细密颗粒。赭色、橄榄灰面保留原色相，仅局部提亮。浅面判定使用输入 sRGB 的加权亮度 `≥0.72`；灰青面判定为 `B≥0.90R` 且 `G≥0.94R`，不依赖材质名。

褐裂纹是轻度曲折的 Voronoi 边界，经过中粒和粗斑双重遮罩打断，不铺满规则龟裂网络；颜色为 `(103, 79, 52)`，最大混色白面 `0.48`、其他面 `0.38`。细颗粒在最后叠到颜色上，所以风化皮也保留粒感。色带中的灰值是线性明暗倍率，不是另一个待转换的 RGB 配色。

金属度为 `0`，粗糙度为 `0.85 + 0.13 × 细粒噪声`，范围 `0.85–0.98`；IOR `1.46`，Specular IOR Level `0.28`。Bump Strength `0.12`，Distance `0.0015 / scale`，仅来自 Object 纹理，位移输出保持未连接。若微表面显得过硬，可先将 Bump Strength 降为 `0.08`，保留颜色颗粒。

多个独立立方体默认使用各自 Object 坐标，相同局部形状可能出现相同纹理。主代理如需跨对象共用纹理空间，可以将各材质中 `type == 'TEX_COORD'` 的节点 `object` 指向同一个已有坐标参考对象；本模块不创建该对象。指定共享坐标时，`scale` 按该参考空间的实际尺寸调整。

## 接入与验证边界

节点通过 `type` 查询默认节点，创建时使用 API 类型标识；具名接口使用 socket `identifier`，其余接口按类型固定的序号连接，不依赖本地化节点名称。采用 Blender 5.2 中的标准 Noise、UV Map、Math、Mix RGB、Voronoi、Bump 和 Principled 节点，无额外工具或插件要求。Mix RGB 与 Voronoi 枚举已对照官方 [Mix RGB API](https://docs.blender.org/api/5.2/bpy.types.ShaderNodeMixRGB.html) 和 [Voronoi API](https://docs.blender.org/api/5.2/bpy.types.ShaderNodeTexVoronoi.html)。

本次只提供源码和说明，不调用 Blender 或 Unity，不制作或覆盖几何、地板、场景与其他资产，也不安装工具。已完成 Python 源码语法检查和函数签名核对，颜色转换采样 `(0,128,255)` 得到线性 RGBA `(0,0.2158605001,1,1)`。实际节点构建、UV 方向、背面连续性、各观察角度的颗粒尺度与最终画面尚待主代理在真实 Blender 5.2 场景中确认；源码语法或参数正确不代表视觉已通过。
