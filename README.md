# 游城拓荒模拟器

《游城拓荒：铸基者》2D Unity 模拟器项目。当前目标是先把基础版规则转化为可运行、可验证、可扩展的数字规则系统，再逐步补齐桌面 UI、卡牌效果、回放、AI 与扩展规则。

## 当前状态

- Unity 工程根目录：`F:\游城拓荒模拟器`
- 设计资料目录：`F:\游城拓荒模拟器\游城拓荒`
- Unity 版本：`2022.3.62f2c1`
- 当前 Unity 内容：默认 `SampleScene`，核心玩法代码尚未落地
- 首个目标：完成 3 到 4 人基础版热座 MVP 规则闭环

## 项目资料

- `游城拓荒/规则书/`：规则说明书 PDF
- `游城拓荒/总体架构/`：Unity 模拟器分层架构
- `游城拓荒/技术路线/`：技术选型、数据建模、里程碑与测试策略
- `游城拓荒/yc_plan_docs/`：MVP、架构、数据、测试和扩展计划
- `游城拓荒/模块工作/`：多 Agent 开发分工与顺序
- `游城拓荒/素材/`：地图和规则图标素材

## 架构原则

- `Domain` 只表达规则，不引用 `UnityEngine`。
- 玩家操作统一通过命令系统进入校验与结算流水线。
- `GameState` 必须可序列化，支持存档、回放和自动测试。
- 地图、卡牌、效果、计分规则优先数据化。
- UI 只读状态并提交命令，不直接修改规则状态。
