## 目标与范围

布局以 [07 纠正规范](07-原生布局命名与旧UI清理纠正规范.md)为准：本项所有常规行列从搭建起使用原生 `VerticalLayoutGroup`／`HorizontalLayoutGroup`／`LayoutElement`。主框架按上中下分配，内容区三列横向并排，列内纵向分配；建设页按页头、正文、页脚分配，候选／城市预览／报价并排时由 HLG 分配。需要填充的区域和 Viewport 取得真实余量，超量内容仅在本区滚动。保持 1920×1080 正常基准的最终屏幕位置；明确删除的旧节点、取消的分区换页及已知越界修复单列差异。

禁止按 16:10 或其他比例隐藏整列、切成主界面分区分页、给整列加滚动或平移整张 HUD。原三个行动业务页签保留。原生布局有效、素材与页面状态完整后，才开始多比例验证；挂有自定义 Layout、矩形暂时没有越界或截图已有若干张，都不能作为布局完成依据。

把正式建设入口迁到新版候选、城市目标、付款路线和报价窗口。主要目标为 `BuildInfoPanel` 及相关 Prefab／View、`BuildFacilitySelectionController`、实际建设 renderer 与正式绑定。按当前业务复用建设命令／请求，不重写费用和入场效果规则。

## 工作步骤

先接收基础修正的实际成果，核对根布局、右栏 VLG、无分区换页、生产语义命名及旧 UI 清理；未完成的部分按补充闭环，不能跳过后在 UI-012 再补。之后完成建设页及原业务未完项。建设视觉按[视觉搭建优先规范](03-视觉搭建优先与分阶段验收.md)先在原生布局中放齐框体、候选区、城市预览、付款／报价区域和必要素材，核对层级、1920 基准与实际填充，再接正式建设链。适配实现前不批量跑多比例截图；业务尚未接入可以明确标记，视觉缺图不能作为完成画面验收。

1. 列出公共供应、主要行动、效果授予建设、储备／延伸枢纽等现有入口及实际差异。选择每条入口唯一的输入与提交链，清晰处理旧流程启用和退出，不让两套控制器同时监听。
2. 候选来自正式投影，保留“可查看”和“可提交”的区别。不可支付候选是否可见以现有规则提供的权限为准；不能为了贴近示例读取隐藏数据或伪造候选。
3. 新窗口组织候选、城市目标、付款路线及只读报价；旧左侧可交互效果迁入全局抽屉。移交后清除只服务旧入口的监听、节点和配置，避免重复控制器；不得用停用整套旧壳替代应完成的清理。
4. 少量候选在其内容区居中，超量列表在自己的 Viewport 内滚动，卡牌网格按可用宽度换列；不得新增按屏幕比例触发的分段页面或强制下一页。若正式建设规则原本已有候选／目标／支付步骤，按真实状态保留，不能把尺寸变化当作步骤转换。城市预览保持比例，复用已验证的统一格位转换；UI-004 未执行时核对当前城市显示容器并补足本项映射证据，不等待整套世界地图回归。页脚操作区和窗口底边始终受内容区约束。
5. 设施、位置、支付方式或效果变化后更新当前报价。显示原价／当前费用、等待、不可支付及需要子选择等状态；规则没返回价格时禁止当作免费。
6. 确认前校验选择与请求仍匹配；必要目标未完成、报价失效、pending 或规则禁止时不可提交。支付、建设、奖励与后续效果全部走正式路径。
7. 正确处理选中、拖拽、聚焦、预览和确认之间的转换。拖拽层低于两栏，地图点击归属明确；改变窗口大小或请求被替换时安全恢复或退出。
8. 取消／返回／撤销各自遵循当前业务能力，不能把本地撤销预选等同于已提交建设回滚。
9. 页面接入统一互斥管理。效果唤起的建设页支持顶栏收起／展开，保留当前请求下仍有效的设施、位置和付款草稿；收起时停止建设选点和拖放提交，资料浏览不触发建设。展开关闭资料页，复核候选与报价再恢复；子选择替换当前页或切换内部步骤。
10. 费用、资源 icon 前数量、效果与选择次数使用 NarrowBold；纯 UI 页码等使用 wide。其余文字按方正、汉仪（关闭 Bold）及 msyh 特殊词角色绑定。
11. 对本项仍新增或改动的生产文件、对象、类型和长期测试使用功能名称，不创建 `Ui008` 等任务编号目录。既有编号名称由基础修正映射迁移，保持 `.meta`／GUID 和对象 fileID；更新字符串路径、场景覆盖、绑定、动画和工具，不重建 Prefab 取得新身份。

## 验收

- 真实盖牌阶段通过新版角色牌单选／确认完成正式盖牌；旧拖动放置不再提交，pending、拒绝及阶段变化正确处理。
- 根 VLG／内容 HLG／右栏 VLG 的实际尺寸驱动明确，整个右栏和三个业务页签随可用高度填充；背景／框体／Viewport 的伸展贯通。1920×1080 正常位置保留，16:10、超宽、低高度和恢复基准时三主列同屏，没有分区换页或整列滚动。
- 旧资源计数器、旧翻转／查看提示／上下文按钮、旧固定弃牌控件和旧内嵌预览壳有逐项实际删除结果；必要资源／手牌／建设刷新、第二效果继续／结束和弃牌只读查看由新版正式入口完成，无失效引用或重复监听。仅改名、隐藏、保留旧壳或因旧 builder 引用而保留废弃链均不通过。
- 生产路径、对象和长期工具／测试按职责命名，旧新映射证明 GUID／fileID 与场景覆盖正确；历史记录允许保留任务编号。
- 公共供应、少量候选、大量候选和当前实际存在的储备建设路径分别有验证证据。
- 设施／位置／付款切换后报价匹配；报价迟到、支付能力变化、提交拒绝不产生错误建设。
- 效果授予建设与主要行动的次数消耗、费用语义仍由既有规则正确处理。
- 顶底栏和结算抽屉可访问，选择／详情／拖拽／窗口调整后不丢失有效上下文，也不重复提交。
- 建设页、资料页与独立抽屉不会同时显示；收起浏览再展开后恢复当前有效建设步骤，隐藏期间不产生意外选点、付款或提交。
