## 3. 实际结构与输入边界

主表由 HLG/VLG 与玩家 Grid 管理；列表至少填满视口，超长内容可滚动。总览使用原生网格纵向填列，卡面内部状态槽随卡图缩放；摘要与城市是同一页的并列区域。每个轴保持一个尺寸所有者，不用按分辨率硬编码逐项定位。

`GameplayInteractionHud.prefab` 的 BuildInfoPanel 是本地子树，必须和独立 BuildInfoPanel 源模板一起核对。完整卡模板属于窗口自身 Templates，optionTemplate 是本地引用。场景覆盖以实际运行场景为准，测试和捕获不得保存、生成或重建界面。

候选集合和数量按真实内容与权限刷新，不复制预览卡组。主表点击进入宣告总览；只读工作流仍可被内部流程使用，但不恢复主表名字点击入口。查看、宣告、特殊行动各自保持正式职责，收起恢复不得把未提交草稿变成已提交命令。
