## 使用方式

把对应提示词文件交给执行者，并要求同时读取共同约束与实施计划。例如：

> 执行 `prompt/UI换新/UI-008-设施建设与报价联动.md` 和 `UI-008-补充-盖牌选择右栏适配与旧UI清理.md`。承接 UI-007 局内交付，先修整个右栏的纵向填充并接入正式盖牌选择 UI，迁移必要功能后清理旧资源计数器、翻转和弃牌区，同时完成原建设与报价迁移。保持正常 1920×1080 基准，适配完成后再验证多比例。

执行 UI-008 时将主提示词与新增修复补充一并交给执行者，见[本次安排](执行记录/2026-09-26_UI-008新增修复安排.md)。此前的[布局补充记录](执行记录/2026-09-26_UI-007布局重构补充.md)、[3.4／3.5 素材整理记录](执行记录/2026-09-25_UI-005完成与补丁3.4-3.5整理.md)及[按钮 3.2 整理记录](执行记录/2026-09-25_UI-003完成与按钮3.2整理.md)保留。

执行记录新增到本分类的 `执行记录/`，采用 `YYYY-MM-DD_UI-编号_主题.md`；文件已存在时追加序号，避免覆盖前轮记录。每项记录注明修改的源 Prefab／场景覆盖、接入入口、验证范围、截图位置、已知问题和任务状态。

编写这些提示词不等于已执行资产覆盖。后续执行一项实施提示词时，仅处理其中指明的界面目标；普通检查、运行或测试不得顺带重建界面。已有文档及源素材保持保留。
