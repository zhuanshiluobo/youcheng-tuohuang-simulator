### A. 资产核对与完整视觉

1. 复核两场景的实际共享 HUD／覆盖和 Registry。先列本项会改的具体源 Prefab、条目模板和配置；区分共享源与场景覆盖。保留并行修改的相机、姿态和取景算法，沿用中央地图区域接口。运行、测试、截图入口不得调用 Rebuild；不执行原包安装器去覆盖旧素材目录。
2. 建立资产映射：3.5 四项资源、3.4 各部件／状态／标记、源路径、Unity 路径／GUID、实际引用节点、选择的 PNG 倍率及导入设置。仅导入采用的一套，SVG、演示网页、原 QA、预览整图留在来源目录。
3. **先换 3.5 的 outer-frame、bottom-frame、chain-slot-frame，以及 bottom-bar-clean。** 三个透明框使用九宫格且不填中心；底栏底图普通铺满。明确 1x／2x 源切片、目标角区、PPU／像素倍率和导入后实际分辨率；不能只换三张框却留下旧白角底图。
4. 旧框对应节点替换引用或停用后，再启用新框；整图与八片二选一。保持主外框低于模块边框、底栏内容高于其背景与框，明确共享边归属。保留 3.2 按钮和现有模块布局，不能重新生成整张 HUD。
5. **再搭 3.4 共用行和三个宿主的完整视觉。** 行包含独立背景、边框、0～2 标记、标题／说明、可选右侧状态和焦点层；模式为 choice_execute／persistent_detail／quick_action。场景静态结构与文案存资产；运行时动态条目由配置好的模板实例化。
6. 在实际快速行动组和其他玩家摘要中搭对应列表／开关，补齐真实空态。对手明细下插并推开后续摘要，城市下缘稳定、原图等比，列表溢出内部滚动且滚动条独立占位。执行选项共用模板和结算宿主也需完整配置，不以未来业务未接通为由漏图。
7. 完成 1920×1080 基准视觉逐项对照。普通／强调文字分别使用方正／汉仪且无额外 Bold，特殊词用 msyh，效果次数／标记数字用 NarrowBold，纯 UI 数字用 wide。

### B. 层级与适配

8. 核对每个容器的背景／框／内容顺序和 Raycast；装饰不抢输入，两栏继续最高层。不能为修主框把它提到所有模块之上，不能让独立行组件重新赋已完成按钮的 Sprite。
9. 复用集中布局配置，检查 4:3 分区、超宽、低高度。明细最多展开一名真实玩家，实际展开量按剩余高度限制；城市保持可读，不拉伸变形。原有交互城市的显示矩形变化时核对对应格位，世界地图完整点击／导航仍待俯视改造后补验。
10. 隐藏左右插槽时回收间距，长说明允许增高或完整提示；触摸热区不覆盖邻行，滚动条不盖右按钮。正文详情和右侧操作的命中范围分开，UI 点击不触发地图操作。

### C. 规则数据与结算接入

11. 逐一审计三种宿主的数据来源和正式事件，定义稳定条目 ID、可见内容、模式、左右区域、显式 enabled、请求／版本、pending 与正文查看入口。数据缺失时显示空态／禁用并记录缺口，禁止复制预览示例作为真实规则数据。
12. 仅 status=use 且规则明确 enabled=true 时允许执行。unused／used 为只读，none 回收区域；禁用 use 不显示成 used。鼠标、键盘、已启用手柄与触摸遵守同一守卫。点击后等待正式状态回传，不自行消费次数或改成已使用。
13. 审计现有 `EffectDialogOptionRowView` 的整行按钮及各 renderer。保持“选择草稿后确认”和“立即执行允许的选项”的区别，不能因为新图标写着 use 就跳过既有确认。正文查看不执行，右侧操作不再触发一次整行回调；复用条目时清理全部旧状态与监听。
14. 玩家标记显式映射绿1／黄2／蓝4／红8，仅接受 mask 1～15；单色 count=0 保留，多色数量由每槽提示完整描述。对手条目只用玩家可见投影，通常只读，不从标题或旧暗牌 ID 推断能力。
15. 快速行动复用 UI-005 原“使用角色牌”等正式入口。新行接通且验证后再停用对应旧按钮，保留其他页签和卡面操作；不新增第二套命令。玩家明细的局部展开与顶栏 effect 收起恢复各自保持职责，正文若开详情须走唯一页面管理。
16. 完成原 UI-006 的摘要、必要／可选效果、报价、上下文、防重入和 effect 恢复。沿用 3.2 撤销／结束按钮；无撤销能力、无独立特殊行动能力的项继续明确禁用。原 effect 页隐藏时保留草稿、释放显示和提交输入，同一请求刷新不强制弹回。

### D. 实际验证与交接

17. 先做引用及新增交互的必要检查。状态验证覆盖左右插槽组合、零数量、三模式、只读／可用／禁用、详情与执行分离、复用换 ID、pending、过期请求。不得把坐标、颜色和字号锁成不可编辑测试常量。

19. 新增 UI-006 执行记录，保留四项框体和三种宿主的实际节点、配置、Unity 资源映射、事件／数据来源、验证及缺口。给 UI-007／011 提供同一行组件的接口和接入边界，卡牌网格与资源编辑器继续保留各自语义。
