# UI-002：新版素材导入与共用组件

请执行本任务。先读 [共同约束](00-共同执行约束.md)、[实施计划](01-UI更新实施计划.md) 和 UI-001 执行记录。前置：UI-001 已完成素材映射与资产归属核对。

## 目标与范围

导入选定的运行时素材及用户指定的五种字体，建立供主界面及窗口复用的框体、按钮、卡槽、状态层、滚动控件和字体语义配置。修改范围是 UI-001 确认的相关 Sprite、字体及必要的字体维护适配、主题／布局配置和共用组件 Prefab；已有场景结构的迁移放到后续任务。

## 阅读入口

- 整理版 `文档/03_Unity接入说明.md`、`清单/新版组件索引.json`、`清单/资产索引.json`。
- 新版组件、沿用控件及对应专用窗口的原包参数。
- 当前字体、TMP 配置、`CardVisualCatalog`、`CardInteractionLayoutProfile`、`EffectDialogLayoutProfile` 和共用按钮／条目资产。
- [单页面与字体补充规范](02-单页面与字体补充规范.md)、[字体来源清单](字体来源清单-2026-09-24.json)、当前 `FontUtility`／`FontRefreshDriver` 及实际 `Text`／TMP 使用方式。

## 工作步骤

1. 按 UI-001 映射决定导入目标目录和复用关系；先列出将新增或修改的资产路径。保留旧引用和 `.meta`，不把 ZIP、预览、QA 文件、生成脚本整包放进运行时目录。
2. 新版 3.1 组件优先使用整理后的 PNG。设置 Sprite、Alpha、过滤、最大纹理尺寸和压缩，以中文、细线及透明边缘的实际显示为准；不同用途不强套一组参数。
3. 使用索引中的 `unityBorderLeftBottomRightTop` 设置九宫格。源数组为左上右下，Unity 为左下右上。区分切片边界与内容留白。
4. 搭建底图、边框、文字、状态层和命中区域分离的共用组件；新按钮不再套旧按钮 `visibleRect`。沿用的选中叠层及滚动条使用自己的内容映射。
5. 覆盖正常、悬停／聚焦、按下、选中、禁用及 pending 的必要状态。没有专用新图时采用共用状态表现并记录，不伪称源包已提供。
6. 静态文案在资产中配置；多场景固定文案做配置。建立五种字体角色：方正普通文字、汉仪强调文字（关闭 Bold 与 `<b>`）、msyh 特殊词、Novecento NarrowBold 效果相关数字、Novecento wide Normal Regular 纯 UI 数字。资源 icon 前数字和选择次数用 NarrowBold，顶栏回合数用 wide；“策略”“计谋”明确使用 msyh。装饰 Image 关闭不必要的 `raycastTarget`。
7. 为共用组件提供可序列化的最小／首选尺寸和内容间距；九宫格可拉伸，卡面和图标等比。不要在运行时控制器中写一套组件生成器。
8. 使用明确标记为验证用途的场景或既有安全预览方式检查正常／紧凑／宽尺寸。该预览不替代后续正式接线；不要重建实际对局界面来得到样板。
9. 五种字体从清单中实际文件导入或生成所需字体资产，保留来源与字体成员记录。wide 文件虽然带 `.woff2.ttf` 名称，实际为 TrueType；`msyh.ttc` 使用 Microsoft YaHei Regular（当前索引 0）。导入结果需真实检查，不以改扩展名代替转换。
10. 实现可配置的文字／特殊词／数字／icon 混排，检查基线、换行与缺字。适配现有字体维护逻辑，让重新聚焦、字体纹理恢复及动态条目实例化保留五种角色；不将角色重新合并为单一 CJK／Latin 字体。混排不改写用户静态文案。

## 交付与验收

- 新增或调整的共用资产可直接供后续 Prefab 引用，GUID 与来源映射有记录。
- 边角、透明区域、文字、状态层与命中区显示正确；卡面没有拉伸，禁用状态可辨认。
- 五种字体、汉仪不加粗、两类数字及 msyh 特殊字词在组件样例中实际显示正确，字体刷新后保持角色；混排、中文标点和缺字回退有证据。
- 记录至少一组实际显示证据及使用尺寸；无法运行则明确未完成视觉验收。
- 新增 `执行记录/YYYY-MM-DD_UI-002_共用组件.md`，附导入表、五类字体引用与成员映射、混排配置、沿用项和缺口。

不要求为纯 Sprite 替换新增测试；仅在新增状态行为或配置校验存在实际风险时补充有意义的验证。
