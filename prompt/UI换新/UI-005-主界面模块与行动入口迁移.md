## 目标与范围

为 UI-003 已搭好的玩家状态、城市、企业家、手牌、合作区、牌堆和行动页签连接真实游戏数据及行动流程。主要目标为共享 HUD、`ActionPanel`、`CharacterHandPanel`、资源／回合相关 View 及两场景绑定。本任务不再承担“首次搭建主模块边框与底图”；发现前置视觉缺项时先补齐再继续业务接线。

## 工作步骤

1. 复核逐区视觉清单、素材和基础修正后的实际资产：根 VLG 分顶／中／底，内容 HLG 分持续同屏的三列，各列 VLG 分内部区域。保持正常 1920×1080 屏幕位置；新动态条目从第一步进入最终布局，并在贴图／字体／层级完整后接行为。不照抄坐标到控制器，不因历史组件名含 Layout 就直接复用其手写排布。
2. 玩家数量、顺序、回合、分数、资源和标记从当前可见投影读取；支持长名字和多位数。数据刷新只更新内容和合法状态，尺寸变化、明细开闭及页面返回保留有效选择、业务页签和滚动状态，不生成侧栏收起或主分区导航。
3. 手牌、企业家、弃牌和盖放角色按实际集合显示。图包的可见槽数只是布局容量，超量内容提供滚动／展开；隐藏卡不能通过缩略图、详情或工具提示泄露。
4. 合作轨道与城市样式标记保留各玩家独立状态。多人同级组合色块使用素材映射，缺少规则状态时不要用演示等级填充。
5. 右侧按主要行动、快速行动、城市样式组织入口，结束行动统一到常驻底栏。按功能逐项迁移监听与快捷键，确认只有一个输入所有者；用户点名的旧计数器、翻面／查看提示变体、旧固定弃牌与旧盖牌拖放必须按基础修正清单彻底删除，不能以隐藏或改名作为最终清理。
6. 对每项行动跟踪启用条件、候选来源、取消、返回、确认和失败提示。现有主要行动预选与新 `InteractionRequestRouter` 之间明确输入所有权；不在本项顺带重写 Domain 主链。
7. 使用当前动作能力驱动禁用状态。非行动玩家、必选交互、pending、断线等状态仍可查看合法信息和使用两栏合法功能。
8. 各列 VLG 的固定标题／页签与伸展主体分别配置 LayoutElement，城市、合作正文、行动正文和 Viewport 得到实际剩余高度；标题／页签不被 ForceExpand 拉高。长列表在本区内部滚动，隐藏业务页签不占布局；主列、整块城市与行动模块不因比例变化关闭。核对每层背景／框／内容实际尺寸，不只验证父矩形。
9. 主界面详情与资料入口接入唯一页面管理。effect 页收起后可以查看其他资料，切换资料关闭前页，顶栏展开时关闭当前资料并恢复 effect；查看行为不能触发隐藏 effect 的地图选点或提交。顶栏按钮只控制 effect，没有独立的“自适应侧栏收放”入口。
10. 使用 UI-002 的字体角色配置；常规／强调文字分别为方正／汉仪，汉仪不勾选 Bold，特殊词使用 msyh。资源 icon 前数量等效果数字用 NarrowBold；顶栏回合数等纯 UI 数字用 wide，混排按语义分段。
11. 本项保留地图相机、姿态、投影和取景改造的职责边界，承接实际中央地图区域接口。UI 按钮／遮罩命中仍做必要检查；若迁移城市板或设施供应交互，核对被改动的城市映射。世界地图点击、导航边界和相关完整链交给俯视改造后的 UI-004；受影响业务未验证就如实记待验，不能把旧翻面／旧盖牌拖放恢复为备用入口。
12. 新生产目录、对象、类型、工具及常驻测试按功能命名。按旧路径／fileID／GUID 到新名称的映射更新 Prefab、场景覆盖、UnityEvent、查找路径和测试；不得用重新生成 HUD 的方式整理名称。局外场景及其合法共享源保持不变。

## 验收

- 两实际场景可以通过新版入口完成已有主要行动及快速行动代表流程；每次提交只产生一次正式意图。
- 当前业务页签、选择、手牌状态在玩家明细开闭、effect 收起／恢复、资料返回和尺寸变化后合理恢复；这些行为不隐藏另外两列。
- 正确显示自身／对手信息，未知或隐藏内容不泄露；空牌堆、超量手牌与资源增位可用。
- 顶底栏、地图及新模块不争用输入，用户点名的旧入口退出实际资产、监听、快捷键和生成路径，必要功能由新版入口完成。
- effect 收起后的资料浏览与展开恢复流程可用，同时最多一页，不绕过业务限制；实际文字与数字符合五类字体规范。
- 布局结构、素材和实际状态就绪后，再做基准 → 1920×1200 → 超宽 → 恢复基准及一个低高度的必要检查。无独立页覆盖时三列同时显示；玩家明细展开后的城市和右侧三业务页签正文都在分配区内填充，不被底栏遮挡；长列表末项可达。先修失败区域，不重复批量截图。正常基准位置及用户可编辑的静态文案／样式保留。

上述验收先完成不依赖世界地图改造的部分。需要最终地图选点的行动链在记录中明确标为待验，保留入口和上下文检查结果；不能把按钮可点击当作完整行动已通过，也不因整套地图矩阵尚待执行而阻挡独立 UI 工作。
