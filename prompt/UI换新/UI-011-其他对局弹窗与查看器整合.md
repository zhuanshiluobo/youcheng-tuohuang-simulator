# UI-011：其他对局弹窗与查看器整合

请执行本任务。先读 [共同约束](00-共同执行约束.md)、[实施计划](01-UI更新实施计划.md)、UI-001 完整界面清单及 UI-003／UI-006／UI-007 交付。

## 目标与范围

将尚未迁移的对局内事件、调度、特殊行动、角色／设施效果窗口、回合详情、设置、规则书、日志、图片查看器及已存在的结束／断线提示纳入新框架。仅处理游戏场景内的实际入口；启动、加载、房间等独立页面需另列后续任务。

## 阅读入口

- `GameplayDialogRegistry` 及实际引用的专用 Dialog。
- `EventChoiceDialog`、`DispatchDecisionDialog`、`SpecialActionChoiceDialog`、`CharacterCardEffectChoiceDialog`、`FacilityEffectChoiceDialog`。
- `GameSettingsMenu`、`RulebookViewer`、`ActionLogViewer`、`ZoomableImageViewer`、`RoundTracker` 对应资产与控制器。
- 实际对局结束／断线处理入口，以及 UI-001 发现但以上未列出的对局窗口。

## 工作步骤

每个页面都按[视觉搭建优先规范](03-视觉搭建优先与分阶段验收.md)先搭完整视觉，再核对层级／适配，随后迁移业务和页面管理，最后实际验收。采用新版共用外观的页面也要逐区核对，不能仅修改排序和 Controller 就认定视觉已完成。

1. 将当前完整清单与 UI-005～UI-010 交付交叉核对，列出本项具体资产。已有专用窗口继续保留正确业务职责，复用共用外观和输入框架，避免重复改写已迁移模块。
2. 没有新版专用美术的窗口复用 3.1 共用组件与既有内容，记录沿用项。静态文案仍由 Prefab 配置，不根据图包示例覆盖用户编辑内容。
3. 替换散落的独立排序和全屏内容遮罩，所有查看器、事件窗口、拖拽提示均受统一内容层级约束；检查相关 Camera 与 CanvasGroup。逐个停用窗口拖动移位组件和事件绑定，检查运行时启用及历史位置恢复路径；窗口位置由布局决定，查看器内部图像平移和内容滚动独立保留。
4. 设置可从顶栏在 effect 页显示时打开，但必须先按统一收起语义保存 effect，再在唯一页面位置显示设置。规则书、日志、图片查看器等彼此切换也须关闭前页。关闭资料页返回主界面，effect 继续收起；顶栏“展开”关闭当前资料页并恢复有效 effect 步骤。页面导航只保留返回状态，不叠开窗口，也不取消或强制结束必选步骤。
5. 规则书、日志、图片／卡牌详情适配长内容、放大、滚动和内容区边界。工具提示不遮住常驻操作，隐藏信息仍按当前玩家权限提供。
6. 专用事件／调度等需要连续交互的窗口继续走统一请求生命周期，处理 pending、返回、失效和重复提交；不能恢复已结束请求的旧内容。
7. 对局结束和断线状态下，两栏仍保持显示与合法功能可达；需要禁用的业务命令根据会话状态给出原因。不要用整屏输入锁顺手禁用设置、查看等合法功能。
8. 在标准、紧凑及低高度窗口下重排；使用内容滚动而非整窗裁切，返回或改变尺寸后保留合理位置。
9. 审计各独立 Controller 的打开／激活路径，让全部对局页面经过统一互斥管理，收起期间不会由每帧刷新强制弹回；终局和断线处理更新／清理失效的 effect 恢复目标。查看器内部平移保留，隐藏页不留下遮罩、焦点或事件监听造成输入冲突。
10. 所有页面和动态条目复用五类字体配置；特别核对日志／详情中的效果数字与特殊词、查看器和设置的纯 UI 数字，避免把整段内容统一替换成一个字体。汉仪不勾选 Bold。

## 验收

- 清单内每个实际对局窗口有明确迁移或沿用状态，没有遗漏的旧整屏遮罩或越层 Canvas。
- 能从实际游戏入口打开、操作并关闭，各专用功能保持正确；仅检查源 Prefab 不算接入完成。
- 设置／查看器／结束与断线提示出现时，两栏仍可达，焦点和地图命中正确。
- 所有对局窗口的标题、背景和边缘均不能拖动窗口，关闭重开后约束仍成立；内容滚动、缩放和图像平移正常。
- 长内容、窗口大小变化、资料间互斥切换、effect 收起／恢复及隐藏信息均经过相应检查；任何时刻最多一页。
- 设置／日志／规则书／查看器从实际入口切换后，字体与混排角色仍正确；展开 effect 会关闭当前资料页，原有效草稿可恢复。
