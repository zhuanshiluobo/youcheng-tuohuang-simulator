## 工作步骤

先完成补充提示词的布局阶段及 1920×1080 位置核对。以下窗口迁移从开始就使用最终布局容器，按[视觉搭建优先规范](03-视觉搭建优先与分阶段验收.md)完整搭建外框、底图、标题、卡槽／选项条、按钮、滚动区及文字图标，核对层级与适配后接请求逻辑。验收截图须等待当前状态必需素材和布局就绪；不在适配实现前批量跑多比例截图。

1. 复用正确的框体、按钮和卡槽，选中框按透明留白与实际卡面映射。窗口根在 PageHost 中受限布局，VLG 分页头、正文 Viewport、页脚；页头／操作区 flexibleHeight=0，正文 flexibleHeight>0。按钮栏用 HLG，选项和资源列表用 VLG；背景、边框、Mask 与装饰填满各自区域而不参与行列统计。按 07 规范明确 childControl／ForceExpand，不能由自定义壳布局再次写各部分坐标。
2. 卡牌 Content 优先用原生 GridLayoutGroup 和仅更新列数／cellSize 的局部辅助器，以实际 Viewport 宽度、卡牌可读尺寸和间距计算列数；必要时 Content 纵向增长并在正文内滚动。支持 0、1、少量、7、超过 7 和大量候选；列数变化不能隐藏主列或把整个窗口改成尺寸分页。原图在单元内部等比，最小尺寸总和不能超过页宽，页脚不随候选增多被推出屏幕。
3. 单选与多选只修改当前请求的草稿，明确已选数量、最少／最多数量、确认条件和取消权限。查看详情不等于选中；返回详情后保留草稿。
4. 普通选项使用稳定 ID，连续阶段切换时清理不属于新请求的旧选项。失效或不可选内容可以按规则显示原因，不能提交过期目标。
5. 重复出售使用每种资源的整数数量草稿，约束在当前库存范围。全零不能确认出售，结束出售按规则允许零成交退出；整批只提交一次。
6. 分开显示库存、预期收入及已成交结果；实际价格和收入由规则提供。库存变化／被拒绝时刷新并复核草稿，成功后按真实结果清理。
7. 请求仍由统一 router 分发，详情与子选择共享 UI-006 上下文，并通过唯一页面切换或当前页内部步骤展示，不同时显示父子页。收起保留当前有效草稿并释放输入，展开先关闭资料页再复核并恢复当前步骤；同一请求刷新不强制重开。区分 renderer 的业务清理和页面隐藏，保证 pending、防重入、返回和过期响应处理一致。
8. 静态标题、说明、按钮文案按窗口模式配置到资产。不要把图包演示角色步骤、浏览器事件或示例库存作为正式规则。
9. 使用 UI-002 的五类字体配置；选择次数、资源 icon 前数量、效果费用和收入数字使用 NarrowBold，纯 UI 页码使用 wide。“策略”“计谋”等特殊词用 msyh，普通／强调文字分别用方正／汉仪，汉仪不勾选 Bold。数字与中文按语义混排。
10. 窗口、遮罩及详情查看器都在 ContentRect 内，不盖住顶底栏。移除 `EffectDialogDragHandle` 的组件、必需引用和运行时重启路径，固定尺寸下标题、背景、边缘均不能拖动窗口。查看器内部图像平移与合法内容滚动保留；不能把旧盖牌拖放或旧翻面／查看提示当作卡牌内容交互恢复。
11. 普通选项行 HLG 分可伸展文字与必要状态；资源行 HLG 分资源身份、库存／收入和整数增减操作，纵向行高由真实文本测量提供。高频状态刷新只更新数据、禁用和草稿，不写固定标题、坐标或另一套高度缓存。需要测量的辅助器只提供布局输入，不重排页面。
12. 逐项登记旧新生产路径、GUID/fileID、字符串查找及 Registry；按功能命名窗口、类型、配置、长期测试和工具。已有任务目录应按基础修正映射定位新路径；不复制出第二套同名选择壳，不通过重生成资产解决引用迁移。

## 验收

- 所有实际局内 UI 有原生结构、每轴驱动者和尺寸输入清单；正常 1920×1080 相同状态位置保持，改变尺寸后恢复也成立。玩家明细展开后的城市、右栏三个业务页签正文均处于实际分配区；主三列不因比例隐藏／换页。非局内来源及已完成隔离保持不变。
- 实际单选、多选和选项业务入口可用；空状态、超量候选、滚动末项和数量边界正确。
- 出售数量增减、库存变动、零成交结束、整批成功／拒绝正确，预选不提前结算。
- 详情返回、切换请求和调整窗口大小后状态一致；隐藏候选／卡面遵守玩家权限。
- 主页面、独立抽屉、详情及子选择互斥切换，两栏仍可操作，UI 点击不穿透到地图；effect 收起后可查看资料，展开关闭资料并恢复有效草稿，全程最多一页。
- 拖动窗口标题、背景和边缘不移动窗口；关闭重开、切换模式／请求后仍不可拖窗，内部列表与卡牌操作正常。
- 从正常开局角色“7 选 2”与一个正式效果选择入口验证：候选可见 → 查看详情 → 返回且草稿保留 → 达到数量边界 → 只确认一次 → 正式响应更新。分别补单选、普通选项、资源出售真实已有路径；不存在的规则分支记缺口，不用诊断数据当成交证据。
- 布局结构及当前必需素材完成后，定向检查基准、1920×1200、一次宽度／低高度变化及回到基准；页头、正文、页脚都在 ContentRect 内，候选末项可达，无主分区导航辅助操作。发现未适配先修对应区域，不能继续批量截图。几何使用同一屏幕坐标空间，素材看图与业务操作分别记录。
