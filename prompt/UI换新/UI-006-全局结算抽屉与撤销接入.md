## 目标与范围

让底栏摘要、结算抽屉、必要步骤、可选效果、报价和撤销状态共享当前操作上下文。修改底栏／抽屉相关 Prefab、View 与表现适配；不依据素材演示重建规则层或自行添加未定义的回滚能力。

## 工作步骤

先在以下原生结构中按[视觉搭建优先规范](03-视觉搭建优先与分阶段验收.md)搭完整摘要槽、抽屉／页内结算区的底图、边框、标题、图标、文字及空态，保持正常 1920×1080 位置，核对层级与实际填充，再开展业务接线。素材或布局未完成时只做必要诊断，不进入正式多尺寸验收。

### 布局与尺寸必须明确

- 常驻摘要置于底栏 HLG 的伸缩段；撤销、结束行动使用固定／首选尺寸，摘要取得横向余量。底栏高度由根 VLG 分配，结算业务控制器不再改变整栏矩形。
- 独立抽屉置于 PageHost，外壳受 ContentRect 约束；使用 VLG 分页头、正文、页脚，正文 flexibleHeight>0，固定操作区 flexibleHeight=0。必要链与可选效果维持基准的并排／上下关系，分别用 HLG／VLG 和明确的 LayoutElement 比例分配，两个正文 Viewport 独立受限。
- 普通效果行由原生 HLG 分标记区、可伸展文字区、右侧状态／执行区；文字区可用 VLG 分标题与说明。列表 Content 用 VLG，确需增长时仅 Content 的纵轴由 ContentSizeFitter 驱动，Viewport 不随内容无限长高。背景与焦点框拉伸，不参与列表尺寸统计。
- 每个 RectTransform 每轴只有一个驱动者。按 07 规范设置 childControl／ForceExpand；页头页脚不强制伸展，不能保留自定义逐行坐标算法再挂一层不生效 Layout。生产代码、目录和条目对象用功能名，不能继续新增 Ui006 等任务命名。
- 根／三列继续沿用基础修正的 VLG／HLG／VLG；结算面板开关、长内容与尺寸变化都不能引入主分区分页或隐藏其他列。需要关闭资料时由唯一页面管理完成，不让宽高判断代替业务状态。

### 业务接线

1. 根据现有会话和玩家投影定义表现输入：请求标识／版本、当前步骤、必要步骤、可选效果、pending、报价状态和可用操作。语义字段可作适配模型，不假定代码已存在同名 API。
2. 底栏显示常驻摘要，必要结算链和可选效果作为当前页内部区域，或使用占用唯一页面位置的独立抽屉。独立抽屉不能与其他页面同时打开。两个列表独立滚动，标题和摘要固定；没有内容时显示配置好的空状态。
3. 可选效果显示来源、资格、费用影响和不可用原因。复杂目标选择使用当前页内步骤切换或替换当前页，返回后仍归属原上下文；父页与子选择不能同时显示，避免再建独立选择状态机。
4. 明确报价的等待、有效、不可支付、失效和需补充目标状态。未报价不能显示成零费用；客户端只展示正式报价并提交选择意图。
5. 撤销入口仅调用规则／会话明确支持的能力。没有可用能力时展示禁用与原因；有能力时处理成功、拒绝和上下文变化后整体刷新，不能直接回写本地游戏状态伪造撤销。
6. 统一提交防重入及旧响应保护。确认、撤销与结束行动共享同一上下文校验；pending 不应屏蔽整个顶底栏，其他合法功能仍可用。
7. 当前页的结算区／子步骤保持原有业务关系并受内容区约束；标题、正文、操作区按原生布局伸缩，长内容在两个列表各自滚动。不能因为宽高变化把摘要改成入口、隐藏主列或添加新的分段切页。顶栏收起／展开只针对当前 effect 页，抽屉内部内容状态不替代该按钮语义。
8. 给设施、企业、科室、城市样式和通用选择窗口提供复用接入点，记录需要它们移走的旧效果控制器；确保同一效果不会在两个区域都可提交。
9. 实现 effect 页隐藏与当前请求的独立绑定：收起保留有效草稿但释放显示、遮罩、焦点和结算输入；状态同步继续，同一请求刷新不重新显示。恢复先关闭当前资料页并校验版本，恢复该流程当前待处理步骤。请求完成／失效时清理旧恢复目标；收起和展开不发送业务命令，不把 renderer 的清理／取消当成隐藏。
10. 摘要、报价和选择次数中的效果数字使用 NarrowBold，中文按普通／强调角色分配，汉仪不额外 Bold，特殊词用 msyh；纯界面页码等数字使用 wide。

## 验收

- 展开／收起、空链、多步骤、长列表、不可用效果和复杂子选择均可操作，两个滚动区不串动。
- 取消／返回、报价过期、提交拒绝和旧请求回复不会污染新操作；重复点击不重复提交。
- 撤销能力缺失、禁用、可用、成功或拒绝分别按真实能力验证；没有实际支持的分支标明未接入。
- 当前页为结算抽屉或子选择时，两栏仍可访问，同时没有第二张可见页；地图不接收被遮区域点击，尺寸改变后状态一致。
- effect 收起 → 查看其他资料 → 展开时关闭资料并恢复有效步骤；同一请求刷新、pending 回包、下一步骤和流程失效均不恢复过期选择或产生重复提交。字体角色符合补充规范。
- 按正常入口打开当前结算页，验证空态、短链与长链时页头／页脚位置、两个 Viewport 和列表末项；正常 1920×1080 位置保持，正文填满获配空间，最小尺寸总和不把页面撑出 ContentRect。只有适配、资源和业务状态就绪后才定向检查 1920×1200、宽度／低高度变化与恢复基准，无主分区导航参与操作。
- 同一屏幕坐标空间核对页面、底栏与内容区矩形，实际点击两栏合法入口；本地 sizeDelta、挂载组件或组件测试通过都不能替代该证据。窗口不支持拖动，隐藏结算页没有残留遮罩或输入。
