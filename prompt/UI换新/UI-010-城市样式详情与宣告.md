## 2. 主界面城市样式页

### 2.1 入口与清理

- 删除 `City Style Table Header`，不再显示本局样式数量表头。
- 删除 `Action Region` 下 `Header Background`、`Header Title`、`Quick Header Title`、`City Header Title`。
- 复用 `Declare City Style Button`，透明命中矩形覆盖整个 `Action Region`，删除其可见文字、描边和换色组件。`Action Content` 为其子节点；列表保留 ScrollRect。
- `UiMainActionTabs` 仅城市样式页签启用该 Button 组件，其他页签禁用组件而不隐藏内容。`ActionPanelController` 只设置可用性，不再给该透明入口套有色背景。
- 移除样式名字点击详情入口：名字 Button/透明 Image、`nameButton` 字段、`CityStyleClicked` 事件、控制器订阅/回调及旧 `TurnActionPresenter.OpenCityStylePreview` 转发。主表名字只显示文字；窗口内仍可查看完整卡。底层只读工作流可供已有流程及恢复使用，不作为第二个主表入口。

### 2.2 行、状态、字体

| 项目 | 当前规格 |
| --- | --- |
| 信息结构 | 六条紧凑名称/状态行，禁止改为完整原卡网格；数据来自本局正式供应 |
| 每行背景 | 每条独立浅色背景，行间露出深色模块底；取消列表整块浅纸底，Viewport 的 Image 仅作透明命中 |
| 三个业务页签、六个样式名字、中文状态 | `HanYiCuHeiJian-1`，不叠加 Bold |
| 一级行动型 | 未使用、已使用，两槽；中文字号 14 |
| 一级奖励型 | 已宣告，单槽；中文字号 14，不虚构未使用状态 |
| 二级五槽 | `2 → 已使用 → 1 → 已使用 → 0`；两种已使用轨道保持独立，不合并领域状态 |
| 二级标签 | 不透明黑色，字号 14，高 22；删除余 1/余 2 等余量后缀；数字使用 `Novecento NarrowBold` |
| 一级玩家标记 | 正常 24×24，每槽四玩家横排 |
| 二级玩家标记 | 正常 24×24，与一级同大；每槽 2×2、间距 4，Player Counts 高 52；五槽大小一致 |
| 二级行高 | HLG/VLG 根据标签和标记自然撑高，当前基准行高 86；不得恢复固定 58 高或让标记越出 State Slots |

`CityStylePlayerMarkerGrid` 保留窄列尺寸适配；正常宽度使用上述大小，窄空间可等比缩小。数量表示宣告标记数，不表示剩余次数。

### 2.3 宽度、边距与纵向分配

- `Action Content` 四边各留 8 UI 单位，水平边界与上方 `Cooperation Paper` 对齐，下边距参考企业合作背景。Stretch、anchoredPosition `(8,-8)`、sizeDelta `(-16,-16)`。
- `City Style Status Table Content` Padding 四边为 0。`UiFlexibleCanvasContent` 使内容至少填满视口，超过视口时允许滚动。
- `UiDistributedVerticalLayoutGroup` 继承原生 VLG，保持各行所需高度，只将剩余高度均分到五处行间，不额外分配给顶部、底部，不拉伸标记。先按行高与 Padding 计算内容所需高度，再计算非负行间距；继承的 Inspector Spacing 不作为最小间距，不将计算结果累积回资产。
- 目标是基准 1920×1080 六行完整同屏且填满可用区域。统一验收时发现旧算法强制最小 spacing=4，内容高312超过视口308。用户指出后已修正算法：当前行高合计292，应自动得到 `(308-292)/5=3.2`；只有行本身高于视口时才撑高内容并滚动。详见[自动行间距修正](执行记录/2026-09-27_UI-010_自动行间距修正.md)，修正后实际画面待复核，不将旧截图当成新结果。

## 3. 主要行动页的同步修改

六个按钮保持两列三行及原按钮高 55，使用 `UiDistributedGridLayoutGroup` 将剩余纵向空间均分给顶部、两处行间和底部，整体居中。保留 `UiAdaptiveGridColumns`，窄宽度可变为一列。原生 Grid 的 spacing/alignment 只在计算时临时调整后恢复，反复调整窗口尺寸不能累计撑大内容。

## 4. 城市样式总览、放大与宣告窗口

### 4.1 构图、卡面与按钮

- 窗口内左侧六卡总览及固定纸底摘要，右侧完整城市板；1920 基准六卡按三列两行同屏。原生网格按列填入，四张一级卡位于左侧两列，两张二级卡位于右侧一列；正式候选索引与选择回调不改变。
- 完整原卡为 930×600、31:20，保留右侧状态区域。总览 `Card Image` 相对外层卡片等比 **97%**：锚点 min `(0.015,0.015)`、max `(0.985,0.985)`，sizeDelta 为 0，即四边各留 1.5%。轨道和标记随卡面子树缩放。
- `Card Selection State Frame` 位于外层卡根，所有对应 Image 的每单位像素乘数为 **1**；根背景透明，旧 Outline 不显示。总览 Grid 四边 padding=10、spacing=(24,20)。选中框与卡面分层，透明边不能把卡面挤进相邻框。
- 删除所有城市样式的 `Unavailable Lock`，包括总览模板和放大路径。保留可用/不可用/选中边框、勾选及正式资格判断。
- `Close City Style Declaration Preview Button` 仅保留关闭符号与透明点击区域，不显示有色底框。
- 删除主窗口取消按钮；确认宣告采用 `MainButtons-v3.2-Patch.zip` 的 `primary-default/hover/pressed/disabled.png` 四态及对应九切片。特殊行动警告和支付流程中的取消职责保留。

### 4.2 状态轨道和玩家标记

- 删除 `State Track Backgrounds` 下各 Track 的 Image 及 `State Label`，保留轨道 RectTransform 和玩家布局。此要求不删除主界面表格的 State Label；原卡贴图中已经印刷的状态文字也不属于被删 Text 组件。
- 全部玩家块采用 `MainGameUI-CooperationMarkers-v1` 基础四色 Sprite：红、蓝、黄、绿，对应 `cooperation-{08,04,02,01}-64.png`。复用 `Assets/YC/Presentation/Effects/Sprites/EffectRows/markers/`，不使用无 Sprite 方框染色或多色组合图。
- 数字统一白色。所有城市样式相关玩家标记，**数量为 0 时图和数字完全透明，但保留四玩家布局槽位；非零正常不透明**。主界面、总览、放大一致，撤销零值半透明方案。
- 四玩家由原生 HLG/Grid 排列。窗口 `Track reward declared` 为 2×2，单块尺寸参照一级普通轨道；其他窗口轨道四列，二级五组使用统一尺寸参考。
- 二级 `Track 2` 上移 4、`Track 0` 下移 4 UI 单位；普通 `Track active unused` 上移 5.5、`Track active used` 下移 5.5。总览模板及放大页一致。
- 删除 `Track all extra` 及卡外额外宣告带。同玩家同样式所有宣告合并为一个数量块；使用时整个块换轨道，数字不随使用减少。`CityStyleInteraction.DisplayMarkerArea` 以解锁行动的声明记录轨道为主，无行动时以首条为主。
- 合并只改变显示投影。宣告记录、奖励、消耗和正式次数规则保持，拖动仍只提交一次正式特殊行动命令。

### 4.3 查看手势与精简文案

- 删除放大按钮、返回总览按钮，保留放大后的 UI。
- 总览左键/点按选择；长按 0.5 秒、右键或双击查看完整卡。拖动滚动取消长按。放大卡面点按/左键返回总览，并保留有效草稿；右键查看不能同时关闭窗口。
- 删除 `Condition And Reward`、`Player And Available Markers` 节点及相应字段、格式配置、运行时赋值、`RenderSummary`。删除的是页头玩家信息节点；既有页脚动态已选设施/可用标记计数保留。
- `Mode Description` 静态资产文案为：**选择城市样式与设施牌，长按、右键或双击查看城市样式牌**。删除按模式覆盖此文案的旧配置和代码。
- `City Style Preview Name` 仅显示当前样式名字 `option.Name`，删除拼接分数/首次宣告等摘要标题格式。`City Style Match Status` 字号 **20**，最小布局高 28，显示动态匹配结果或不可宣告原因。

## 5. 业务与输入约束

候选、卡版本、设施组合、玩家权限和可用数量必须来自正式查询与可见投影；素材预览中的卡组和数字仅供构图参考。确认前不扣标记、不改真实设施、不发奖励。确认复核请求版本与合法组合，防止重复提交及旧回包覆盖新草稿。

城市板完整等比显示，格位、方向与高亮依赖同一真实图像矩形，包含留白、父缩放与滚动变换。宣告和特殊行动是两个正式命令，不因打开详情或确认宣告自动发动特殊行动。

保留 effect 收起/展开、有效草稿恢复、隐藏页停止选点、顶底栏最高输入、窗口不可拖动、最多一个可交互页面。不同屏幕比例保持相同信息结构，不新增主列分页或单卡轮播。
