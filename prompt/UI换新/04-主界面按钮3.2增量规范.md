## 3. 必须按语义映射现有入口

阅读时的 `ActionPanelView` 有使用角色牌、宣告样式、部署、调度、探索、城市移动和结束行动引用，没有独立的建设／特殊行动按钮字段。已完成 HUD 的旧六格因此不等于素材的新六格；执行前再次复核现状。

| 新用途 | 当前核对入口／要求 |
| --- | --- |
| 主要行动／快速行动／城市样式页签 | 复用 `UI003 Main Surface/Main Regions/Action Tabs` 的节点及 UI-005 页面组织；主界面页签切换属于常驻模块内部，不新增独立可见页面 |

| 建设 | 查清 `BuildInfoPanel`、设施供应、合法候选和建设流程的正式入口；不能把旧“使用角色牌”只换标题当建设 |
| 特殊行动 | 从实际行动能力和既有流程确定含义及入口；没有明确业务能力时禁用并记录缺口，不能把旧“宣告样式”直接改名代替 |

建设／特殊行动即使业务未齐，也先按素材完成对应视觉及明确禁用反馈，保留后续接线边界。不能为了保留旧监听而继续展示错误图标，不能静默移除旧有可用功能。业务范围不明确的项记录为未接入。

## 4. 贴图、文字与状态

1. 以增量包的 `button-roles.json` 与 `assets/button-assets.json` 建立 11 行接入表，包含实际节点、源素材、Unity 资产、状态来源及事件路径。共享源为 `Assets/YC/Presentation/Prefabs/Gameplay/GameplayInteractionHud.prefab`；两场景的覆盖也要复核。
2. 底板 → 等比图标 → 独立文字 → 可选焦点层。底板九宫格切片 1x 为 12、2x 为 24；不用旧 3.1 切片。具体图标矩形、文字中心和分隔线取角色配置，基准构图成立后再用局部布局适配，不能整按钮含文字一起拉伸。
3. 页签有 6 态，其他 3 个底板系列各 4 态。使用实际状态图和 `recommendedInk` 配色；禁用态优先，选中页签在鼠标离开、恢复页面及尺寸变化后仍保持选中。选中页签按下后恢复选中，不丢失状态。
4. 当前 `UiSharedButtonState.Refresh()` 会重新赋旧主题 Sprite，并以 tint 层表示悬停／按下／选中。接入时必须处理这条刷新路径与 Unity `Button.transition` 的职责，防止刚换图又被旧主题覆盖、多个状态驱动器竞争或整图被重复染色。只为目标按钮配置新状态资源，不全局替换旧主题资产。
5. 正常文字使用方正，需要强调时使用汉仪并关闭 Bold／`<b>`；特殊词和两类数字沿用 02。源预览使用的浏览器字体不作为项目字体依据。按钮名等静态文字继续保存于 Prefab；运行时仅按可序列化配置切换状态提示。
6. 逻辑按钮矩形是命中区域；图标、文字、分隔线、焦点装饰不抢射线。底栏两按钮保持最高显示与输入层；结算内容不能盖住它们。鼠标、触摸、键盘／已启用的手柄提交都服从同一可用状态和防重入校验。
7. pending 结束时重新读取最新合法性，不能恢复过期的 `interactable`；按下后禁用／隐藏再松开不得触发旧命令。无撤销、必选结算、支付或选择未完成时，相关按钮保持实际业务规定的禁用状态。
