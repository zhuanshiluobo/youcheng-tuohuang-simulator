## 使用方式

把对应提示词文件交给执行者，并要求同时读取共同约束与实施计划。例如：

> 执行 `prompt/UI换新/UI-005-主界面模块与行动入口迁移.md` 和 `UI-005-补充-主界面按钮3.2.md`。先读 `05-地图俯视改造期间的任务安排.md`，复用 UI-003 框架，完成按钮和独立 UI 工作；保留相机改造范围，地图相关端到端验收待俯视方案交付后补齐。

执行 UI-005 时将主提示词与 `UI-005-补充-主界面按钮3.2.md` 一并交给执行者。新增素材的检查和规划见[本轮记录](执行记录/2026-09-25_UI-003完成与按钮3.2整理.md)。

执行记录新增到本分类的 `执行记录/`，采用 `YYYY-MM-DD_UI-编号_主题.md`；文件已存在时追加序号，避免覆盖前轮记录。每项记录注明修改的源 Prefab／场景覆盖、接入入口、验证范围、截图位置、已知问题和任务状态。

编写这些提示词不等于已执行资产覆盖。后续执行一项实施提示词时，仅处理其中指明的界面目标；普通检查、运行或测试不得顺带重建界面。已有文档及源素材保持保留。
