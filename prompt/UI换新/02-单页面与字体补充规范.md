# 单页面、结算页面收起恢复与字体规范

日期：2026-09-24。来源：用户在 UI-001 完成后补充的交互与字体要求。适用于 UI-002～UI-012。

本规范优先于先前计划中的多窗口叠加、顶栏按钮收起整个主界面等描述。UI-001 的[接入基线](执行记录/2026-09-24_UI-001_接入基线.md)保留原样，作为补充前的静态核对记录；运行画面、字体实际渲染及页面交互仍须后续验证。

## 1. 同时最多显示一个页面

### 1.1 页面范围

- “页面”包含 effect 唤起的选择／结算页，以及从主界面打开的详情、建设、企业、科室、城市样式、设置、规则书、日志、图片查看器等独立页面。
- 同时最多一个页面可见、激活并接收输入。打开另一个页面时，先退出前一个页面的显示与输入，再显示新页面；过渡动画也不能同时显示两张页面或保留双重遮罩。
- 顶栏、底栏、主界面常驻模块不计为页面，仍保持原先规定的显示和交互层级。普通无交互提示及卡牌拖拽展示不是页面；可独立浏览、操作的详情必须纳入页面管理。
- 结算抽屉如果作为独立展开界面，占用同一个页面位置；如果是当前页面内部的结算区域，则属于该页面。底栏摘要常驻，不能借“抽屉”名义在另一个页面上叠开一张结算页。
- 原文所说的“嵌套选择／子窗口”改为单页面内的步骤切换或替换当前页面。可保留返回所需的状态，但父页和子页不能同时显示。
- 页面不可拖动。页面位置和大小继续由资产配置、自适应布局与 `ContentRect` 决定。

### 1.2 页面管理职责

统一协调所有页面入口、遮罩、焦点和显示切换，包括 Registry 实例化的窗口，以及设置、日志和图片查看器等独立 Controller。某个控制器直接 `SetActive(true)` 或重新渲染不能绕过页面互斥。

需要区分两类状态：当前显示的页面，以及当前仍在结算的 effect 页面恢复信息。后者可以在本地保留而不显示、不命中、不占用焦点；它不算第二个打开页面。

页面互斥属于表现层。EffectRuntime、Host 请求、合法候选和命令仍由既有正式规则管理，页面管理器不另建规则状态机。

## 2. 顶栏“收起／展开”按钮

### 2.1 核心流程

1. 当前 effect 唤起结算／选择页面，顶栏按钮显示“收起”。
2. 玩家点击“收起”：隐藏该 effect 页及其遮罩，释放该页的输入与焦点；保留结算上下文、仍有效的预选、子步骤、滚动位置等本地草稿。主界面可以继续用于查看信息。
3. effect 页已收起时，按钮显示“展开”。玩家通过主界面打开其他页面，一次只显示一页；从资料 A 切换到资料 B，A 退出显示。
4. 再次点击“展开”：先校验当前 effect／请求仍有效，再关闭当前资料页面，恢复当前待处理的 effect 页及有效草稿。恢复后按钮回到“收起”。

该按钮针对当前结算中的 effect 页面；不再复用为主界面侧栏、地图区域或任意资料页的折叠开关。自适应布局若需要侧栏折叠，使用独立配置或入口。

### 2.2 状态与按钮行为

| 状态 | 当前可见页面 | 顶栏按钮 | 点击结果 |
| --- | --- | --- | --- |
| 没有可恢复的当前 effect 页 | 无页面或一张普通资料页 | 禁用，并提供配置好的原因 | 不关闭普通页面，不折叠主界面 |
| 当前 effect 页正在显示 | effect 当前步骤页 | 收起 | 隐藏该页，保留有效结算与草稿，显示主界面 |
| 当前 effect 页已收起，尚未打开资料 | 无页面 | 展开 | 恢复当前待处理 effect 页 |
| 当前 effect 页已收起，正在查看资料 | 一张资料页 | 展开 | 关闭资料页，恢复当前待处理 effect 页 |
| 原 effect／请求已结束或失效 | 按有效状态保留普通资料页或回到主界面 | 清除原恢复目标并刷新状态 | 不恢复旧页、不提交旧选择；有新的有效请求时按新请求处理 |

按钮文案、禁用原因在资产中配置。按钮只对当前玩家有权处理、且确实存在页面的 effect 提供收起与恢复；纯地图输入阶段不伪造一张恢复页面。

### 2.3 查看其他信息与返回

- 用户要求的标准路径是“effect 页 → 收起 → 主界面打开资料 → 展开 → 回到 effect 页”。
- 顶栏设置等入口若在 effect 页显示时直接打开资料，统一先执行同样的收起逻辑，再打开资料。这样仍然保留结算，也保证同时只有一页；不能让独立 Controller 直接叠加窗口。
- 关闭普通资料页回到主界面，effect 页继续保持收起，等待玩家点击“展开”。普通资料之间的返回可保留浏览状态，但每次仍只显示一页。
- effect 内部的下一步、详情查看或返回都通过同一页面管理切换；保留逻辑返回目标，不能再展示父子窗口叠层。
- effect 收起后，允许查看当前玩家有权限的信息、滚动及地图导航。原 effect 的地图选点／拖放提交等输入同时暂停，不能把查看操作当成结算答案；其他行动是否可执行仍由规则决定。

### 2.4 收起不改变规则进度

- 收起和展开只改变本地显示，不调用 `AnswerInteraction`、取消、跳过、确认、结束行动或撤销，也不替玩家选择默认答案。
- 收起后，Host 请求仍可等待玩家回答。不能通过隐藏页面绕过必选步骤，也不能解除原本不合法命令的禁用条件。
- 区分“隐藏显示”和“清理／取消业务上下文”。审计 renderer 的 `Clear`、页面 `OnDisable`、销毁回调及旧折叠组件，避免隐藏时丢失草稿或触发业务取消。
- 不能通过暂停全部状态同步来维持收起。当前玩家投影、pending 和合法性继续更新；同一请求刷新不得强制重新打开隐藏页，也不得生成第二张可见页。
- 恢复信息至少关联对局、玩家、当前 effect／流程、请求 ID 与状态版本。相同有效请求可恢复仍合法的选择；发生版本变化须重新校验候选与报价，失效草稿不能原样提交。
- effect 在收起期间进入新的待处理步骤时，恢复目标应更新为该流程当前步骤，不能恢复已完成的前一步。同一流程保持已收起的浏览状态；提示与底栏摘要同步更新。
- 原流程结束、请求撤销／失效、玩家切换或退出对局时清理旧恢复信息。后续新的 effect 页走正式请求入口，不复用旧草稿。
- pending 时也可收起查看信息，命令仍只提交一次。回复到达后刷新当前有效状态；展开动作本身不能重发命令。
- 改变游戏应用窗口大小时按当前尺寸恢复页面，保留有效草稿与合理滚动位置；不恢复旧屏幕坐标或窗口拖动偏移。

## 3. 字体按语义角色使用

字体源文件位于 `游城拓荒/UI素材/`。以下五类是用户指定的使用规范，后续组件和动态条目均按语义选择字体。

| 语义角色 | 指定字体 | 当前源文件 | 使用示例／要求 |
| --- | --- | --- | --- |
| 常规文字 | FangZhengHeiTiJianTi-1 | [FangZhengHeiTiJianTi-1.ttf](../../游城拓荒/UI素材/FangZhengHeiTiJianTi-1.ttf) | 不加粗的标题、说明、按钮文字等；关闭加粗选项 |
| 强调文字 | HanYiCuHeiJian-1 | [HanYiCuHeiJian-1.ttf](../../游城拓荒/UI素材/HanYiCuHeiJian-1.ttf) | 需要粗体视觉的文字使用该字体；**不勾选 Bold，不用 `<b>` 或额外伪加粗** |
| UI 中的特殊字词 | msyh | [msyh.ttc](../../游城拓荒/UI素材/msyh.ttc) | 例如干员的“策略”“计谋”；明确指定此角色，不仅依赖缺字回退 |
| 卡面 effect 相关数字 | Novecento NarrowBold | [Novecento NarrowBold.otf](<../../游城拓荒/UI素材/Novecento NarrowBold.otf>) | 资源 icon 前的数字、效果数量、费用／奖励、选择几次等；使用字体自带字重 |
| 纯 UI 数字 | Novecento wide Normal Regular | [Novecento wide Normal Regular.woff2.ttf](<../../游城拓荒/UI素材/Novecento wide Normal Regular.woff2.ttf>) | 顶栏回合数，以及仅用于界面导航／展示结构的页码等 |

### 3.1 数字分类与混排

- 按数字的含义选择字体，不按控件所在区域选择。效果次数或资源 icon 前的数量即使出现在底栏摘要，也用 NarrowBold；顶栏回合数用 wide Normal Regular。
- “选择 2 次”中的 `2` 用 NarrowBold，“选择”“次”使用对应文字角色；“第 3 回合”中的 `3` 用 wide Normal Regular。
- 同一行出现说明、特殊词、数字、资源 icon 时，使用明确的文本片段／子控件或所用文本系统支持的字体片段配置，保持基线、间距及换行。不能把整句中文设为数字字体，也不能将全局所有数字替换成同一种字体。
- 不确定语义的数值先在字段与字体角色表中说明用途，按上述定义归类；避免在刷新函数中根据字符串正则猜测用途。

### 3.2 文件与接入注意

- [字体来源清单](字体来源清单-2026-09-24.json)记录实际路径、SHA-256、文件头、字体名称和集合内字体。原文件保留，导入或生成字体资产时另建可追溯资源。
- 宽体数字文件实际名称带 `.woff2.ttf`，文件头为 TrueType，名称表为 `Novecento wide Normal Regular`；不能仅因文件名含 `woff2` 就按网页压缩字体处理或擅自替换来源。
- `msyh.ttc` 含 `Microsoft YaHei` 和 `Microsoft YaHei UI` 两个 Regular 字体。按用户指定 `msyh` 使用 `Microsoft YaHei` Regular（当前集合索引 0）；导入时记录具体字体成员，检查“策略”“计谋”的实际字形。
- UI-002 核对项目当前 `UnityEngine.UI.Text`／TMP 的实际使用，建立可序列化的五类字体引用或样式配置。需要派生字体或 TMP 资产时，记录源文件与字体成员，实际验证导入；不能只改扩展名冒充转换成功。
- 现有 `FontUtility`／`FontRefreshDriver` 仅按 CJK／Latin 管理，需纳入 UI-002 适配核对，保证重新聚焦、纹理恢复、动态条目创建后仍保留五类字体角色，不退回统一字体或重新开启 Bold。
- 缺字回退单独配置，检查中文、标点、数字、符号和特殊字词；回退不能替代已指定角色。字体尺寸、行高与间距仍为可编辑的视觉参数。
- 本次只核对了文件头与名称表，尚未进行 Unity 导入、字形覆盖或实际渲染验证。

## 5. 验收场景

1. effect 页已有预选 → 收起 → 打开资料 A → 打开资料 B → 展开：全过程可见页面数量始终为 0 或 1；资料 B 关闭，恢复同一有效请求与预选。
2. 收起后关闭资料页：回到主界面，effect 继续收起；没有当前 effect 时顶栏按钮不能折叠普通页或主界面。
3. 同一请求多次刷新、重复收起／展开、切换资料、打开子选择、调整渲染尺寸：没有自动弹回、双重遮罩、焦点残留、隐藏页命中或重复提交。
4. pending 期间收起，随后成功／拒绝／请求替换或流程结束：展开只恢复当前有效步骤；旧请求草稿不提交到新请求。
5. 收起过程中只查看资料、滚动、平移地图：不产生 effect 答案，不跳过必选结算；顶底栏合法功能仍能操作。
6. 方正普通文字、汉仪强调文字、msyh 的“策略／计谋”、NarrowBold 效果数字、wide 顶栏回合数在实际场景显示正确。汉仪关闭 Bold；字体刷新与动态条目创建后不变更角色。
7. 长中文、混排数字与 icon、不同字体基线、缺字回退及窄屏换行实际检查；用户指定的字体角色可以验证，仍不锁定可编辑的字号、坐标或行距。
