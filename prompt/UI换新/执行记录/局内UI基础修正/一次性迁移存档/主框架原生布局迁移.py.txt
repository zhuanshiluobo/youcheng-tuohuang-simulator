"""本次授权的定点 YAML 编辑。保留已有对象 ID；不运行旧生成器。"""
from audit_gameplay_ui import ROOT, OUT, documents, field, ref
from pathlib import Path
import re, json

def guid(path):
    return re.search(r'^guid: (\w+)', (ROOT/path).read_text(encoding='utf-8-sig'), re.M).group(1)

NATIVE = {}
for p in (ROOT/'Library/PackageCache').rglob('*.cs.meta'):
    if p.name[:-8] in ('VerticalLayoutGroup','HorizontalLayoutGroup','LayoutElement','GridLayoutGroup'):
        NATIVE[p.name[:-8]] = re.search(r'^guid: (\w+)',p.read_text(),re.M).group(1)

class Asset:
    def __init__(self,path):
        self.path=ROOT/path; self.docs=documents(self.path); self.next=max([7451260000000000000]+[i for i in self.docs if 7451260000000000000 <= i < 7451270000000000000])
        self.removed=[]
    def uid(self):
        self.next+=1
        assert self.next not in self.docs
        return self.next
    def text(self,i): return self.docs[i][1]
    def set(self,i,key,value):
        k,t=self.docs[i]; pattern=r'^  '+re.escape(key)+r':.*?(?=^  [\w]|\Z)'
        assert re.search(pattern,t,re.M|re.S), (self.path,i,key)
        self.docs[i]=(k,re.sub(pattern,lambda m:f'  {key}: {value}\n',t,flags=re.M|re.S))
    def go(self,r): return ref(self.text(r),'m_GameObject')
    def children(self,r):
        t=re.search(r'^  m_Children:(.*?)(?=^  m_Father:)',self.text(r),re.M|re.S).group(1)
        return [int(x) for x in re.findall(r'fileID: (-?\d+)',t)]
    def children_set(self,r,items): self.set(r,'m_Children','\n'+'\n'.join('  - {fileID: %d}'%i for i in items) if items else '[]')
    def move(self,r,parent):
        old=ref(self.text(r),'m_Father')
        self.children_set(old,[i for i in self.children(old) if i!=r])
        self.children_set(parent,self.children(parent)+[r]); self.set(r,'m_Father','{fileID: %d}'%parent)
    def fill(self,r):
        for k,v in [('m_AnchorMin','{x: 0, y: 0}'),('m_AnchorMax','{x: 1, y: 1}'),('m_SizeDelta','{x: 0, y: 0}'),('m_AnchoredPosition','{x: 0, y: 0}')]: self.set(r,k,v)
    def component(self,go,script,body='',ident=None):
        if ident is None:
            ident=self.uid(); k,t=self.docs[go]
            self.docs[go]=(k,t.replace('  m_Layer:',f'  - component: {{fileID: {ident}}}\n  m_Layer:'))
        self.docs[ident]=(114,f'''--- !u!114 &{ident}
MonoBehaviour:
  m_ObjectHideFlags: 0
  m_CorrespondingSourceObject: {{fileID: 0}}
  m_PrefabInstance: {{fileID: 0}}
  m_PrefabAsset: {{fileID: 0}}
  m_GameObject: {{fileID: {go}}}
  m_Enabled: 1
  m_EditorHideFlags: 0
  m_Script: {{fileID: 11500000, guid: {script}, type: 3}}
  m_Name:
  m_EditorClassIdentifier:
{body}''')
        return ident
    def components(self,r):
        go=self.go(r)
        return [i for i,(k,t) in self.docs.items() if k==114 and ref(t,'m_GameObject')==go]
    def element(self,r,mw=0,pw=-1,fw=1,mh=0,ph=-1,fh=0,ignore=False):
        old=next((i for i in self.components(r) if NATIVE['LayoutElement'] in self.text(i)),None)
        return self.component(self.go(r),NATIVE['LayoutElement'],f'''  m_IgnoreLayout: {int(ignore)}
  m_MinWidth: {mw}
  m_MinHeight: {mh}
  m_PreferredWidth: {pw}
  m_PreferredHeight: {ph}
  m_FlexibleWidth: {fw}
  m_FlexibleHeight: {fh}
  m_LayoutPriority: 10
''',old)
    def group(self,r,vertical=True,spacing=0,padding=(0,0,0,0),ident=None):
        return self.component(self.go(r),NATIVE['VerticalLayoutGroup' if vertical else 'HorizontalLayoutGroup'],f'''  m_Padding:
    m_Left: {padding[0]}
    m_Right: {padding[1]}
    m_Top: {padding[2]}
    m_Bottom: {padding[3]}
  m_ChildAlignment: 0
  m_Spacing: {spacing}
  m_ChildForceExpandWidth: {int(vertical)}
  m_ChildForceExpandHeight: {int(not vertical)}
  m_ChildControlWidth: 1
  m_ChildControlHeight: 1
  m_ChildScaleWidth: 0
  m_ChildScaleHeight: 0
  m_ReverseArrangement: 0
''',ident)
    def node(self,name,parent):
        go,r=self.uid(),self.uid()
        self.docs[go]=(1,f'''--- !u!1 &{go}
GameObject:
  m_ObjectHideFlags: 0
  m_CorrespondingSourceObject: {{fileID: 0}}
  m_PrefabInstance: {{fileID: 0}}
  m_PrefabAsset: {{fileID: 0}}
  serializedVersion: 6
  m_Component:
  - component: {{fileID: {r}}}
  m_Layer: 5
  m_Name: {name}
  m_TagString: Untagged
  m_IsActive: 1
''')
        self.docs[r]=(224,f'''--- !u!224 &{r}
RectTransform:
  m_ObjectHideFlags: 0
  m_CorrespondingSourceObject: {{fileID: 0}}
  m_PrefabInstance: {{fileID: 0}}
  m_PrefabAsset: {{fileID: 0}}
  m_GameObject: {{fileID: {go}}}
  m_LocalRotation: {{x: 0, y: 0, z: 0, w: 1}}
  m_LocalPosition: {{x: 0, y: 0, z: 0}}
  m_LocalScale: {{x: 1, y: 1, z: 1}}
  m_Children: []
  m_Father: {{fileID: {parent}}}
  m_AnchorMin: {{x: 0, y: 0}}
  m_AnchorMax: {{x: 1, y: 1}}
  m_AnchoredPosition: {{x: 0, y: 0}}
  m_SizeDelta: {{x: 0, y: 0}}
  m_Pivot: {{x: 0.5, y: 0.5}}
''')
        self.children_set(parent,self.children(parent)+[r]); return r
    def remove_tree(self,r):
        for child in self.children(r): self.remove_tree(child)
        go=self.go(r); parent=ref(self.text(r),'m_Father')
        self.children_set(parent,[i for i in self.children(parent) if i!=r])
        self.removed.append(dict(fileID=go,name=field(self.text(go),'m_Name')))
        for i in [i for i,(k,t) in self.docs.items() if i==go or ref(t,'m_GameObject')==go]: del self.docs[i]
    def save(self):
        self.path.write_text('%YAML 1.1\n%TAG !u! tag:unity3d.com,2011:\n'+''.join(t for k,t in self.docs.values()),encoding='utf-8')
