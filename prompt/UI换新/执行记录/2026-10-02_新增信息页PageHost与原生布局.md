## 布局与尺寸责任

两个页面实例现在直接挂到 `GameplayHudFrame.ContentRect`（实际 PageHost），继续通过 `ShowPage`／`HidePage` 管理互斥。根 RectTransform 四向拉伸；嵌套 Canvas 排序 118，低于常驻栏 30000；独立 CanvasScaler 禁用，继承宿主缩放。遮罩只填满 PageHost，顶底栏继续显示、命中和操作。

| 区域 | 原生结构 | 唯一驱动者与配置 |
| --- | --- | --- |
| 页面根 | VLG → 横向窗口定位容器 HLG → 窗口 | 根填满 PageHost；窗口首选尺寸来自 LayoutElement；原生组分配矩形 |
| 页头／正文／页脚 | 窗口 VLG | 固定区 `flexibleHeight=0`；正文 `flexibleHeight=1`；VLG 控制宽高、横向填满、纵向不强制均分 |
| 表头和区域行 | 既有 HLG | 固定区域／分值／空格列；参与玩家列分配余量，不改变玩家排序或人数投影 |
| 区控行内容 | VLG + 单轴 ContentSizeFitter | 行首选高 70、可读最小高 50；`InformationTableHeight` 只提供内容高度测量，VLG 分配每行矩形，Fitter 仅控制 Content 高度 |
| 游戏盒四模块 | HLG → 各模块 VLG | 模块宽度输入保持素材的 316／316／260／678；主体取得高度余量，标题和底部提示固定 |
| Token 滚动 | HLG 分 Viewport／滚动条；Content VLG；每行 HLG | `InformationTokenRows` 只按图像宽高比选择 168／228 的布局输入、决定分行和父级；不写条目坐标或 Content 高度 |
| Token 单项 | HLG：原图 + 数量 | 图片取得剩余宽度并保持比例，数量保留 58 宽；不依赖原图导入尺寸撑大布局输入 |
| 底图、边框、装饰 | stretch 或局部锚点；`ignoreLayout` | 不占用行列槽位，保持正确绘制顺序；原图牌堆散落与企业板比例约束仍只负责图片内部 |

根、窗口和正文 VLG 明确 `childControlWidth/Height=true`、`childForceExpandWidth=true`、`childForceExpandHeight=false`。定位和模块 HLG 横向不强制均分、纵向填充；页头内按素材装饰高度居中。所有原生组关闭 childScaleWidth/Height。

已移除 `GameBoxPageView.Render` 对每个 Token 的 `anchoredPosition`、`sizeDelta` 和 Content 高度写入。保留的两个局部辅助器只处理异宽 Token 分行和表格内容高度输入，不承担窗口、页头、正文、页脚的坐标排布。普通运行和测试不调用 `InformationPageAssetInstaller`，不保存或覆盖界面资产；本次使用一次性人工迁移脚本直接编辑已授权的两份源预制体。

区控 24 处数值字体仍为 `Novecento NarrowBold.otf`，FontStyle 为 Normal；分数图仍复用主界面的 `resource-score.png`，与用户指定的“分数.png”同源。游戏盒四种玩家标记仍复用有数字版方块及该页面的颜色配置。

## 1080p 基准与必要差异

基准为同一次任务中、同场景、同测试业务状态、1920×1080 的实际渲染和屏幕矩形。屏幕坐标以下方为原点。

| 对象 | 迁移前 | 迁移后 | 原因 |
| --- | --- | --- | --- |
| PageHost | `(0,102,1920,906)` | 相同 | 复用既有宿主，不重新扣除顶底栏 |
| 区控背景窗口 | `(180,80,1560,920)` | `(180,102,1560,898)` | 原下缘比 PageHost 多伸出 22；收紧背景及底部留白，保留表格和页脚位置 |
| 区控页头、表头、各区域行、页脚 | 实际基准矩形 | 相同 | 由原生关系复现原构图 |
| 游戏盒窗口 | `(135,130,1650,820)` | 相同 | 保留正常基准 |
| 游戏盒模块、牌堆、Token 视口、页脚 | 实际基准矩形 | 相同 | 保留正常构图和条目间距 |

模块标题文本框与右侧数量原有 20 的重叠余量改由 HLG 分离，文字起点和实际显示不变。Token ScrollRect 根收纳原先延伸在根外的滚动条区域；实际 Viewport 与滚动条显示位置保持。页头图标及装饰只使用局部锚点补偿素材基线，不恢复逐项屏幕坐标算法。

几何核对记录：`Logs/InformationPageLayout-20261001/final-report.json`。没有以宽松容差解释整体位移：列出的正常区域差异不超过 0.01 屏幕像素，区控背景 22 的修正单列。
