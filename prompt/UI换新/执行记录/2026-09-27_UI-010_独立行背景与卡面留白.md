## 主界面城市样式

- 原二级行固定高 58，而 State Label 高 16、Player Counts 高 44，尚未计入边距就需要 60。解除行根、State Slots、各 State 容器 LayoutElement 对最小／首选高度的覆盖，让 HorizontalLayoutGroup、VerticalLayoutGroup 根据子项需求逐层计算高度。整行上下边距各 3，二级槽上下边距各 2，标签与标记间距 2。
- 二级每组 Player Counts 继续使用原生 GridLayoutGroup 两列；复用 CityStylePlayerMarkerGrid 按容器宽高计算等比格尺寸，窄列时格子随容器适配。标记位置由 GridLayoutGroup 管理，不以手写坐标或裁切掩盖溢出。
- 二级状态按“2、已使用、1、已使用、0”显示。删除两处已使用标签的余量后缀，五个业务状态槽仍独立保留，不合并规则状态。
- 根据既有五类字体规范，状态中的剩余使用次数 2／1／0 使用 Novecento NarrowBold，修正上一轮误设的汉仪字体。玩家数量同属规则数值，保持 NarrowBold；中文状态和名称保留 HanYiCuHeiJian-1。数字控件允许在较窄标记内适配字号。
- 本轮读取 FrontierUI-v3-Patch/main-city-patterns.png 原素材预览：每条样式有独立浅色底、行间露出深色模块底。此前文字规范写过“整块浅纸底”，本轮以用户明确要求和该预览为准。
- 三种状态行模板各自增加不透明浅色 Image，行间距设为 4；列表视口去掉整块纸底，保留透明 Image 供滚动区域命中使用，不新增点击入口。
- 同步修改 GameplayInteractionHud.prefab 的实际本地子树与独立 BuildInfoPanel.prefab。
