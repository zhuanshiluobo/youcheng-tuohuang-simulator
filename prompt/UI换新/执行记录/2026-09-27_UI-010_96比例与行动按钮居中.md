# UI-010：96% 卡面、列表边距与主要行动居中

日期：2026-09-27。按用户本轮三项要求直接修改。

- 总览卡面的宽高均改为父卡片的 96%，对应 Anchor Min (0.02, 0.02)、Anchor Max (0.98, 0.98)，Size Delta 为零；四边各留 2%。选中边框每单位像素乘数继续为 1。
- 企业合作 Cooperation Paper 的下边距为 8。将 Action Content 改为四边各留 8，城市样式列表自身上下 Padding 清零，避免重复叠加后变成 10 或 12。样式背景条相对 Action Region 上下实际留白为 8，水平也维持各 8。
- 一级 active、reward 行中的“已使用”“未使用”“已宣告”字号统一为 14，继续使用 HanYiCuHeiJian-1。文字布局预留高 20、首选宽 48／最小宽 42，行高继续由布局计算。HUD 实际模板和独立 BuildInfoPanel.prefab 同步修改。
- 主要行动六个按钮继续两列三行。Main Actions 改用 UiDistributedGridLayoutGroup，继承原生 GridLayoutGroup，复用原自适应列数组件。按钮尺寸仍由原配置决定，仅将纵向余量均分到顶部、行间和底部；最小上下 Padding 均为 10，最小纵向 Spacing 为 10，所以三行时四处空隙相等、整体垂直居中。窄宽度变为单列时按实际行数计算。
- 计算仅在布局回调中暂时调整原生网格的间距与纵向对齐，结束后恢复配置，不累计改变 Inspector 参数或布局首选高度。城市样式列表仍采用此前仅分配行间距的布局。

修改属于源 Prefab 与布局组件，不保存场景或运行 UI 生成器。遵循此前要求，本轮未运行 Unity、测试或截图，未提交 Git；以上不作为视觉或运行验证结论。
