## 动态创建与共用组件补漏

- Registry 现有正式序列化项是效果壳、事件、调度、城市样式预览、卡图目录、卡牌交互 Profile，以及 UI-006 新增 `effectRowPrefab`。`Instantiate*` 已把对局页挂到实际 `GameplayHudFrame.ContentRect`，但挂载内容区不自动解决每个固定大小 panel 的溢出。
- `Ui006/Prefabs/EffectRow.prefab` 只有 LE，没有负责内部的布局容器；`UiEffectRowView.ApplyLayout` 写标题/正文 left inset、宽度和行高。需以同一轴一个驱动者迁移；右侧用法/状态空间应预留。
- `Ui002/Prefabs/MixedLine.prefab` 的 `UiFlowLayoutGroup` 是现有可复用换行 LayoutGroup：按可用宽测 preferred/min width，设置儿童坐标并返回高度。适合语义文本/图标片段，不适合直接替代所有窗口页头/内容/页脚。
- 卡牌 ghost、地图点击热点、城市格位、InfluenceModelUiAnchor 的 3D 模型、LoadingModelDragController 的模型旋转属于内容交互；不应为了“无固定坐标”删除它们。应记录父容器和局部图像坐标映射，保留唯一输入所有者。
- `FontHealthCheckRunner`、`PlayerJourneyRuntime`、Editor 预览/烟测创建属于诊断入口，不是发布 UI 源；普通运行/测试不得触发资产重建。
