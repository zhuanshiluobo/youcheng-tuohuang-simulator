# 使用角色牌界面修复与旧弹窗清理

日期：2026-09-27

## 修改

- 以用户更新后的 `CardViewer-v3.6-Patch.zip`（包内版本 3.6.2）为依据，直接修改 `Assets/YC/Presentation/Prefabs/Gameplay/Dialogs/CardViewer.prefab`。没有运行界面生成器，也没有保存覆盖场景。
- 计谋、策略按钮改为 224×64，取消按钮改为 176×64；间距分别为 24、40。使用补丁提供的完整 @2x 图片，不再沿用旧裁切。三按钮使用相同的中文字体、26 号粗体标签。
- 导入 action/cancel 的 normal、hover、pressed、disabled 共 8 张纹理；新增 `UiTextureButtonState` 切换贴图和文字状态，并保留独立焦点描边。
- 正常使用模式清空通用提示，禁用时显示动态原因。
- `CardViewer.IsShowing`、`Dismiss()` 和 `MobileCityInteractionController.OnDestroy()` 按 Unity 对象销毁语义判断有效性，迟到的关闭不再访问已销毁对象或触发旧回调。
- 清除 Prompt Bounds 旧提示层，以及 PromptPresenter、GameplayPromptView、UiPromptSizeInput、旧效果弹窗拖动和局部折叠组件与相应引用、配置。Prompt Bounds 原本只负责旧提示，并非所有弹窗的父节点。规则书等仍在使用的查看器保留。
- 临时交互反馈转到 HUD 现有摘要区域；地图选点让出效果页时保留地图提交能力，转为查看资料时暂停效果输入。
- 更新相关测试的旧查看器、旧折叠接口，保留选择、返回、禁用、重复提交、拖放等功能断言。
