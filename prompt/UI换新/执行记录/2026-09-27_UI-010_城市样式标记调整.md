# UI-010 城市样式标记与窗口细节调整

日期：2026-09-27。承接同日素材构图纠正结果，落实用户最新五项修改，不覆盖旧交付与截图。

## 五项修改

| 用户要求 | 实际修改 |
| --- | --- |
| 源石工业中枢删除 `Unavailable Lock` | `CityStyleVisualCatalog` 为正式卡 ID `city_style_source_stone_industrial_hub` 配置 `hideUnavailableLock`；该卡从共享卡模板创建后移除锁对象，刷新不会恢复。其他卡锁保持既有行为，不改变宣告资格。 |
| 轨道删除 `State Label` | 从总览卡模板及放大页的 `State Track Backgrounds` 中各移除8个标签对象。主界面状态表的列标题不属于此次删除范围。 |
| 关闭按钮出现有色框 | 原因为按钮 Image 的棕色底及金色 Outline；源 Prefab 去掉描边、底色透明，保留“×”、透明命中区域和关闭监听。 |
| 统一基础四色 | 零值、已有数量、额外宣告及主界面表格统一引用 `MainGameUI-CooperationMarkers-v1` 的基础单色 `cooperation-08/04/02/01-64.png`，不再用无 Sprite 色框或旧 `digit-base-*`。 |
| 四个标记使用 Layout | 总览模板和放大页各9条轨道均有原生四列 `GridLayoutGroup`，四个玩家槽持续参与布局；动态数量放入对应槽。自适应组件仅计算正方形格尺寸及间隔，不设置四个标记的位置。主表沿用Ⅰ级 HLG／Ⅱ级2×2 Grid，零值弱化而不隐藏布局槽。 |

颜色序列仍按玩家枚举红、蓝、绿、黄保存引用；视觉顺序红、蓝、黄、绿。四色图与指定源 zip 内同名文件逐字节一致。图形使用白色 tint，保留素材本身的边缘与透明区域，数字由独立 Text 更新。拖动模板的旧 Outline 已移除，拖动虚影沿用同一 Sprite。
