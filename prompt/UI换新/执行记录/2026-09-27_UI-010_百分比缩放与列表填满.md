# UI-010 百分比缩放、选中边框与列表填满

日期：2026-09-27。按用户最新四项要求直接修改。

- 城市样式总览卡面的 Card Image 改为相对父卡片宽高各 99%：Anchor Min 为 (0.005, 0.005)，Anchor Max 为 (0.995, 0.995)，Size Delta 为零、居中。四边各留 0.5%，不再使用左右 12.4／上下 8 的固定像素内缩；轨道与玩家标记仍随卡面一起调整。
- 窗口内所有城市样式共用的 Card Selection State Frame 的 Image/Pixels Per Unit Multiplier 改为 1。边框仍处于卡模板外层，实例从同一个本地模板生成。
- City Style Status Table Content 的 ContentSizeFitter 替换为项目已有 UiFlexibleCanvasContent：内容高度至少等于视口，需求超过视口时仍允许滚动。
- 原生 VerticalLayoutGroup 没有把剩余高度只分到行间距的开关，Child Force Expand Height 会拉伸各行。因此增加 UiDistributedVerticalLayoutGroup，继承原生 VerticalLayoutGroup；保留原生行尺寸和定位，只在纵向布局时把多余高度均分给 n−1 个间隔。Inspector 中 Spacing 仍表示最小间距（当前 4），布局计算后恢复该配置，不累计放大间距。六条样式能在空间足够时撑满内容区，空间不足时保持最小间距并滚动。
- 各行维持由标签和标记推导的高度，不重新固定二级行高。主 HUD 实际子树和独立 BuildInfoPanel.prefab 的内容容器同步使用上述布局。
- 企业合作浅色背景 Cooperation Paper 左右各留 8；此前样式条左右实际留白为 Action Content 的 10 加列表 Padding 的 4，共 14。将 Action Content 的水平位置改为 8、宽度差改为 -16，列表左右 Padding 改为 0。两模块同属右列，各样式条的背景宽度由父级拉伸为右列宽度减 16，与企业合作浅色背景两边对齐。列表上下 Padding 保留 2。

同步修改 GameplayInteractionHud.prefab、BuildInfoPanel.prefab、CityStyleDeclarationPreviewDialog.prefab 和布局组件；源资产为修改来源，不保存场景、不运行生成器。按既有要求未启动 Unity、未运行测试或截图、未提交 Git。本记录不代表运行或视觉验收通过。
