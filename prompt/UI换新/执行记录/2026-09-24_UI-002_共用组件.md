## 3. 共用组件与状态

| Prefab | 内容与约束 |
| --- | --- |
| `SharedFrame` | 底图、透明九宫格外框、Content 分层；最小 320×200、首选 720×480、内容四边 24。 |

## 4. 五种字体与混排

| 角色 | Unity 字体资产与 GUID | 来源／成员 |
| --- | --- | --- |
| 常规文字 | `FangZhengHeiTiJianTi-1.ttf` · `43e9d69dcca63724db85852acd46004d` | 原文件同名，方正黑体简体 Regular。 |
| 强调文字 | `HanYiCuHeiJian-1.ttf` · `5c5a187d1eb86944c93f847ec521c324` | 原文件同名，汉仪粗黑简原生字重；Text `FontStyle.Normal`，不用 `<b>`。 |
| 特殊字词 | `MicrosoftYaHei-Regular-face0.ttf` · `583ab100aa403d043b49362948eef356` | 从 `msyh.ttc` 提取索引 0 的 `Microsoft YaHei Regular`，未使用索引 1 的 UI 字体。`策略`、`计谋` 用该角色。 |
| effect 数字 | `Novecento NarrowBold.otf` · `3eddf79db7bec9c4193e00ae800bfd4e` | 原生 NarrowBold，资源 icon 前数量及“选择 2 次”的 `2`。 |
| 纯 UI 数字 | `Novecento wide Normal Regular.ttf` · `0a6c131175d7afb4daca1a87a679f835` | 源文件名为 `.woff2.ttf`，文件头和名称表均为 TrueType；复制时去掉误导性中缀，字节未变。“第 3 回合”的 `3` 使用此角色。 |

`UiFontRoles.asset` 明确持有五种角色和旧 `NotoSansCJKsc-Regular.otf` 缺字回退。`UiSemanticText` 按片段角色设置字体，检查片段字符覆盖后才选择回退；`SetValue` 用于动态条目，静态样例仍在 Prefab。`MixedLine` 将“选择 2 次，使用 策略／计谋 获得 +3 [资源图标]；第 3 回合”拆成文字、两类数字和 icon 子控件，汉仪只用于按钮强调。对这组中文、标点、数字和符号核对了 cmap；两套 Novecento 不含中文，所以不能把整句绑定为数字字体。项目相关 UI 当前是 `UnityEngine.UI.Text`；未为未使用的 TMP 文本系统制造字体资产。

`FontRefreshDriver` 在共享设置菜单源 Prefab 持有角色配置，`FontUtility` 刷新时依原来的字体角色逐一恢复，不把新片段归并到旧 CJK／Latin。旧两角色接口仍可用。定向 EditMode 测试 `RecreateManagedTextPreservesFiveSemanticFonts` 对五种角色的 Text 执行重建刷新后全部保持原字体与 `Normal` 样式，结果 1/1 通过；[测试 XML](证据/UI002-EditMode结果.xml)已保存。

## 6. 沿用项与缺口

- 正式主界面、窗口 Registry 和两个对局场景尚未引用 UI-002 共用 Prefab；UI-003～012 需按各自资产所有权与场景覆盖逐项接线。安全预览的通过不能替代正式游戏画面、输入焦点与联机流程验收。
- 旧页签、步进器、滚动条和专用选择状态保留自己的映射；Card-Picker／Option-Picker 的大画布图没有通用导入，后续窗口需核对原包 `visibleRect`／透明区域。撤销能力、企业和科室业务入口不在本项实现。
- 片段式混排会按片段换行；更复杂的行内中英文断行、全部 Unicode 缺字覆盖和具体设备字体基线仍需在正式窗口使用时验收。预览图证明上述样例与尺寸的实际渲染，不宣称所有窗口视觉已完成。
