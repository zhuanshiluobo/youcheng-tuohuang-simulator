# UI-010 主界面宣告区域与文案精简

日期：2026-09-27。按用户本轮六项要求直接修改。

## 主界面

- 删除 `City Style Table Header` 及本局样式数量；删除 `Action Region` 的 `Header Background`、`Header Title`、`Quick Header Title`、`City Header Title`。
- 复用已有 `Declare City Style Button` 的 Button 组件和正式业务监听，将其矩形拉伸覆盖整个 `Action Region`。按钮只负责透明命中，删除旧按钮文字、描边和换色组件；行动控制器只设置其可用性，不再给它涂按钮背景色。
- `Action Content` 放入该按钮下面，四边保留 10 UI 单位内边距，使用腾出的标题空间。点击由父按钮接收，列表仍使用原 ScrollRect；城市样式页签启用该 Button，其他页签禁用该 Button 组件，不隐藏行动内容。
- 删除名称 Button、透明命中 Image 和 `nameButton` 字段，以及 `CityStyleClicked` 事件、控制器订阅、名称点击处理和旧查看入口转发。主表名称现在仅显示文本。窗口内长按、右键、双击查看完整卡以及点击返回继续保留。
- 三个页签按钮、六个动态城市样式名称所用的三种状态行模板、所有状态标签统一使用 `HanYiCuHeiJian-1`。主 HUD 本地子树与独立 `BuildInfoPanel.prefab` 同步修改。
- `未用`、`已用` 改为 `未使用`、`已使用`；二级标签使用 `已使用余1`、`已使用余0`，并将二级五组 State Label 改成不透明黑色。普通状态标签宽度扩至 42，二级标签高度增至 16，以容纳完整文字。

## 城市样式窗口

- 总览卡模板与放大卡的 `Track active unused` 上移 5.5，`Track active used` 下移 5.5；保留此前二级轨道和标记的调整。
- 删除 `Condition And Reward`、`Player And Available Markers` 节点及其序列化字段、格式配置和运行时赋值；删除 `RenderSummary` 方法与调用。
- `Mode Description` 固定为“选择城市样式与设施牌，长按、右键或双击查看城市样式牌”。文案保存在 Prefab Text 上，删除旧按模式改写的字段和代码。
- 完整卡模板继续属于窗口自己的 `Templates`，`optionTemplate` 保持本地引用。
