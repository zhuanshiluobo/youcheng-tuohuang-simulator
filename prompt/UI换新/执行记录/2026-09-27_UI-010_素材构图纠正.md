- 清理6个本轮误重复的CanvasRenderer，最终日志不再有对应Transform断言。
- 三个Prefab无重复fileID，无新增悬空本地引用。HUD开工前已有6610471206676212675悬空引用，属于其他隐藏模块，本轮未改。SampleScene和ThreePlayerScene字节与上轮快照一致，未保存或应用场景覆盖。
