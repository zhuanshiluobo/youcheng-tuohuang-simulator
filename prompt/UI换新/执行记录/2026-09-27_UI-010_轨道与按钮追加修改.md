已直接修改：

1. 从共享卡模板删除全部 `Unavailable Lock`，移除锁字段、控制逻辑及原源石工业中枢专用配置。
2. 总览模板和放大页的所有 `State Track Backgrounds/Track` 移除 Image 组件，保留轨道、状态映射和玩家槽。
3. 两处 `Track reward declared` 改为原生 Grid 两列两行，自适应尺寸计算同时考虑行数。

5. 删除主窗口取消按钮及序列化字段、监听和模式显隐逻辑。确认宣告按钮复用已导入的 `MainButtons-v3.2-Patch.zip` 主按钮四态背景，使用 `UiMainButtonState` 和已有12px九切片资源，移除旧描边。右上关闭入口保留；特殊行动警告及支付窗口的取消不在本次删除范围。
6. 总览使用原生网格按列排列，先Ⅰ级后Ⅱ级。正常六张卡中，两张Ⅱ级卡位于右侧一列；正式候选索引和点击回调保持对应。
