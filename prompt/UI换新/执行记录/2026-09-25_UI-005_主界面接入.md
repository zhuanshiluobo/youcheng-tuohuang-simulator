# UI-005：主界面模块与行动入口接入记录

日期：2026-09-25。按 `UI-005-主界面模块与行动入口迁移.md` 及按钮 3.2 补充执行。UI-004 地图俯视改造尚未交付，地图选点后的完整行动链单列待验。

## 资产来源与修改边界

- 两张实际场景 `SampleScene`、`ThreePlayerScene` 均实例化 `Assets/YC/Presentation/Prefabs/Gameplay/GameplayInteractionHud.prefab`，本项手动修改该**共享源**，没有保存场景覆盖，也没有改变两场景的地图相机、投影、姿态或视口算法。`Ui005AssetMigration` 是对指定共享 Prefab 的一次性手动迁移入口，检查已有组件后拒绝重复写入；运行、截图、测试均不调用 `Rebuild` 或覆盖生成器。
- 从 `游城拓荒/UI素材/整理增量-2026-09-25-按钮3.2/原包/assets` 按 `button-roles.json`、`button-assets.json` 导入 1x 的 18 张底板和 33 张图标，仅覆盖本项 11 个目标。目标为 `Assets/YC/Presentation/Ui005/Sprites/Bases` 与 `Icons`；51 个 PNG 与原包逐一比较 SHA-256，均一致。底板为 256×80、九宫格边距 12、PPU 100，图标为 64×64，静态文字存于 Prefab。未导入 2x、预览图或网页逻辑。
- 目标按钮使用 `UiMainButtonState` 独立驱动底板、图标和字色，关闭 Unity Button 自身过渡，不使用旧 `UiSharedButtonState` 换图。页签六态，其他系列四态；禁用优先于选中、悬停和按下。按钮图标、文字及分隔线不接收射线。新按钮文字为 UI-002 方正字体角色；现有顶栏和模块字体沿用 UI-003 配置。

## 模块数据与交互

| 区域 | 实际来源和本次接线 | 边界 |
| --- | --- | --- |
| 顶栏／底栏、自身状态 | UI-003 的 `GameplayHudFrame` 继续读当前 `GameState`／行动投影；自身姓名旁增加 `PlayerState.Score`，资源与回合数字沿用现有动态更新 | 长名字启用适配，多位数未用固定占位值模拟 |
| 对手席位 | 新 `GameplayMainModules` 在客户端优先读 `GameSession.View.Players` 的公开投影，离线／Host 回退到当前 `GameState.Players`；按席位顺序跳过本机，显示姓名、颜色、分数、手牌**数量**与已宣告城市样式**数量**，其余席位维持空态 | 客户端净化后的 `State` 不含对手暗牌 ID，但 `View.HandCardCount` 保留公开数量；不传对手卡 ID、卡面、详情或提示 |
| 手牌、弃牌、盖放 | 继续使用 `CharacterCardPanelPresenter` 与原 `CharacterHandPanel`；新增五张一页的手牌上一页／下一页，重绘时保留当前页；自身盖放区只显示本机颜色对应牌背，弃牌页仍走 UI-003 唯一页面管理 | 未把对手暗牌投到可查看控件；旧卡面操作保留 |
| 角色牌堆 | 客户端取 `GameSession.View.Decks.CharacterDeckCount`，离线／Host 取 `GameState.Decks.CharacterDeck.Count`，空堆显示 0 | 客户端净化状态不含牌堆 ID，不能从其列表长度误读为 0 |
| 企业家／合作 | 保留 UI-003 静态空槽与“暂无合作资料”空态；当前 Domain 没有独立企业家集合或合作轨道等级投影 | 不伪造人物、等级、多人色块或演示资料；待规则状态提供后接真实集合 |
| 建设旧供应板 | 未进入建设时 `BuildFacilityInteractionUiCoordinator` 隐藏临时旧 View，避免遮住新版左侧模块；原建设草稿或设施效果选择活跃时恢复旧交互层 | 保留原候选／取消／确认业务，城市板格位迁移随 UI-004 核验 |

主要行动、快速行动的 `interactable` 继续来自 `TurnActionPanelPresenter.BuildViewModel`，包括回合阶段、本机轮次、主行动额度、必选项和建设草稿。`UiMainButtonState` 在 pending 时只禁止提交；pending 解除后由正式投影重新设置合法性。底栏撤销仍不可用，特殊行动仍无独立主入口定义。

## 待 UI-004 与后续规则交付的核验

1. 部署、调度、探索、城市移动的**地图选点 → 候选 → 取消／确认 → 单次正式意图**；建设的实际设施落位／确认与相关城市映射；世界地图命中、缩放和平移边界。当前只验证新版按钮到既有正式入口及建设草稿，不能宣称这些完整行动通过。
2. 独立特殊行动入口与撤销规则能力目前不存在，保持禁用；企业家集合、合作轨道等级及多人组合色块没有规则数据，维持空态，待状态投影定义后接入。
3. 键盘／已启用手柄的正式提交与触摸设备禁用操作、联机 pending／断线后的实际恢复、超量手牌的真实对局局面，以及城市样式宣告的最终提交仍需专门实机或联机验收；当前状态驱动与七张有效卡的手牌分页测试已接线，未把组件检查说成这些流程已通过。
