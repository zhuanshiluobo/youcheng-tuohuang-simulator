# UI-003 执行顺序纠正

日期：2026-09-25。本记录只说明对任务方法的核对和文档纠正，不代替 UI-003 实施记录，也不宣称视觉问题已修复。

## 依据

- 用户指出：主界面边框尚未优先完成，素材未完整呈现就开始截图校验；希望按素材文档先搭贴图，再核对层级，最后接逻辑与截图验收。
- UI-002 [执行记录](2026-09-24_UI-002_共用组件.md)明确“共用资产可用；正式对局界面未接线”。组件样板不能当成主界面完成依据。
- 查看了当前[主界面截图](证据/UI003-SampleScene-1920x1080-actual-1920x1080.png)，并与 [Frontier 主界面预览](../../../游城拓荒/UI素材/整理版-2026-09-24/预览/FrontierUI-v3-Patch/main-idle.png)核对：已有新顶底栏，主体仍为旧桌面构图，缺少新设计中的分区框体与整体布局。
- 读取当时共享 HUD 文件：直接引用了 `topbar-bg/frame`、`bottom-bar/frame`；未直接引用 `outer-frame`、`module-frame`、`module-bg`、`paper-bg`、`header-bg`、`round-plaque`、`redzone-plaque`。此项是直接引用检查，不能单独排除嵌套资产中的间接引用；结合实际画面，足以判断整张新版主界面尚未完成。
- 当前 `Ui003VisualCapture` 使用帧计数推进捕获。固定等待与顶底栏命中检查不能证明全部必要图像已呈现，需补充实际就绪条件。

## 纠正

新增[视觉搭建优先规范](../03-视觉搭建优先与分阶段验收.md)，将 UI-003 明确分为：主界面完整视觉搭建 → 层级与适配 → 主框架交互 → 就绪后验收。主外框、所有主模块框体、背景、标题、图标和内容容器提前到 UI-003；UI-004／005 沿用视觉结构完成几何交互与数据接入。

保留现有逻辑和证据。当前不应继续用尚缺新模块的画面完成多尺寸视觉验收，应先逐区补齐素材。搭建中的少量截图用于诊断，正式验收需要完整素材、稳定布局与实际逐区查看。
