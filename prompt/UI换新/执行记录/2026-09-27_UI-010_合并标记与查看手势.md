# UI-010 合并标记与查看手势

日期：2026-09-27。承接用户最新四项调整，继续直接修改，不运行测试、验证或截图。

1. 总览卡模板与放大页的Ⅱ级 `Track limited 2` 设置 Y 偏移 `+4`，`Track limited 0` 设置 Y 偏移 `-4`。采用 Unity UI 的 RectTransform 单位；合法落点叠层跟随轨道偏移。
2. `Track reward declared` 保持2×2排列，尺寸引用Ⅰ级普通轨道的四人标记基准，避免因奖励轨道空间较大而自动放大标记。
3. 删除所有 `Track all extra`、卡外额外宣告带及相关 Catalog 安全区，回收原卡外条带空间。主界面状态表、总览、放大页使用同一投影：同一玩家、同一样式的所有宣告数量合并，位置跟随解锁行动的那次宣告；没有行动入口的样式跟随首次宣告。使用时整个数字块移动，数量保持，例如“3”从未用移到已用后仍是“3”。领域宣告记录、奖励及行动次数规则不变，拖动仍只提交一次正式行动。
4. 删除每卡放大按钮和窗口“返回总览”按钮及其字段、监听、必填校验。保留放大页：总览卡牌长按0.5秒、右键或双击查看，左键单击仍选择；放大后点按卡面／左键返回总览。滚动或拖动取消长按，释放拖动不当作点击；右键查看不再同时触发全窗口关闭。玩家标记保留自己的特殊行动拖动处理，点按返回针对卡面。

结构修改落在 `BuildInfoPanel.prefab` 的共享完整卡模板与 `CityStyleDeclarationPreviewDialog.prefab`。主界面实际 HUD 状态行继续使用 `CityStyleInteraction.DisplayMarkerArea`，由同一投影同步合并数量。原有选择草稿由原窗口保留，不通过重建页面切换详情。

后续 `optionTemplate` 空引用修复已将上述完整卡模板迁入 `CityStyleDeclarationPreviewDialog.prefab/Templates`，不再由 BuildInfoPanel 跨资产提供。今后应修改窗口内模板，详见[模板本地引用修复](2026-09-27_UI-010_卡牌模板本地引用修复.md)。

新增资产化组件 `CityStyleCardGesture`，原有查看工具及相关测试源码同步更换入口和数量预期，未运行。静态说明文字已在窗口资产中更新。半透明零值策略不在本次四项修改范围内，维持现状。
