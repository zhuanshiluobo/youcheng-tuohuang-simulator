## 分类规则

1. 一级文件夹表示一项持续任务；该任务的索引、共同约束、计划及分步提示词放在同一分类下。
2. 根目录只放分类索引和迁移记录。新增任务创建新分类，避免混入既有编号序列。
3. 保留既有说明、设计和工作记录；新要求在新任务文档中标明日期、来源及适用范围。
4. 提示词是执行说明，不代表任务已实施、场景已修改或验收已通过。实际状态必须附对应执行记录。
