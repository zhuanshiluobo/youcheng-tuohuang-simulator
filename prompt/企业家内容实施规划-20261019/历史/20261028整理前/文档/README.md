## 两条不能变的实施准则

- UI不超出文档规定的页面链路。链路无法实现功能或描述模糊时，必须征询用户；在答复前不能实施依赖该决定的页面变更。
- C#内核不实现企业家、角色牌卡面效果。Lua负责实际效果、卡面条件与顺序、专属费用／数量和规则修正；C#只提供通用执行机制。
