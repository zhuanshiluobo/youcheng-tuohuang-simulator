## 本轮改动

MoveCharacterCard保留公开apiVersion=2及原参数，执行定义升3.0.0。它只验证角色类型/语义，组织唯一公开MoveItem v4 transfer/角色profile，原changed/movedCount/movedItemIds由真实共同收据投影；父节点没有位置变化。共同步骤负责源区/控制者复验、在途使用和载物退出、订阅清理、原归属保留、真实转交/可选reveal事件，以及全部必要响应。

OperateToken保留公开apiVersion=1/operation=move等原参数和原地图业务结果，执行定义升2.0.0。执行时冻结真实源区/格位，组织唯一公开MoveItem v4 move_map_token步骤；相邻/开放地点、类型profile、控制权限及登记的附加目标限制仍由共同规则执行并在提交前复验。搬运和token.moved只在共同子节点执行一次，父结果从同一事件投影，父节点等待完整必要响应。旧专用ExecuteToken搬运/发事件算法移除；共享TokenMovementProfileRegistry规则服务保留。

恢复核验父原参数、规范稳定子身份、玩家、完整共同计划/收据和结果投影；节点、嵌套/结算/延迟响应的待执行规格、snapshot/journal均经既有通道加上Token旧定义门禁。旧角色2.2.0、Token v1及MoveItem4.7.0保存拒绝，不补写或升级原档。当前core2.1.34、MoveItem4.8.0、角色包装3.0.0、Token包装2.0.0。无生产UI、静态文案、素材、场景/预制体或生成器改动。
