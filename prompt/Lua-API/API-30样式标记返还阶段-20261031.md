# API-30 样式标记返还与专用包装阶段

对应计划4.13.2、4.13.4、6.13及API-30/31；版本恢复、文档、证据和静态目录分别对应API-04/05/06/01/33。

新增直接operation=return_city_style_marker：省略selector时取本人二级样式的合法当前标记，单一候选仍确认，不可取消、无候选失败；也支持单枚explicit及真实expectedSource。固定类型core.player_marker、本人归属、真实原供应及unordered，不接受自由目标/数量/profile/历史字段。执行时按真实样式载体、历史宣告或保留的使用轨绑定确认来源，准备/提交封存实际实例和格位，恢复不从移动后的供应重新规划。使用现有共同事务与完整收据，不另写裸位置移动。

ReturnCityStyleMarker公开参数仍为apiVersion=1/player；专用执行定义升到2.0.0，组织唯一共同MoveItem子步骤，父节点投影真实子收据为changed/markerItemId，等待必要响应。已删除专用旧选择/搬运算法，并移除UsageTracks按该专用节点名放行的旧转移分支；共同能力按真实物品/权限检查。API-31由未完成推进到部分实施，只交付该入口，不代表其他专用或内部消费者已归一化。

分数、宣告ID/设施/图案、使用轨初始化凭证、使用组收据和本轮已用记录不改写。资格及动态标记区域只按当前真实位置，返还即失去当前资格；绑定仍保留，后续换入的实际新成员可被返还，本轮已使用的组不会重置。

当前core2.1.29、MoveItem执行定义4.4.0、公开合同item.move.v4.1。旧v4执行定义（含4.3.0）沿现有门禁拒绝；旧专用v1节点及待执行/嵌套规格在snapshot/journal及领域恢复前返回city_style_marker_return_version_unsupported，原文件不改写。公开apiVersion=1仍有效；旧执行结构不保留兼容算法。
