## 保持的边界

- MoveItem只移动已确定的真实手牌；没有发出选择、伪造实例、加空分支或提高预算。
- 为单模式角色族用例选择真实非先手窗口，避免用旧可选第二模式假设解释协议3；没有修改当前玩家字段或关闭生产双发规则。
- 盖牌界面的CanCover与实际候选对应，不锁定所有手牌必定可盖；本人仍必须看到自己的私有事件，其他人仍不得看到。
- 双模式的序列化往返只是隔离续接准备，不记作Host冷恢复、断线重发或正常页面通过。
- 采集完成断言保持严格，只补FailureReason／FlowStage诊断，不把失败节点、非法起点或未完成清理当作成功。
- 既有当前角色夹具只提取共同的盖牌前初始状态构造；三席、地图、内容装配与种子71保持，不修改随机结果。
