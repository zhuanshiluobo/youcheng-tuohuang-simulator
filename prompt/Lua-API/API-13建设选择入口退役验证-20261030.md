# API-13 旧建设选择入口退役

对应[升级计划](Lua-API升级计划-20261029.md)第 3.2、4.5.4、6.5 节及 API-13；以 [API-11 唯一建设合同](API-11统一建设合同-20261030.md)与 [API-12 正式迁移](API-12正式建设迁移对照-20261030.md)为前置。core 为 2.1.10，Build 仍登记 2.0.0，新模式以 apiVersion=3、targetMode 和 facility.build.v3.1 区分。

| 条款 | 实际改动 | 保留边界 |
| --- | --- | --- |
| 3.2、4.5.4 | 移除 ChooseBuild 的 Lua 目录、白名单、generic 接受、编译目录和旧节点注册 | 只保留诊断 ID／原因 choose_build_api_retired，不设兼容转发 |
| 3.2、4.5.4 | 删除旧非实体选择执行、payment/slot 历史分支及 sourceZone 公共别名接受；选择服务只由 Build v3 调用 | SelectFacilityPanel 及同文件共用候选、来源、费用和实际建设保留；PromptParameters 的既有 sourceZone 仍供当前页面读取，不是第二套公开参数 |
| 3.2、4.5.4 | 共用退役门禁拒绝创建、编译、内存待答及所有保存规格载体的旧类型 | 不改写旧档案，不释放托管或伪造已付证明；旧直接 Build 的未受影响合同继续合法 |
| 4.5.3～4.5.4、6.5 | 26 处当前 C# 正向夹具创建真实新 Build 参数，结果／查询身份跟随统一根；新增退役矩阵、冻结模块和原始待答拒绝 | 不增加接受旧字段的夹具适配器；历史文档与原始失败 XML 保留 |
| 4.5.4、7.3 | 移除旧类型默认表现，只给选择式 Build 使用原选牌脚本；DIY 可用表移除旧推荐，当前内容身份递增 | 指定实例 Build 不套用选牌默认表现；未修改场景、预制体、静态文案或样式 |

旧名称／别名、手写和嵌套规格、冻结模块、六类快照／journal、类型化保存载体和内存待答拒绝已验证。首轮 43/43；无旧入口正式复验 82 项为 79 通过／3 失败，三项均在后续同名复验通过；边界复验 50/50，首次执行前调度修正后最终 52/52。原 XML 与修正依据见[实施记录](Lua-API升级实施记录-20261029.md)，没有覆盖首次失败。

所有验证均为隔离规则／内存页面消费者；不计正常菜单、可见独立程序、多局、视觉或联机验收。既有两项旧实体迁移失败以及 API-12 大批次发现的历史输入／无效夹具前提另行跟踪，不在本项自动关闭。

静态交付已收口：71 个公开名、81 个编译类型，1,924 行引用／1,116 组中 1,054 组分类、62 组有据排除，未分类和过期审阅均为零；固定输入指纹 `68af7bd894a48fc8d811e41030cd8108b3ac55b4edd770152f1a60ed85b4c8de`。采集器 6／6，通过可用表检查 72 行，无已退役入口推荐。详见[审计结论](API-01审计结论-20261030.md)。

原始失败追踪、隔离运行身份和逐文件条款／字节摘要位于 `Logs/LuaApiUpgrade/API-13/`。45 个曾失败全名中，40 个同名后续通过、1 个扩为双模式后通过（原全名没有通过记录）、4 个本轮前提缺口仍未关闭；加上此前 2 项兼容缺口，共 6 项待续。
