| CardVisualCatalog.IsCardDefinition | 只读已安装启用定义及活动别名的角色／设施／事件／奖赏类型，按当前Pack缓存元数据；不读图集或纹理，不调用Host实例解析器，不拆实例名或猜后缀，不脏写目录资产 |
