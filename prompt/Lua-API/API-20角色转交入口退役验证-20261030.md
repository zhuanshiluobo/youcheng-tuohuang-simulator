## 正式调用与必要查询

唯一正式调用位于[刻俄柏计谋](../../Assets/StreamingAssets/Content/core/lua/characters/infected.character.ceobe.tactic.lua)。原5／6分支仍先执行即时主要行动，只有真实completed／executed结果进入原接收者选择。回答复验另一真实玩家与本次c.source的当前控制者；用真实源区／格位及接收者唯一手牌区创建MoveCharacterCard apiVersion2，unordered、core.character_card_transfer、requiredCount1，不按卡名补选。1／2、3／4、action_completed和done顺序保持；接收者页面不变。

首轮真实Lua暴露content_zone_missing:hand：默认Lua查询只返回身份可见区域，漏掉对手手牌目标区。现仅让Global.Content返回原公开投影已有的手牌区域元数据／数量；实例集合仍使用原visible.Items，orderRevision、orderDigest和topItemId仍为空，不开放对手牌。新语义hand_destination_metadata.v1纳入活动指纹。

[刻俄柏定义](../../Assets/StreamingAssets/Content/core/character/infected.character.ceobe.json)及计谋为2.0.4，策略保持1.0.0；core2.1.16。MoveCharacterCard执行定义2.1.0、直接MoveItem共同定义3.1.0及character_move.v2.1保持API-19版本，不另建转交包装。
