新增UI用例覆盖一个真实卡面、两个原动作ID、无草稿提交、重复与过期动作拒绝、缺图保留及隐藏身份不读取。领域用例覆盖全部三张原实例分别入手／入弃、同一张卡的两个真实移动分支、实际目标区、正式可见投影及每次待答／完成冷恢复；原持续角色及额外盖放／回收用例继续通过。奖赏卡页4个隔离用例也通过。这些均为隔离组件或规则验证，不计正常游戏、当前场景或视觉验收。
