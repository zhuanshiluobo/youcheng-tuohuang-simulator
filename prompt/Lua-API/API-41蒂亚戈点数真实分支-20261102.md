## 实施与规则

主／额外点数的每个候选直接包含原实际点数效果：0发动企业特效，1替换影响力，2获得15金券，3／7升级1／2级，4沿原批次出售，5获得2源岩＋2碎片＋1铁，6放置后移动影响力。没有空分支、NoOp或只返回值的正文包装。

删除main_selected／extra_selected值→正文分派和main_reward辅助。main_completed只消费真实主分支完成结果、继续原额外条件，不再次发主收益；主分支失败仍保留原独立额外组织。点数4仍由原实际出售回执累计soldCount／revenue，完整出售结束后只组织一次额外条件，外层完成续接不再重复组织。

普通两骰的唯一其他点数仍自动确定；三骰及D07的额外点数保留原去重／不同点规则和D07可主额外同点。需要选额外点数时，先执行原两枚费用的真实Condition，再只在其condition_met回执后由Lua构造已冻结点数的真实Choice。Condition有真实费用左式，空右列表没有占位效果；未付款、放弃或费用失败均不产生额外Choice。MoveItem只移动已经确定的两枚费用实例，没有发起选择。

声望仍按原逐枚移动，独立失败不回滚成功兄弟，原唯一点数后继保持。正式随机、骰子组件、原价格、投资费用、外层D07／D08费用与使用轨道保持；无生产C#、UI、场景、预制体、布局、静态文案、素材或生成器改动。
