# API-26 标记存取迁移与旧入口退役

对应[计划](Lua-API升级计划-20261029.md)4.11.5、6.11，依赖[API-25 v4 与当前权限合同](API-25玩家标记v4与当前权限合同-20261031.md)；共同合同依据[API-29](API-29共同区域物品合同-20261030.md)。

## 已实施行为

诗怀雅从选中对手的真实供应取出一枚、返还卡上一枚，以及林的返还均使用 MoveItem v4。显式 selector/expectedSource、真实牌区、requiredCount=1，返还 destination.kind=original_supply；不生成同义包装或伪实例。对手空供应仍跳过；选择、每次至多返还一枚、原收益和后继顺序保持。林初始数量选择后的逐枚 v3 装载保留实际不足时的独立失败语义，待 API-30 统一旧形状；异客既有通用装载继续回归，LoadCardMarkers 不回流。

Host 在移动前封存真实原所有者，完整收据及单枚 originalOwner=pN 一致；Lua 核对 changed、实际 movedCount=1 及同一 movedItemIds。诗怀雅保留“返还 → 自己获得6龙门币 → 自己选择企业升级 → 原所有者在同一企业升级”的顺序，最后一枚离开时仍等待真实载体离场。UpgradeEnterpriseForPlayer 仍有效，归 API-27/28 迁移，本阶段不提前退役。

StorePlayerMarker/ReturnPlayerMarker 从公开构造、编译目录和默认注册移除，删除专用 MoveMarker 执行及 AllowsMarkerTransfer 放行。旧 store_marker/return_marker 类型通过共同退役门禁明确拒绝，包含旧名/别名、手写和嵌套规格、自注册内核、真实冻结模块、已挂接必答响应的旧父链、原始 snapshot/journal 及六类类型化保存载体。被拒绝存档不改写，合法 v4 存档保持完整收据并恢复续接。

core2.1.22；诗怀雅角色/计谋及其来源声明2.2.0，策略保持2.1.0；林角色/计谋及其来源声明2.1.0，策略保持2.0.0。实际活动 pack、能力定义、模块哈希与每局冻结内容形成身份，不覆盖旧保存版本。
