# API-35：盖放v2与角色无版本签名迁移

对应计划4.14.2、4.14.3、4.14.4及API-35，直接共同转移依据4.13/API-30～31，恢复、文档和证据对应API-04/05/06/01/33。本阶段优先实现，收缩为编译和受影响路径的定向检查，暂缓完整批量回归；不把暂缓检查写成通过。

盖放v2的独立搬运分支已移除。CharacterCoverEffectExecutor只接受显式公开v3；apiVersion=2返回character_cover_v2_contract_retired。Lua归一化、手写/别名/嵌套规格编译、内核建树、snapshot/journal及所有既有待执行规格载体恢复均拒绝。使用原始long比较版本，不能回绕为合法版本；没有apiVersion的正常内部盖牌形状保持，不全局禁用其他接口的v2。

旧CharacterLifecycleTests.AdditionalCoverBlocksOnlyNewInstanceUntilNextActionRound曾以无来源v2裸调用直接盖放，现将原构造改为退役拒绝用例；其正向阻塞/下一轮资格改由InfectedCharacterEffectsTests.AdditionalCoverV3ActualSourceBlocksOnlyNewInstanceUntilNextActionRound及既有正式赫拉格三组行为验证。实际v3具有真实赫拉格使用/激活/续接来源、acceptedTypeId、reusable=false及当前行动轮阻塞，不是只改版本数字。缪尔赛思可复用槽与正常主链盖牌仍各自保留定向检查。

铁皮人计谋将旧无版本MoveCharacterCard的sourceZone/destinationZone写法改为MoveItem v4 explicit：读取本人真实弃牌实例和手牌/弃牌区域，整体转移再按原弃牌数量依次选择原奖励，空弃牌零奖励。未新增选择页，不改费用、5金券或移动影响力分支，不使用新来源动作。原旧整数完成结果无人消费；原正向C#夹具迁移为movedCount/movedItemIds及同一实际实例断言。

MoveCharacterCard保留显式v2；无版本旧签名在Lua/编译/内核与raw/domain恢复前明确返回character_move_unversioned_signature_retired。旧自动兼容恢复和专用弃牌回手算法、无消费者的列表原地搬运方法已移除，不改写旧存档。原公开/私有转交、reveal、载物退出和必要响应仍由当前角色共同策略处理。

当前core2.1.31，铁皮人计谋定义1.3.2；MoveItem4.5.0、盖放v3包装2.0.0、MoveCharacterCard显式定义2.2.0保持。本阶段无UI代码/文案/场景/预制体修改或生成器调用。
