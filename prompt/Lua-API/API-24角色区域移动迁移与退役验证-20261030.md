## 全路径退役

移除ContentTransactionEffectExecutor中MoveCharacterCardToZone公开目录、move_character字段、reveal旧校验、注册后缀来源及独占执行分支，BoundSource继续保护其余事务。[共同门禁](../../Assets/YC/Domain/Effects/ContentPrimitiveEffectExecutor.cs)保留effect.content.transaction.move_character和character_zone_move_api_retired，仅用于明确拒绝。Lua、编译目录、默认注册、手写／嵌套规格、冻结模块、原始快照／journal、类型化六类保存载体及旧父节点的待答／已接受响应均不能执行；不改原存档，也不回滚已经提交的牌或展示事实。

22项退役用例包括Lua名称／别名／原始及嵌套4项、手写编译／自注册内核2项、六类保存载体×快照／journal12项、冻结模块2项及旧父链挂接真实展示响应2项。纯业务上下文同名不会误禁；其他自动生命周期、同玩家移动、跨玩家转交、正常盖牌和未退役事务保留。
