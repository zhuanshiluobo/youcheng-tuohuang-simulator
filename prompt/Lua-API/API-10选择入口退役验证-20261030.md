对应[升级计划](Lua-API升级计划-20261029.md)第 3.1～3.3、4.4.5、6.4 节及 API-10；前置 [API-09 逐调用迁移](API-09正式影响力选择迁移对照-20261030.md)已完成。core 当前为 2.1.7，三类基础操作的 v3 模式与 influence.selection.v3.1 持久化合同不变，合法显式 Remove v2 继续保留。

## 实际删除与拒绝

| 条款 | 改动 | 保留边界 |
| --- | --- | --- |
| 3.2.1／2、4.4.5 | 从 MoonSharpLuaRuntimeHost 构造目录、旧参数表和 generic 接受分支移除 SelectInfluence；从 LuaEffectTypeCatalog 移除旧类型 | 不改三类基础操作的公开名、字段或显式目标合同；旧名字／别名不能产生效果声明 |

| 3.3、4.4.5 | 共用流程去掉旧 operation／ownerFilter／candidateScope 字符串及 owner 去重别名分支、旧默认交互选择分支；清理不再使用的 mapQuery 入口参数 | 保留正式候选、实例／主体去重、严格移除、真实查询服务、请求归属、确认、必要响应和结果／恢复，未删共用选择能力 |
| 3.2.3／4 | 创建、编译、嵌套、执行推进及各保存规格复用现有退役门禁；内存旧待答也在回答写入前明确拒绝 | 不从 DTO 默认值补旧协议，不静默映射为新基本操作，不修改原归档；普通业务上下文中的同名文字不是可执行规格 |
| 7.3、API-05 | core 升为 2.1.7，DIY 可用表移除旧推荐，列明类型／原因；基础执行登记仍为 2.0.0 | 不为退役旧包装改变正常显式目标合同或提前发布其他计划 API |
