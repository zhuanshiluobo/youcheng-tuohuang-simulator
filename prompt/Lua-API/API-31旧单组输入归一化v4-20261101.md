# API-31 旧单组输入有限归一化为v4（2026-11-01）

对应计划4.13.1、4.13.4/API-31及API-29最终输入表；版本/原件边界对应API-04，证据/文档/目录对应API-01/05/06/33。当前core2.1.44/MoveItem4.11.0：旧MoveItem v1显式单组的有限可表达输入在Lua顶层/嵌套及C#根/子/持久化规格创建时统一生成原生v4，保存有界原参数及原/规范摘要；旧v1落盘协议和旧4.10执行定义恢复拒绝。34个不同全名最近通过，10个本轮首次失败同名闭环。API-31仍部分、API-32未完成；原7未关闭/6明确替代及正常验收限制保持。39项仍32完成、6部分、1未完成。

## 已完成的子项

新增纯输入归一化服务，先校验旧v1互斥字段，再将itemRefs映射为selector.explicit.itemIds、保留实际源/目标/插入/profile、最低数量、carrierPolicy/reveal，省略旧空slotId的未指定语义，补默认requiredCount=0。玩家编号沿旧规则解析后写成规范数字字符，兼容0001等合法旧写法但不改变实际执行者；原记录仍保留原写法及摘要。只接受通过现行v4校验且128值/深度8边界内的子集；不创建另一执行器或旧来源/轨道权限。

Lua顶层与所有嵌套编译，以及C#创建根/子节点和持久化描述均归一化。运行时节点和待执行描述保存v4、当前执行定义及ItemMoveInput记录（有界原参数、原参数摘要、规范参数摘要）。完成结果统一使用当前v4摘要/真实收据及分页，不提供旧v1结果格式投影。克隆、嵌套续接、执行及恢复复验原记录与实际规范映射；原生v4不需要旧输入记录，此记录不授予权限，也不参与公共/旁观DTO。

原v1独立移牌分支、旧轨道黑名单和无消费者旧建设放行辅助已移除。共同v4继续复用现有角色生命周期执行原语，没有按名称删除仍被共同路径调用的CharacterCardMovement.Execute。实际状态、事件、等待、生命周期、可见性和收据都由当前共同策略决定。

公开合同仍item.move.v4.1；执行定义升4.11.0，core2.1.44。已落盘旧v1节点/待执行规格及旧v4 4.10执行定义，均在snapshot/journal恢复前明确item_move_contract_version_unsupported，不借新输入服务升级原档。提供的输入记录缺字段、原参数/摘要或规范摘要失配均明确拒绝。

## 有限输入和原业务边界

旧v1空列表却requiredCount>0、最低数量超过显式数组、重复ID、超出v4范围/预算或混入其它字段不在保留子集，创建/编译时明确拒绝（item_move_legacy_input_not_representable或旧字段校验原因），不降低数量、不补假ID、不改成成功。不能宣称这些旧形状仍兼容原普通Failed。v2批次/v3 Token输入在本轮仍沿既有路径，未归一化；正式v3和内部付款标记、影响力锁、旧Host准备等仍待后续，API-31整项不关闭。

原RequiredCountRejectsWholeGroupAndConditionReward改用合法v4选择（真实手牌2枚、count=requiredCount=3），保留原手牌全不动、分数不变、insufficient_items及不发条件右式奖励断言。原重复组用保留的MoveCharacterCard v2验证相同duplicate_item_id和全零提交；未知实例/源变化仍通过v1有限归一化验证。错误类型夹具原来使用角色profile，提前被设施profile校验拒绝；现使用正确设施profile到达原destination_rejected。没有放宽或改掉原业务断言，旧v1不表示输入另有独立前置拒绝用例。

## 原始结果及限制

本轮原XML依次7/14、22/22、9/12、5/5、2/2；34个不同全名最近通过，10个曾失败全名同名闭环，不把各批相加为一次全通过。首轮7项失败涉及新夹具未回答真实Condition、创建API异常类型/字段排序，以及嵌套摘要具体错误被旧通用诊断覆盖；生产代码现保留具体摘要诊断，夹具按实际合法请求推进。原夹具回归另有3项失败，按上一节迁移后保留全部业务断言通过，原XML不改。

验证包含真实原生/归一化区域状态、事件和完整共同收据相同，完成恢复不重复；顶层/嵌套Lua、C#待执行规格与深克隆；snapshot/journal的原参数/两摘要/记录字段篡改、旧v1/旧4.10拒绝；非表示输入零物品/随机变化。额外回归真实载物退出、他人私有区拒绝、顺序/空集/补牌及上轮派遣、建设、开局供应生产者。逐例身份按当次真实产物登记，缺失列在覆盖核验中，不回填。
