## 完整性与复杂度

设有G个等价组，其中H个至少有两枚。全部语义不同的二元方案为G×(G−1)/2＋H：不同组各取首代表，同组取两枚真实代表。

不超过16种时按原顺序平铺完整成对移动。超过16种时，首组i对应其自身第二代表（若有）以及所有j>i组的首代表。各阶段方案数相加仍为同一公式，每个方案恰好一次；首组内部只有一个完整方案时，首项直接显示两枚并执行。第二枚仍有多种时才出现下一页。大组合不在Lua里构造深层或超限表，也不预建G²个移动分支；只为选中的首组构造第二阶段。

这属于源码与组合表达说明，没有执行合成库存、完整99项边界或正常游戏验收。当前库存被冻结于选择开始时，后续仍由实际移动复验；未把UI选中当作费用完成。整体可选收尾入口保持，进入原必答返还后不新增放弃或结束行动轮语义。
