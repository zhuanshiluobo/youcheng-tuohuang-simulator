## 实际问题与修复

即时特殊行动的ValidateSaved原本排除成功分发收据登记的响应，只要求一个实际业务Choice；Execute却统计全部ChildNodes。两者对“一个业务子节点”的口径不一致：如果父节点同时含有合法附加响应，恢复判读可接受，执行判读却会以immediate_special_child_invalid拒绝。此为源码上可以直接定位的不一致，本批没有运行正常局或声称取得实际故障复现。
