# API-43 明确卡牌入口缺图不退文字

对应API-43、4.16.5、4.16.6.4；必要组件夹具同步对应API-44，文档与消费者同步对应4.16.7、API-01／33、API-40。本阶段完成七处明确卡牌入口的语义固定，API-43／44整项仍部分，44项保持38完成／6部分；原39项保持37完成／2部分。

## 实施

原`ShouldUseCardPicker`除奖赏外依赖`HasCardArtwork`：全部无图时，即使调用方已经明确正在选牌或浏览牌，也会创建普通文字条目。现在由调用方声明`IsCardSelection`，在图片探测前固定原卡牌页；每个缺图候选保留原卡位与真实标签，并输出包含request／item的诊断。奖赏原诊断键保持，不生成、复制或伪造卡面。

| 入口 | 实际改动 |
| --- | --- |
| CharacterCardEffectChoiceDialog.ShowCoverSelection／ShowBuildFacilities | 原盖放和建设两入口固定卡牌语义；候选、草稿、确认及盖放缓存保持 |
| CharacterHandPanel.ShowDiscardList | 弃牌与盖放浏览固定原卡牌页；移除全体无图判断，原只读／合法可见集合和关闭行为保持 |
| CardCollectionBrowser.Show | 只读卡牌集合固定卡牌语义，不增加业务提交 |
| EntrepreneurSelectionUiCoordinator.Draw | 原企业家／选面真实卡牌固定原卡牌页 |
| GameplayExpansionUi.OpenCoveredActions | 原可用盖放角色页固定卡牌语义，原合法可用候选及使用入口保持 |
| GameplayInformationPages.ShowPile | 原非事件游戏盒卡牌页固定卡牌语义；事件独立页、可见性与原快照门禁保持 |

只编辑必要UI源码及测试；场景、预制体、布局、静态文案和素材未改，未运行界面生成器。core2.1.60／Choice3.1.0及482份内容保持；没有Lua、领域、付款或移动合同改动。通用角色／设施候选中尚未明确迁移的路径仍保留原图片判断，普通模板及其余业务仍待清理，不将本阶段写成全模板退役。

## 验证与原失败

首批[原XML](../../Logs/LuaApiUpgrade/API-43卡牌缺图不退文字续作/缺图卡页定向1.xml)为8/9；六项新缺图用例和两个既有缺图用例通过，原完整卡面／草稿用例因`-nographics`设备的4096纹理上限无法装入5400×5100正式图而失败。保留原日志、XML、逐例结果；未修改正式图片、加载器校验或该用例断言，第二批仅去掉`-nographics`使用真实GPU，同批[9/9通过](../../Logs/LuaApiUpgrade/API-43卡牌缺图不退文字续作/缺图卡页定向2.xml)。不合算成单批17/17。

新用例覆盖两个宿主的缺图选择／只读四组合，原盖放入口的真实ID、草稿及缓存，以及原弃牌入口的缺图只读；保留真实标签、无普通条目、点卡不提前提交、确认一次、陈旧回调不提交及请求不变。两个旧奖赏／单卡双去向用例也通过。CharacterHandPanel测试反射调用补齐生产已有的可选第三参数null，不改生产签名或降低断言。这些组件验证不计正常完整卡面、当前场景视觉或整局通过。
