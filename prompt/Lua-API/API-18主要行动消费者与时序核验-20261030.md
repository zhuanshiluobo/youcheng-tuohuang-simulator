# API-18 主要行动消费者、结果与时序核验

对应[计划](Lua-API升级计划-20261029.md)4.7.1～4.7.3、6.7、7.2；依赖 API-17、09、12、15。API-09／12／15 已分别迁移即时分派的影响力移动、建设和探索，本项不重新引入旧选择节点。本文记录规则隔离验证；正常独立程序、多局、页面视觉和联机仍未覆盖。

## 两个入口与结果

`GrantMainActions` 的公开参数保持 `player, amount, lockCharacterCard?, allowedActionTypes?`，默认锁牌 true；现有两处正式调用均显式 false。只增加本行动轮额度，返回整数 amount，立即续接后续效果。限制只能为空，或完整指定 build／explore／move_city 三项；并非任意行动集合。旧 grant_budget 正向夹具已迁移，旧模式拒绝；不读取剩余额度猜测来源或清零。

`ExecuteMainAction` 保持 `player, executionMode='immediate', allowedActionTypes`，无新增公开 apiVersion 参数，不接受额度参数。单个候选仍经过原选择请求；没有新增菜单、确认层、静态文案或 UI 资产。本项执行定义版本为 `1.1.0`，活动内容指纹包含该版本；它与仍保留的正常包装 `action.main.execute` 是不同节点。

即时根等待所选真实子树及必要响应。完成结果为 `{outcome, executed, actionType, actionEffectId, actionResult}`：actionEffectId 指向唯一实际挂接的子流程，actionResult 保存它的权威结果；executed 只有 outcome=completed 时为 true。取消与无目标可以完成流程清理，但分别返回 cancelled／no_legal_target，不能当作执行了行动。真实失败返回 failed，沿原失败合同处理；故障未结清时不提前完成、不重复提交、不给托管退款。

| 所选行动 | 实际生产者与结果映射 |
| --- | --- |
| build | Build v3/select/supply/auto，consumeMainAction=false；built→completed，cancelled／no_legal_target 原样交付，实际建设 ID 在 actionResult.buildEffectId |
| explore | Explore v3/select，consumeMainAction=false；completed／cancelled／no_legal_target 原样交付，实际结算 ID 在 actionResult.explorationEffectId；路费仍真实预留与结算 |
| dispatch | MoveInfluence v3/select/self/count=2；completedCount>0 才算执行，零次为 no_legal_target，不创建 SelectInfluence |
| deploy | 原基础 PlaceInfluence；changed=true 才算执行，未变化为 no_legal_target |
| move_city | 原 CityMove，consumeMainAction=false；读取真实完成结果，后续响应失败不能伪称成功 |
| special | 原即时特殊行动包装；真实授权激活子节点完成才算执行，无候选为 no_legal_target，失败不能被外包装的空结果吞掉 |

直接续接的消费者须核对 normalizedResult.outcome／executed，不能仅凭 EffectCompleted 的流程终态推断发生了行动。刻俄柏计谋的 action_completed 已按此检查，只有真实行动完成才打开原接收者选择；取消／无目标不进入成功转交续接。转交入口本身仍留 API-19／20，不提前改名或修改转交规则。

## 原始运行与范围

所有原始 XML 和日志均保留在 `Logs/LuaApiUpgrade/API-18/`；同名后续通过按完整 fullname 对照，不能覆盖首次失败。

- 首轮 9 项为 6 通过／3 失败：三个失败均为隔离后续加分探针手写规格缺字段；改用领域 GainScore 工厂。
- 既有消费者复验 33 项为 32 通过／1 失败：商业区夹具选到印刷分数 −1 的备用设施却只期望探针 +1；改为正式付费设施，并分别核对真实印刷分数与后续探针，保留原始失败。
- 完整时序复验 9／9，三项原失败全名通过。包含真实前置收益／付款、即时建设付款放置、探索响应与故障、刻俄柏成功续接和冷恢复；不是正常页面验收。
- 角色二次使用补查 2 项为 1 通过／1 失败：旧夹具把并发盖牌 CurrentPlayerId=-1 当玩家，尚未进入受测规则；沿当前本人正式请求提交后 2／2 同名通过。仅修隔离准备，不改变生产盖牌主链。
- 取消／未执行首次定位 0／2：重现旧即时根没有结果且刻俄柏仍可能进入成功续接。随后补齐本项结果合同、消费者和执行版本；复验结果单独补录，不用原来的其他通过替代。

API-11～16 原有七项未闭环及两处明确夹具替代仍独立留存；本项通过不自动关闭它们。正常菜单、可见独立程序、自然候选、多局、视觉和联机没有实际证据，继续留在 API-06。

最终补充：执行结果首轮因缺少Facilities命名空间编译失败，无XML。编译修正批次25项为21通过／4失败；补齐恢复前明确版本门禁及真实零供应、正式终身Token夹具后26项为25通过／1失败。最后旧空手接收者用例明确选择实际可达部署后，在35／35批次同名通过。原无目标／取消两个失败全名均后续通过，旧版本拒绝诊断为immediate_main_action_version_unsupported。真实特殊行动自身授予的2次额度仍保留，包装不额外发放。
