# API-15 正式探索与内部消费者迁移

对应[升级计划](Lua-API升级计划-20261029.md)第 4.6.1～4.6.3、6.6、7.3 节和 API-15；以 [API-14 合同](API-14统一探索合同-20261030.md)为前置。迁移及针对性隔离验证已完成；旧 ChooseExplore 的最终禁用留给 API-16。

## 三处正式调用

三处均从 `Effect.ChooseExplore({player=ctx.playerId})` 改为 `Effect.Explore({apiVersion=3,targetMode='select',player=ctx.playerId,consumeMainAction=false})`，不新增外层确认，也不减免路费。

| 正式正文 | 保留的流程与完成语义 |
| --- | --- |
| [载具仓库](../../Assets/StreamingAssets/Content/core/lua/facilities/remove_then_dispatch_or_explore.lua) | 保留原二选一；移除／调度分支不变，探索分支等待统一探索完整结束。取消／无目标不改为失败，真实失败不跳过后续结算 |
| [感染版梅兰德基金会二级](../../Assets/StreamingAssets/Content/core/lua/enterprises/infected.enterprise.maylander_foundation.level_2.special.lua) | 统一探索后仍执行原自身影响力移除；取消／无目标按原包装的成功续接处理。事件与必要响应、路费交付尚未结束时不先执行移除 |
| [马丁 M05](../../Assets/StreamingAssets/Content/core/lua/entrepreneurs/martin_rounds.lua) | 保留探索／两次放置的 Choice，M05.after_intro 仍在整个所选分支结束后进入一次原交换配对，不将探索根与实际结算重复计数 |

全部路径、原表达式、新表达式、实际定义／处理器／模板绑定、SHA-256 和版本字段见 `Logs/LuaApiUpgrade/API-15/逐调用迁移对照.json`。载具仓库按数量清单生成 building_039～041，清单组定义升至 1.0.1；模板未改，不无故升版。梅兰德定义及二级能力为 1.0.2，其余能力版本保持。马丁四份 rounds 定义、共享正文能力与处理器统一升至 1.2.4，原依赖模块不变。共递增 31 个实际绑定版本字段，core 为 2.1.12。

## 正常命令与内部工厂

- [正常探索命令](../../Assets/YC/Application/Gameplay/ExploreLocationCommandHandler.cs)保留当前本地地图预览与最终确认参数，提交时创建统一 explicit Explore，复验后按既有托管顺序结算，消费一次主要行动；不恢复旧的无目标 Host 开始请求。
- 同一命令处理器的赠送探索创建统一 select Explore，保留真实来源、可选目标上限、旧设施待答准入及不额外消费行动的合同。
- [即时主要行动工厂](../../Assets/YC/Domain/Effects/GenericLuaEffectExecutor.cs)的 explore 分支创建统一 select Explore，保留来源及原不耗额度语义，不加额度再扣额度。
- 内部 `effect.route_resource.select` 与封存选择／实际探索托管执行保留；原 `action.exploration.selected` 的合法内部记录与旧结算记录按原恢复边界支持。新生产命令不再创建该预选包装，DIY 不能伪造它的权威收据。

本项没有 UI 源码、场景、预制体、布局、静态文案或样式改动。旧正常命令夹具迁为当前确认后提交和缺计划拒绝；隔离规则与正常独立程序／页面／联机验收分别记录，原 XML 不覆盖。

首批 41 项为 37 通过／4 失败，4 项均在 `真实分支装配与后续身份复验/editmode-20261030_175619.xml` 的 12／12 中同名通过；该批还实际运行了三个有序并发请求合同，包括 normal_harvest。它不关闭旧独立根采集夹具的失败，也不计正常联机验收。M05 新用例只覆盖无合法探索目标后原交换续接一次；正常对局中其探索／取消／事件覆盖仍按 API-06 累积。
