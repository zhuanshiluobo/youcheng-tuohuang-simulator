## 正式迁移

## 夹具及证据边界

SupplyStop用例按实际v4 selector及同一能力/阶段定位原移牌节点，保留同一实例、立即补槽和3异铁断言。另三项旧夹具仍使用choice.skip、隐式测试Lua调用或旧Build直接回答/付款入口；改回实际角色激活、合法可选Choice的false回答及正式建设付款准备/确认。资源费用、存放牌所有权/可建资格、禁止他人建设、同名排除、收益、空载体弃牌和订阅清理断言保留。

新放弃辅助方法最初提交后未推进执行器，后续失败保留；补足执行推进后，再按实际零候选自动结束和当前付款确认入口操作，不修改业务预期掩盖差异。每次原始XML/log分别封存，不把不同源码/轮次相加成单批通过，不修改首次失败原件。

测试属于隔离规则/正式内容消费者验证，原安装内容或私有副本的实际身份按各次产物分别记载；缺少逐例身份的夹具不补造GameId或完整冻结记录。正常独立程序、菜单/建房/开局、视觉、多局和联机仍暂停/未验收，原上限99实际42的更正及后续真实99证据不回填。
