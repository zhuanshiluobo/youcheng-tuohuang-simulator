# API-31 内部明确移牌生产者迁入v4（2026-11-01）

对应计划4.13.1、4.13.4及API-31；版本/旧保存对应API-04，文档/审计/证据对应API-01/05/06/33。当前core2.1.43，共同MoveItem执行定义仍4.10.0、公开合同item.move.v4.1；建设执行定义2.2.0，来源校验1.0.6。39项保持32完成、6部分、1未完成。

## 实际改动

新增内部C#原生v4步骤工厂，统一声明transfer/explicit、真实实例、源区、目标、插入/profile及最低数量。它只创建既有共同节点，不新增Lua入口，也不维护独立搬运实现。

三类生产者改用该工厂：两人开局供应退牌（先退所选真实牌，再补原槽）；建设付款后的真实取牌暂存；角色派遣的实际牌堆候选暂存、所选入手、放弃/未选回底。原选择、数量、插入顺序、费用、独立洗牌、公开退牌事件及收益保持。

建设付款前、付款后及保存恢复原来读取旧顶层expectedSource/itemRefs，现从同一冻结v4 selector复验，并用实际暂存区重建预期规格比对完整摘要，禁止篡改实例、源区、目标、profile、数量或执行者。建设旧2.1.0节点/待执行规格按既有snapshot/journal版本门禁明确拒绝，原件不改写；公开Build v3与正常主链选择合同保持。

现存通用旧v1/2/3输入尚未整体归一化；其旧执行分支未在本阶段删除，不能把生产者迁移声称为旧输入/旧保存支持已收口。其它正式v3标记消费者包含空集/不足整笔失败和单枚独立失败语义，仍须逐条迁移；本轮没有降低requiredCount或以假ID补齐。
