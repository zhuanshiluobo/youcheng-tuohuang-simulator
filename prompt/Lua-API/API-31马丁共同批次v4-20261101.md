exchange仍是图纸置供应顶、原供应顶回图纸区的同组操作；over仍只将图纸置顶；under仍保持原顶/图纸/原下层的最终次序，原有下层不重排，无中间补槽。选色、同类判定、资源费用/放弃、后续回底/建设及必要响应未改。共享脚本绑定的四个回合定义及24处能力/处理器版本同步，定义其它字段和静态文案保持。
