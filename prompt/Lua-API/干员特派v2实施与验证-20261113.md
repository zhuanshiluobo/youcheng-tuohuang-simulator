# 干员特派 v2 实施与验证

日期：2026-11-13。当前内容版本：core 2.2.2。特派执行定义：2.1.0。

## 当前合同

Flow.DispatchOperator v2 必填 apiVersion=2、player、deckZoneId，可选 excludedReturnItemIds。基础抽牌数量读取本局合并、冻结的 SetupRecipe.OperatorDrawCount，不再传 drawCount。合法空牌堆正常完成并得 1 分；未知、越权、非干员牌堆不按空堆发分。正式 9 处 Lua 调用已迁移。

OperatorDispatchStarting 采用与候选集修正同类的纯数据前置协议，返回 `{drawCountDelta=整数}` 或 `{}`。不提供 Effect.ModifyOperatorDispatchDrawCount，也不接受手写的 effect.operator.modify_draw_count。数量调整没有效果子节点、普通事件响应树、交互页面或完成续接。

每个补丁的 drawCountDelta 范围 -99～99，所有有效来源读取同一 baseDrawCount；Host 汇总增减值后一次校验最终数量为 1～99，不按响应顺序覆盖。不写回整局配方，不消费来源使用次数。非法返回或最终越界导致特派失败，抽牌和空堆计分均未执行。

当前角色 persistent 实例、通用 abilitySources event 与 DIY ruleBindings 均使用专门返回合同。角色要求 self，且不能声明此事件的 eventResponseAttachments；DIY 使用 diy.rule_bindings.dispatch.v1，禁止 completion。入口不安装 Effect、Flow、Settlement，可读取 ctx.memory，但不允许写回 memory。查询状态与权威状态隔离。

查询完成后保存本次数量和阶段，再抽牌。恢复不重新执行已完成的查询，也不重复发分。Global.Content.FindZones 可以取得隐藏牌堆区域元数据，隐藏牌面和牌序仍不可读。

字段、示例及 JSON 登记方式已同步到设计目录的 Lua API、Event、JSON 编写文档、包体作者指南和 JSON schema。
