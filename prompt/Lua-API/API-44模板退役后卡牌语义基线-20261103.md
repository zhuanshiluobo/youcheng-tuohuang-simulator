## 首次失败与实际复验

首批原XML为19／24。五项均在-nographics的Null图形设备下读取正式facility_faces整图时，因无法保持原始分辨率被现有门禁明确拒绝；失败发生在原卡牌显示前置，不是普通模板回流。仅移除-nographics，使用实际Direct3D 11／RTX 4060 Ti复验，原24个全名全部通过。没有改断言、缩图、替换素材或放宽生产装载门禁。

两批代码、内容指纹完全相同；原XML、日志及启动参数各自保留。不把两批合称一次43／48，也不把Null设备失败改写为通过。五项同名后续通过，系列累计未处置0／历史明确替代24保持；其中四个失败全名为新记录，一个已有历史记录，失败全名总数为551。

涉及正式卡图的后续组件基线应使用有效图形设备的batchmode；纯规则基线可继续使用-nographics。这是基线启动环境的约束，不授权启动正常游戏或界面验收。
