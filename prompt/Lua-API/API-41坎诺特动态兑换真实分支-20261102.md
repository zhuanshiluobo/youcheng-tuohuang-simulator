Flow.ExchangeResource是本次动态库存表达直接所需的通用资源兑换流程，没有卡名判断。参数封闭为apiVersion=1、player、targetPlayer、resourceType、receiveResourceType、amount="all"、rate、reasonId?；资源类型必须不同，rate为1～100整数。执行到每位玩家时读取当前可用库存并冻结本次应兑换总量；各批仍用原PayResource足量复验、原付款前响应、禁止替代付款，再执行GainResource。每批最多50且单笔收益不超过100，原玩家顺序及每批先付后得保持。付款失败不生成该批收益；已结算前批不回滚。保存的批次进度、真实子付款／收益与恢复身份均复验，不重复创建或提交已完成子节点。

结果paidAmount／receivedAmount按实际提交记录报告；已经付款后遇收益容量失败，保留实际付款数，不虚报收益或changed=false。原0库存不创建付款子节点，完成实际兑换0，不能把逻辑分支替换为空列表或NoOp。
