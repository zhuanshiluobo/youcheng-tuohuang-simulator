# API-39 林的有序交易（2026-11-01）

对应计划4.15.5、6.15及[有序次数分配固定合同](API-36有序次数分配合同-20261030.md)。依赖API-37后端、API-38分配模式已交付；本轮core2.1.39，林定义及策略版本3.0.0，计谋版本/脚本/声明保持2.1.0及原字节。

## 真实内容变更

- 策略“特殊渠道”改为一个Effect.AllocateEffects，初始八项、各项上限10、共享总额10、allowEndAction=true。不按初始库存/金券筛掉可能依赖前项收益的选项，不拆成八组额度。
- 源岩/源石碎片/异铁/至纯源石出售1份分别获得3/4/5/15金券，购买1份分别支付1/2/3/13金券。保留原八项正式行文本/类型化价额、购买付款提示、卖出不可替代/买入允许合法替代，以及每笔交易的私有完成事实。只新增直接必要的剩余次数提示，未修改UI控制器/场景/预制体/素材。
- 一次选项仍是实际付款与收益组成的Condition，先完成真实付款及相关响应再获资源。完成续接只从完整allocation_result_v1的真实根Condition结果conditionMet/condition_met统计成功，分配数/尝试数/Completed不代替成交数。普通confirm后仍有成功额度时沿原合法续接打开收窄总额/单项上限的新分配；原成功交易不重放。end_action按当前队列执行完即结束，不再补弹。
- 保留原ruleCondition语义：购买页放弃为player_declined普通Failed，分配器停止尚未开始的尾项；不能为反序测试偷偷改成Completed。初始1源岩/0金券，卖后买完成后仍1源岩、净增2金券；反序首笔无可支付金券，原付款页放弃后停止尾项，资源不变。卖出不足导致的普通Condition未满足则仍是合法完成尝试，不占成功额度；新请求额度按实际成功数计算。
- 当前正式来源没有可用于本次金券购买费用的替代规则时，不能借只支持其他资源的规则免费购买；允许标志和原合法替代框架保持。实际查询资格、真实支付及既有多来源替代合同共同复验，不虚构不存在的正式金券替代来源。
- 策略/定义版本和源码hash同步；旧逐次选择在途的版本/hash/阶段与新节点分开，沿原内容身份及严格分配恢复门禁拒绝，不改写原档。保存覆盖提交前后、实际已付款、购买待答、剩余额度待续接及结束后，不重收费用或发第十一次交易。

实际场景组件验证发现完整GameStateView的文案可见投影遗漏正式分配数量行，会使林页面打不开；本轮在该原投影中仅补effect.effects.allocate/schema allocation_sequence_v1的原候选行，仍沿原权限。未改其它页面或可见性规则，InteractionRequestProjector与完整视图现在一致。
