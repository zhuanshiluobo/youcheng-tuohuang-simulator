## 测试源码迁移的边界

雷蛇六项旧裸状态缺少原生实体／城市，不能满足现行采集及下轮盖牌合同。本批改为规则隔离工厂创建真实标记、角色及初始城市，依正式生命周期放置与收尾，实际提交各自窗口的正式动作、处理删除、结束窗口后才推进后继；保留人数、零影响力、末轮、供应数量与回合结束断言。2人仍是规则隔离，不计正式地图人数覆盖。

盖牌基线按并行盖牌的实际热座授权及当前请求检查，提交期间遍历玩家快照；角色行动改用当前宿主AbilityAction候选与协议3，不拿退役的旧命令当正向入口。合同计数基线改为正式自动取得，其他测试的原私有库存配方保持；预算私有处理器版本与其正式能力版本一致，缺失的地图执行器按实际地图装配。收益与防重断言均保持，不放宽生产规则。

所有这些都是基线规则隔离。没有操作正常菜单、建房、开局或游戏页面；没有编辑UI控制器、文案资产、场景、预制体或素材，没有运行生成器。API-41按实现及规则基线交付结项，6.17中的正常显示、普通／赠送页面、断线重发等仍由API-44验收，不能据引用清零或隔离组件测试关闭。

最终静态采集1999输入、1605组／2891引用，69个公开构造／83个编译类型，211个Lua文件／687处调用；60个变化范围和1个新增共享盖牌范围已逐项审阅。API-40当前58处Lua选择、53个UI方法组、532个请求／旁证组，普通／旧执行模板0，仅两个合法付款行。测试结束后的内容树差异只有README文档；实际Lua／JSON及生产C#与core70各批一致。最后一批1436个代码文件与当前字节完全相同，482个内容文件中仅README随结项说明更新。各较早批次的测试源码差异和程序集身份分别封存，不声称最终输入整批重跑186项。
