马丁M09在上插真实结束后才查询回底候选；上插无配对仍进入回底。德克萨斯先完成12金券及其响应，再创建当前设施候选。两者在Lua中以实际Effect分支选择，明确`facility.supply.select`，复用既有供应卡牌页。供给页面的渲染资格不依赖卡面解析，不回退普通文字模板。

街区管理保留原Condition及接受／放弃；左式调用独立选择Flow，右式仍为获得1至纯源石。逻辑请求由标准Choice节点拥有，标记ID对应真实返还效果。移动包装没有补选子流程，必要生命周期／事件响应仍可独立交互。

实际规则验收发现旧宣告恢复把`ExecutionBinding`当作后续位置变化的必要证明，导致合法无绑定返还不能保存。现改核有效共同移动收据、真实位置变化及源轨道；原宣告分数、历史使用和原所有者不改写。
