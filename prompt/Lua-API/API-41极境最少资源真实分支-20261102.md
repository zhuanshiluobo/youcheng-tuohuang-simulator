## 实施及边界

极境策略只把当前并列最少的源岩／碎片／铁列为候选，每个候选直接承载原获得4资源的GainResource。删除选项字符串→收益的完成回调，正式资源标签保持；不使用空分支、NoOp或假效果包装。

通用GainResource增加显式apiVersion=2、qualification={kind="minimum_balance", resourceTypes={...}}合同。比较集合封闭为2～5种合法、无重复的资源类型，必须包含实际获得类型；缺失／未知资格、重复枚举、错误版本及额外资格字段均拒绝。编译保留完整资格，实际落账前重读目标玩家当前钱包，允许并列最少；已不最少则resource_gain_not_minimum失败且不发收益。资格没有卡牌名称判断，也不执行脚本谓词。

普通未声明资格的GainResource保持原收益，未改变GainScore、对手收益、PayResource和移动协议；MoveItem仍只是确定移动。无UI源码、场景／预制体、布局、静态文案、素材或生成器改动，正常夹具继续使用冻结core2.1.56程序，不热换。
