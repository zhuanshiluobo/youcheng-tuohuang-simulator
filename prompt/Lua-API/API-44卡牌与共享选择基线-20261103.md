## 实际结果与改动

首次原XML为14／16，两项失败均是旧测试仍要求普通文字行提交伪出售候选。生产实现按已退役合同抛出ordinary_option_row_retired，未发生错误出售或游戏业务失败。本批仅迁移测试源码，不修改生产UI、规则、包版本或资产：原PlainChoiceCannotBorrowTheSalePageByItsPromptOrCandidateText的两个参数实例明确撤销；由RetiredPlainChoiceCannotBorrowSalePageOrCreateOrdinaryRows两个实例替代。新断言保留提示键／候选文本不能赋予出售语义的边界，并验证明确拒绝、无普通行／出售控件、无命令及状态零变化。不能将旧文字提交行为记作同名通过。

复验完整XML为16／16。两个原件分别保留，不能合称单批30／32或抹去首批失败；系列累计未处置仍0，历史明确替代22→24。此前原13项处置保持12项同名通过＋1项明确替代，本批两项不混入该13项。
