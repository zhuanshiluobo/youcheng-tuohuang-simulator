直接move_map_token按API-29正式形状实施，固定单枚explicit/真实源区、destinationLocationId和adjacent profile，不接受自由目标区域、requiredCount或随机洗牌字段。Host映射真实map_tokens，复用专用TokenMovementProfileRegistry的相邻/开放/类型/控制者/附加目标限制；绑定后提交前重验。共同计划/收据绑定原始请求、实际源/目标与事件，结果有tokenItemId；公开Lua构造、编译和实际执行均覆盖。OperateToken共用规则/事件生成，但专用入口整体归一化仍属于API-31，不在本阶段宣称完成。

修正专用结果/事件读取旧查询副本造成destination仍为原区域的问题；目标现在来自真实移动后实例。此处属于4.13.2(6)/4.13.4要求的真实结果及入口等价直接必要修复，不扩展玩法权限。共同恢复验证同一事件身份/载荷及收据，不重放业务事件。

当前core2.1.28，MoveItem执行定义4.3.0，公开合同item.move.v4.1。旧v4执行定义（含4.2.0）在现有snapshot/journal、运行节点及嵌套规格门禁明确拒绝，不升级原存档。OperateToken参数/结果字段形状及v1定义保持，事件目标错误属于既有字段事实修复；core身份变化单列。

本阶段未改生产UI控制器、静态文案、场景、预制体，也未运行界面生成器。普通transfer仍不能使用地图profile绕过独立operation。cover_character、return_city_style_marker、完整建设层、全部专用/内部补槽刷新归一化、API-32矩阵及其他系列剩余事项保持未完成。39项仍为27完成/7部分/5未完成；API-29/36是合同任务。原暂停的正常独立程序、多局、视觉、联机及API-25权限变化验收未恢复。
