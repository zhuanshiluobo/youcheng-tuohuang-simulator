## 3. 自动分流、窗口和最小字段

单人解析从 sourceEvent.OperationContext.OriginMainOperationWindowId 找当前索引，核 GameId 派生身份、WindowGeneration、Open、SourceMainNodeId/ExecutionEffectId 和非终止主节点；仅主操作/收尾主窗口，AuthorizedPlayerIds 恰一位且等于真实 MainlineNodeRuntimeState.PlayerId。不能看 AvailablePlayerIds 剩一人，也不能用 Host/LocalPlayerId/UI CurrentPlayerId/ActiveTaskPlayerId。来源不足返回 false；解析不补造窗口。条件左侧按现有 Condition 祖先的 left:n 和当前子链识别，不让旧 Lua 增必填字段。

Kernel 在 Event 同一 Working 分发中核可省略声明、源牌资格和规范 Choice 的真实响应者。无法明确身份保 RequiredChild；合法异人确定后业务材料损坏则原子失败、保原物品事实，不悄悄退回自动归还。RequiredChild 仍原 AppendChildEffects。实际旁路按“建根与记录 → Adopt 同实例 → 原 body 自动挂该根 → 写实际收据”同次提交，新根 ParentEffectId 为空，与原父不建完成 blocker；内部仍必要子树和原 Choice。

业务 ID 使用 StableIdFactory.Create("deferred_response", GameId, sourceDepartureEffectId, reservedItemId, sourceCardInstanceId, abilityId)，不含 EventType、到达时间或节点总数；当前下一次真实离场有新 departure Effect ID。重复同离场 Removed/Replaced 只关联原义务，材料冲突报错。同一业务义务的多个返回 body 按原顺序组合到一个根，不能幂等丢掉后续 body。新根沿用 sequence executor，加根终止前完成钩子；不新增 DeferredResponseEffectExecutor。
