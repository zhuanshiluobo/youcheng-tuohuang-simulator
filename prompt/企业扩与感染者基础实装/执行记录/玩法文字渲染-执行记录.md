### 9.1 UI 可以立即消费的准确端口

```csharp
// namespace YC.Presentation；已有 GameplayTextView 新增：
public float MeasureSingleLineWidth(GameplayTextDocument value);
public void BindSingleLineEllipsized(GameplayTextDocument value, float maximumWidth);
```

`MeasureSingleLineWidth` 用当前配置的真实 Font、Style、同一共享图标定义/精确 Sprite 与字形测量缓存，测完整单行宽度。普通字按完整文本元素测量，正文图按源图实际长宽比和既定行高计算，并计入左右 IconSpacing；分数数字在图内部，不另加一个外部数字宽。宽度不使用字数估算、正文换行后的 preferredWidth、框宽或 BestFit 结果。测量不替换当前绑定、不改其布局、不创建可视 GameObject；null 返回 0。字号取原宿主 fontSize 或调用方已明确给定的 override，没有自动缩字。

`BindSingleLineEllipsized` 的有效上限为 `min(maximumWidth, 当前 source RectTransform.width)`，因此也跟随实际标签框布局后的宽度变化。maximumWidth 必须有限且非负，0 合法；null 文档清除绑定。短文完整显示，长文按实测宽保留最长前缀并附完整 `…`；连省略号也放不下时不画半个字符并记录诊断。硬换行及文本内部 CRLF/CR/LF 在单行模式转成实测空格，不换行；组合字符/代理对按同一 StringInfo 文本元素保留或移除。省略号按宿主 Regular/Inherit 字体和颜色实测，缺字沿既定诊断及已登记 fallback 处理，不选额外字体。

所有真实图示及分数叠数是一个布局元素，整体留下或去掉，不跳过大图后把后文挪到前面。缺图时显式 AltText 也保持一个原子，分数不会只留下半个数值；缺图诊断仍说明资产未完成。它的替代文字只取角色允许的真实字体/已登记回退，不补图。外层字号保持原值且禁用按钮 BestFit；图内叠数沿原 overlay 的内部适配政策。完整 Document 和 AltText 不被截断，tooltip/无障碍内容仍消费原文。

普通 `Bind` 继续原正文换行和宿主 BestFit 政策；同一文档从按钮模式切回普通 Bind 也会正确重绑。模式、上限变化纳入绑定判定，窗口/字体/Style/IconCatalog 变化继续触发重排。测量缓存另跟踪字体角色引用、宿主字体、Style Revision、pixelsPerUnit，避免先测宽再绑定时重复丢弃有效缓存。动态子对象仍按行片段/图示池化，不逐字创建对象。

内部纯布局新增 `GameplayTextLayout.MeasureSingleLineWidth(elements)` 和 `EllipsizeSingleLine(elements, ellipsis, maximumWidth, minimumLineHeight)`；它们只消费实测元素，不引入第二解析器。该低层输入必须已把硬换行转空格。普通 Arrange 只增加对原子 AltText 的 Text 保留，其原换行算法不变。
