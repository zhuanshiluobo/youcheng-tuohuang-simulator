## 点击与正文

公开叠层单击按原科室 ID 查看右栏完整奖励正文；三手势仍打开该科室原板。莱茵本体三手势打开带当前科室的合成详情。科室页固定板上的当前科室只读查看，不进入候选草稿；其单击显示当前科室完整正文，三手势打开该科室原板。固定莱茵本体和原详情按钮打开合成详情。

共用 EnterpriseDepartmentOverlayView 只绑定贴图、有效性守卫和查看回调，复用 CardPickerCardButton 的右键、双击、长按。放大页叠层不接收射线，由原 Details Return Surface 单击返回；保留草稿、滚动位置与焦点，不提交规则。刷新当前关系时更新合成详情；被移除的旧科室查看必须失效。

科室奖励 effect 行的既有回调保持；叠层不生成奖励选择目标。正式企业特效仍仅来自 Kind == special，科室 2—5 级奖励不得成为可选企业特效。
