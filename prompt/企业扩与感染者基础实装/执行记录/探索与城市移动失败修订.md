## 已确认问题与修订范围

1. `Assets/YC/Infrastructure/Lua/ActiveContentCatalogBuilder.cs` 按 `PlayerCount != 4` 裁掉四人事件牌；`Assets/YC/Domain/Cards/EventDeckService.cs` 的旧入口也按人数裁牌。三名玩家选四人地图会得到绿 5 / 黄 8 / 红 5，应按四人地图保留绿 6 / 黄 10 / 红 6。三人地图保持绿 5 / 黄 8 / 红 5。只改事件配方依据，干员抽牌等人数规则不随之改变。
2. `Assets/YC/Application/Gameplay/MoveCityCommandHandler.cs` 仅判断执行报告的 Faulted，没有判断本次移动节点的业务失败，因而可能误报已完成。应消费本次执行已有结果，不重新校验整个流程。
3. 快速城市移动高亮只筛邻接、占用和红区，未揭示目标的事件牌资格由 Host 执行时判断。牌池被错误裁减后，可能出现可选点被 Host 拒绝且错误报完成；需用已揭示/未揭示目标作对照，不先认定存在额外移动内核问题。
4. UI 地图传递链及探索命令提交未发现额外修点；禁止在 UI 补牌、重写连通算法或扩大可选目标。
