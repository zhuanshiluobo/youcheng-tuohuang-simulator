## 结论与实际来源

实际入口仍是 `Assets/Scenes/StartScene.unity` 的 `Start Menu` 实例，房间来自 `Assets/YC/Presentation/Prefabs/StartMenu/StartMenuRoot.prefab` 的 `Waiting Room Panel`。磁盘场景对房间子树没有覆盖，因此建议增量修改源 Prefab，不改场景。已读取当前 View、按钮绑定和 `Room-UI-v1.1-VerticalMaps-Guide.md`；以下结论针对磁盘资产，不代表读取过编辑器未保存内容。

横向溢出的原因是 `RoomBodyContent` 固定为 1888×912、成员区固定为 1004×912、设置区固定为 872×912，主体 ScrollRect 同时开启横向滚动。成员座位内部同样采用固定宽度与绝对位置。不能仅隐藏滚条，必须同时让内容宽度跟随 Viewport，并让成员区及座位内容重排。

## 布局参数与接口

### 主体：设置区固定，成员区承担宽度变化

保留当前 CanvasScaler（参考 1920×1080、按高度匹配）。下列宽度均为 Canvas 逻辑单位，不直接按 Screen.width 判断断点。

设 Viewport 实际宽为 C；模块间隙为 12，设置宽从实际 Rect 读取（当前 872）。并排时 `成员宽 M = C - 设置宽 - 12`，设置 x 为 `M + 12`。Content 宽始终等于 C，高为两模块实际高度的较大值。成员外边距左右 12、上下 10，标题高 50，标题到 Seat List 间距 10，座位间距 8；上述值均保存在 Prefab 检查器配置。

右侧常驻预留 20 宽滚条通道，避免竖滚条压到固定设置区。因此 1920×1080 下成员宽由 1004 变为 984；这是本方案需要一并审核的可见变化。内容先正确收宽，再关闭横滚，水平偏移始终为零。

主体组件通过标准布局过程设定两模块的宽度/位置并报告 preferredHeight；成员区和 Seat List 的原生纵向布局消费座位 preferredHeight。每个轴仅有一个布局拥有者，ContentSizeFitter 仅负责主体高度，不与主体布局争夺宽度。座位变高时由主体纵滚保证末座和设置可达。

### 座位：先重排，再在宽屏放大

座位可用宽 `S=M-24`。正常座位最小高度 202。保留头像、颜色条等装饰比例；Frame/Header 横向伸展，名字给房主徽标留出空间。状态与邀请提示按真实文字测高，不能与按钮重叠。

四管理按钮基准为 154×50，列间距 12、行间距 14；其顺序保持现有阅读顺序：邀请、关闭、本地玩家、机器人。换位置、移除、开放按钮各为 178×50。

右侧操作区可用宽 `A = S - 434`；434 来自左边距 20、头像 136、头像后间隔 22、最小状态区 220、操作前间隔 16、右边距 20。配置值应序列化，不散落硬编码到 View。

| 条件 | 布局与倍率 |
| --- | --- |
| A ≥ 652（4×154+3×12） | 四管理按钮横排；`s=min(A/652, 1.25, 可用高度/50)`，不低于 1。 |
| 320 ≤ A < 652 | 原有右侧两行两列；s=1。 |
| A < 320 | 操作区移到信息区下方；按座位全宽减两侧 20 判断两列或一列，s=1。信息区中头像旁不足 220 宽时，状态文字再移到头像下方，座位随内容增高。 |

七类按钮根统一设置 `localScale=(s,s,1)`，包括当前隐藏的按钮；保留 154/178 的基础尺寸差异。字体、图标、背景和点击范围一起缩放。倍率只由座位宽及同一四按钮基准得出，不能因某座仅显示换位置/移除就另算倍率，也不能累乘上一帧 scale。按钮原监听、interactable 判定和热座业务不变，机器人仍保持未实现状态。

两个新组件只接收序列化 Rect/Text 引用与布局参数。View 在 Render 末尾调用主体的 `RefreshContentLayout()`；主体比较四座文本/可见状态摘要，有变化才标记布局。宽度变化由布局回调处理。不加 Update 轮询、每帧遍历或强制同步布局重建；不改现有命令调用链。

### 极窄边界与预测

建议 `minimumMemberWidth=384`。当 C < 1268（384+12+872）时，成员区与设置区改为上下排列；设置仍为 872×912，仅整体位置改变。此兜底是待根审核的方案项。若 C < 872，固定设置尺寸与完全无横向溢出不能同时满足；应由根明确最小支持宽高比，或另行授权设置适配。本方案不擅自改变 ProjectSettings、裁切设置内容或缩放设置。
