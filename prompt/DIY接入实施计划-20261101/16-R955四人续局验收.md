# R955 四人续局验收记录

本记录用于原房主及三名原席位玩家在不同电脑上验证 R955；隔离程序集恢复与本机夹具结果不能代替本项。

## 测试前

- 四人使用同一份 [R955 安装包](../../Builds/SaveRecoveryInstallerR4-20261114/游城拓荒-0.5.0-alpha-R955-Windows64-安装包.exe)，SHA256 为 `8e2bccd4f44b5a63140f58eefe1d0160c7d88e2908d8af6b4034381c7e9dafc8`。该包不包含测试 DIY 内容。
- 本次迁移的对局 ID 为 `52a6ef35b608403bb1896a66566fdc03`，第 7 回合，企业家模式，启用 core、企业和感染者扩展，未锁定独立 DIY 包。房主使用原席位和对应的 Steam 身份从存档建房。
- 迁移完成时 `auto-2.json` 的 SHA256 为 `91c84b88819675cc81c0e729b5ea232e99f6eb41ced42610a4384dce9434b857`。后续正常游玩可能改写自动存档；测试前核对对局 ID 和回合，不能仅按槽位名称认定是同一局。[已验证的 R955 隔离副本](../../TestResults/SaveRecoveryReleaseR4-20261114/migration/仅供诊断-未替换-迁移候选.json)保留在项目内；旧 R954 原件有单独备份。
- 本机发行程序集读取、恢复及准备建房约 29.3 秒，未包含实际 Steam 建房与跨机发送，不作为其他电脑耗时保证。

## 验收步骤

1. 房主从正确的存档创建房间，记录点击到房间可用的耗时和发送进度；如失败保留提示及日志。
2. 四位玩家按原 Steam 身份加入原席位并准备，确认第 7 回合、资源和可见状态一致；蓝色玩家的第五号企业家牌上应保留两枚标记。
3. 由当前玩家处理本人实际可见的待选，并正常推进至少一轮合法行动；确认各端同步且未重复奖励。
4. 另行记录在线时从设置页点击“重新连接”的结果。设置页打开时可能收起当前选择，关闭设置后可通过“展开”恢复；若无法恢复，保留实际画面和各端日志。
5. 在不影响正式对局的隔离测试房间或存档副本中，分别记录非房主实际断线后的自动恢复，以及确实点击设置页按钮后的主动重连。若自动重连已完成，不把它算成掉线后按钮重连；未发生 60 秒超时也不算超时重试已验证。
6. 如需验证 DIY 跨机一致性，另行让各端安装相同的已授权内容，记录包 ID、版本、内容哈希和房间配置；缺包、不同版本和同版本不同内容的拒绝分别记录。
