# 顶栏行动玩家提示

更新：2026-09-28。

## 显示规则

- 当前行动玩家读取 `GameState.CurrentPlayerId`，通过 `FindPlayer` 获取玩家名字和颜色。其他玩家参与响应交互时，不把响应者误作当前回合玩家。
- 本机回合显示预制体配置的 `localTurnText`，目前为“轮到你行动”，使用 Text 原始颜色。
- 他人回合显示 `otherPlayerTurnFormat` 格式化后的玩家名字，目前为“{0}正在行动”。整段文字通过 `UiTheme.GetPlayerColor` 使用与地图玩家标记一致的配色。
- 玩家名字为空或只有空白时，使用 `unnamedPlayerFormat`，目前为“玩家{0}”，参数为玩家 ID。
- 当前行动玩家不存在时显示 `waitingTurnText`，并恢复原始颜色。切回本机同样恢复原色，避免上一位玩家的颜色残留。
- 使用汉仪粗黑字体资源，`FontStyle` 保持 Normal；不使用合成加粗。关闭该 Text 的富文本解析，玩家名字不会被解释成标签。
- 顶栏文字框保持原布局，字号以 20 为上限、12 为下限自动适配，避免“红色玩家正在行动”等提示被截字。

## 资产与代码

- 源预制体：`Assets/YC/Presentation/Prefabs/Gameplay/GameplayInteractionHud.prefab`，通过 `GameplayHudFrame.turnTagText` 引用顶栏文字。
- 文案格式序列化在 `GameplayHudFrame` 组件中；编辑器中的字体、字号和布局由预制体负责。
- 动态更新：`Assets/YC/Presentation/GameplayHudFrame.cs` 的 `Refresh`。
- 本轮修改应用于源预制体。`SampleScene` 和 `ThreePlayerScene` 没有覆盖该文字的字体及新增文案格式。
