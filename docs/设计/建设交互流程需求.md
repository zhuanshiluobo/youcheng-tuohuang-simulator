# 建设拖放交互目标

> 文档性质：未来体验改造目标，不是当前实现说明。当前版本使用设施选择、支付方式与强制待选弹窗，并保留设施卡双击详情；下述拖放、聚焦和本地虚影流程尚未落地。当前事实以 `docs/概览/项目总览.md` 为准。

## 1. 目标

建设属于当前玩家的一次主要行动。交互需要满足：

- 所有玩家可看到并预览设施供应区。
- 每位玩家只能操作自己的城市面板。
- 当前玩家从选择卡牌到正式建造不超过三步，不包括最终确认。
- 最终确认前的拖动、预选、支付选择均为当前玩家本地状态。
- 其他玩家直到建设确认成功前，不看到任何建设中间动作。

## 2. 设施供应区与预览

设施供应区是所有玩家共享的可见信息。

- 所有玩家可以点击设施供应区中的设施卡查看完整图片、名称、费用、分数和效果。
- 非当前玩家只能预览，不能拖动或选择。
- 当前玩家也可以在拖动前点击卡牌预览。
- 点击卡牌表示预览；拖动卡牌表示开始选择建设。
- 不使用双击承担预览功能。

## 3. 建设流程

```text
点击【建设】
→ 拖动设施卡到自己面板的合法槽位
→ 选择支付方式
→ 最终确认建设
```

其中前三步为建设流程，最终确认属于提交动作，不计入三步限制。

## 4. 进入建设

当前玩家点击主要行动中的【建设】后：

- 当前玩家进入本地建设模式。
- 当前玩家可以操作自己的城市面板。
- 设施供应区保持原样。
- 其他玩家界面不发生变化。
- 不能建设的卡牌可以置灰，并显示不可用原因。

## 5. 拖动卡牌

当前玩家按住设施供应区中的设施卡，拖向自己的城市面板。

拖动过程中：

- 只有当前玩家看到拖动卡牌。
- 自己面板上的合法槽位高亮。
- 非法槽位不高亮或显示禁止标识。
- 卡牌尚未从设施供应区正式移除。
- 其他玩家看不到拖动过程。

### 放置到非法位置

- 卡牌回到设施供应区原位置。
- 不弹出支付界面。
- 不修改任何共享状态。
- 当前玩家可以重新拖动。

### 放置到合法位置

- 当前玩家进入建设聚焦状态。
- 目标槽位和卡牌按原比例放大显示。
- 卡牌显示在目标槽位附近。
- 卡面费用区域显示支付提示。
- 不立即提交建设。
- 不同步给其他玩家。

## 6. 建设聚焦状态

建设聚焦状态只对当前玩家显示，包含：

- 放大的设施卡牌。
- 完整卡牌图片、费用、分数和效果。
- 当前目标建设槽位。
- 可用支付方式。

支付提示可以直接放在卡牌费用区域或卡牌下方：

```text
需要：源岩 ×2、异铁 ×1

[资源支付] [金券支付]
```

支付选项：

- 不满足条件的方式置灰并显示原因。
- 点击支付方式只记录本地预选。
- 不立即扣除资源。
- 不立即同步给其他玩家。

## 7. Esc、重新拖动与取消

### Esc

按 Esc 时：

```text
建设聚焦状态 → 缩回本地虚影状态
```

Esc 只退出放大聚焦，不等于取消建设。卡牌仍处于当前玩家本地预选状态。

### 重新拖动

本地虚影旁保留可拖动状态。当前玩家可以把虚影重新拖到其他合法槽位：

- 旧目标槽位取消高亮。
- 新目标槽位成为预选目标。
- 重新进入建设聚焦状态。
- 不增加建设流程步骤。

### 彻底取消

虚影旁显示明确的 `× 取消建设` 按钮。

点击后：

- 清除本地预选卡牌和目标槽位。
- 返回普通行动界面。
- 设施供应区保持原样。
- 不提交命令。
- 不消耗主要行动。

右键可以作为辅助取消方式，但不能取代明确的取消按钮。

## 8. 最终确认

选择支付方式后显示最终确认摘要：

```text
设施：XXX
建设位置：第 X 格
支付方式：资源 / 金券
支付内容：XXX
获得分数：XXX
建成效果：XXX

[返回修改] [确认建设]
```

### 返回修改

- 返回支付方式选择，或允许重新拖动目标槽位。
- 仍然只修改当前玩家本地状态。
- 不同步给其他玩家。

### 确认建设

点击后才向规则层提交正式建设命令。

## 9. 确认时的最终校验

正式提交时重新检查：

- 当前仍是该玩家的行动。
- 当前阶段仍允许建设。
- 当前玩家仍有可用的主要行动预算。
- 卡牌仍在设施供应区。
- 目标槽位仍然合法且未被占用。
- 设施唯一性条件仍满足。
- 资源或金券仍然足够。

## 10. 确认成功后的同步

确认成功后一次性更新共享状态：

- 从设施供应区移除该卡。
- 若设施卡牌堆仍有牌，从中抽牌补充设施供应区至 6 张。
- 在当前玩家目标槽位放置设施。
- 扣除资源或金券。
- 应用建成奖励、效果和得分。
- 标记当前玩家主要行动已完成。
- 同步所有玩家界面。
- 关闭当前玩家建设界面。
- 提示当前玩家点击【结束行动】。

其他玩家只有在此时才看到建设结果。

## 11. 确认失败

如果最终校验失败：

- 不扣除资源。
- 不移除公共卡牌。
- 不放置设施。
- 不改变主要行动状态。
- 当前玩家保留在建设界面。
- 显示失败原因。
- 允许返回修改或取消。

## 12. 状态边界

```text
公共共享状态：
设施供应区、玩家正式设施、资源、主要行动完成状态

当前玩家本地状态：
拖动中的卡牌、预选槽位、放大卡牌、支付方式预选、确认摘要
```

最终确认之前，所有建设中间状态都属于当前玩家本地预览；最终确认成功后才转为共享游戏状态。
