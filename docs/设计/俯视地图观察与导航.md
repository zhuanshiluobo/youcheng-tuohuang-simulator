# 俯视地图观察与导航

更新：2026-09-30。

## 观察范围

主界面 `Map Region` 继续由原布局分配最大地图区域。`Map Viewport` 及其子物体保持原布局，不再跟随缩放移动或改变尺寸。独立的空节点 `Map Visible Bounds` 表示实际相机开口，仅用于同步背景填充，不承载边框、标题等可见物体。

初始视图保持地图铺满最大开口。继续缩小时，不再以“视口不能超过地图的一条边”作为缩小终点：保持另一轴不变，居中收缩多余的一轴，直到整张地图可见。最终下限由地图实际尺寸和 UI 可用区域的宽高比计算。放大时按相反顺序恢复开口，恢复至最大区域后继续放大地图。

相机根据裁剪高度同步调整视场角，保证收缩观察框时地图仍持续缩小，不会把裁剪后的画面再次拉伸。拖动边界始终采用地图本身，缩到全图后锁定中心，不允许拖出地图边缘。

四块既有 `Map Backdrop` 和 `UiMapSurroundLayout` 读取实际开口，沿用主界面原背景素材填充新增空缺。相机输入和地图命中共用实际开口，边框与标题保持原位，空白补背景区域不作为可点击地图。

## 输入

- 滚轮步长从原始 0.1 调到 0.18（1.8 倍），在地图范围内且未被平面 HUD 遮挡时缩放；保留平滑过渡和鼠标所在地图点的锚定。
- 左键按住移动超过 EventSystem 拖动阈值后可直接平移地图；右键拖动继续可用。移入平面 HUD 或离开地图时停止本次拖动。
- 单指拖动使用同一条平移路径。双指距离比控制缩放，同时支持双指中心移动；跟踪 fingerId，避免触点顺序变化导致跳动。
- 双指手势结束后等待全部手指释放，避免剩余一指被误作地图点击。触摸期间不再重复读取模拟鼠标事件。
- 拖动及双指操作会抑制同帧与紧接下一帧的地图点击。地图空白点击取消确认改为释放时判断，避免按下准备拖动时就取消位置选择。
- 聚焦丢失、组件停用或地图隐藏时结束拖动。已有地图组件的鼠标后备点击改在释放时触发，经过相同地图输入守卫。

## 资产与代码

- `MapView.prefab`：滚轮步长参数。
- `GameplayInteractionHud.prefab`：`Map Viewport` 保持固定，新增独立的 `Map Visible Bounds` 跟随实际观察范围；相关引用应用于源预制体。
- `MapDisplayController`：动态缩小下限、视口、鼠标和触摸导航。
- `MapCameraGeometry`：开口裁剪计算。
- `GameplayHudFrame`：将相机开口同步到 UI 和背景。
- `TabletopPointerClassifier`、地图点击组件及确认取消入口：防止拖动误触。
