# 特殊行动的选择执行条目

更新：2026-09-28。

- 修改来源为 `EffectDialogShell.prefab` 内新增的 `Execution Option Row Template`。特殊行动使用该模板，普通选项继续使用原 `Option Row Template`；没有调用生成器或覆盖场景。
- `EffectDialogOption` 分别传入来源名称与描述；特殊行动来源为规则投影的 `Name`，描述包含规则说明以及当前警告或不可用原因，不再将来源与说明拼成一个多行文本。
- 来源文本位于最左侧，使用字体角色 Emphasis 对应的 `HanYiCuHeiJian-1.ttf`，FontStyle 为 Normal，不使用伪加粗。来源与描述字号沿用模板配置，两者顶部对齐，左右文本框之间布局间距为 0。
- 右侧描述占用剩余宽度，正文使用 Regular 字体，数字使用 EffectNumber 对应的 `Novecento NarrowBold.otf`。描述按字换行、连续数字保持同段，显式换行保留；不再把数字前的一整段长说明作为不可拆分布局项。
- 条目保留原底板、选中反馈和点击选择后确认执行的逻辑。内容增高时行高随内容变化，源模板保留原最小高度。
