# 后续扩展目标

本文件已去重，扩展方向统一维护在：

- `../项目总览.md`

## 扩展原则

扩展目标不进入当前 MVP 阻塞链路。优先级始终是：

1. 基础版规则闭环。
2. 日志、回放和测试。
3. Debug 或最小热座操作。
4. 正式 UI 和表现增强。

## 扩展方向

### 完整桌面 UI

在 Domain 和主要行动稳定后，补地图热点、玩家面板、行动面板、费用预览、非法原因和日志面板。

### AI 玩家

AI 必须和 UI 一样通过命令系统操作，不能绕过规则校验。

### 联机同步

依赖确定性规则核心、统一 seed、命令可序列化和回放稳定。

### 企业扩展版

通过 `RuleSet.Basic` 和 `RuleSet.EnterpriseExpansion` 接入，不能污染基础版流程。

### 动画、音效和引导

由 `GameEvent` 驱动表现，不能反向修改规则状态。
