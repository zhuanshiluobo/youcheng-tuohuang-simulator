## 维护规则

- 当前状态只在项目总览和当前工作总结中维护，不再生成“总集”或重复快照。
- 设计文档写稳定约束和目标；阶段性验证结果写入日期工作记录。
- 历史记录不作为当前实现说明，不因方案过时而改写其原始结论；索引负责标注替代关系。
- 移动或删除文档后，同步更新本索引、根 `README.md` 和受影响的交叉引用。
- 规则、牌面和地图数值若与原始材料冲突，以原始规则书、卡图或地图资料为准，并补充校验记录。
