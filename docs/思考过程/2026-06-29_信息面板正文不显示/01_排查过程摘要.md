# 信息面板正文不显示排查过程摘要

日期：2026-06-29

## 问题现象

- 左侧信息面板展开后，模块标题、行底纹、提示卡图片可见。
- `玩家概览`、`资源状态`、`城市与行动` 的行内正文长期不显示。
- 早期诊断显示 `Text.text`、颜色、字体、RectTransform 均存在，且后续 `CanvasRenderer.cull=False`，但画面仍无正文像素。

## 排查证据

- 通过 `UiDiagnosticLog` 导出运行时 JSON，确认正文 `Text` 已创建并处于激活状态。
- 最终关键诊断来自 exe 运行时导出的文本状态：
  - `text="玩家：Player 1"`
  - `font=NotoSansCJKsc-Regular`
  - `fontTexture=256x256`
  - `cull=False`
  - `preferredHeight≈19.87`
  - `rect.height=18`
  - `vertices=0`
- 该证据说明不是数据缺失、字体为空、颜色透明或 cull 裁剪，而是 UGUI 没有为正文生成可绘制顶点。

## 最终根因

正文行高为 `18`，但当前字体和字号下 `Text.preferredHeight` 约为 `19.87`。同时正文 `Text.verticalOverflow` 使用 `Truncate`，UGUI 在高度不足时直接裁掉整行文本，导致 `cachedTextGenerator.vertexCount=0`，表现为“所有文字数据都存在但完全不显示”。

## 修复方案

- 将信息面板正文行高从 `18` 调整到 `22`，保证能容纳当前 CJK 字体字号。
- 将正文 `Text.verticalOverflow` 调整为 `Overflow`，避免高度边界导致整行顶点生成失败。
- 保留展开完成后的文字刷新逻辑，用于稳定重建字体材质、文字顶点和 Canvas 状态。
- 将行内文字改为纯文本 `标签：值`，避免富文本路径干扰正文排查。
- 将正文 `Text` 挂到模块内容层并显式定位，保证行底纹与正文绘制层级清晰。

## 相关修正

- 开始界面按钮顺序恢复为顶部 `单机开始`、中间 `创建房间`、底部 `加入房间`，保证自动验收脚本能按用户流程点击单机开始。
- 本地构建输出名改为 `tuohuang.exe`，避免 Unity 批处理在中文 exe 文件名上出现日志编码和输出定位不稳定。
- 新增的截图能力当前位于 `tools/tests/Capture-InfoPanelSmoke.ps1`，用于启动本地 exe、点击单机开始、展开信息面板、截图并关闭游戏进程。
