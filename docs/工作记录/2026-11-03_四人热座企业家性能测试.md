# 四人热座企业家性能测试（2026-11-03）

用户要求：热座企业家四人局，逐步监控内存占用、内存净变化和操作耗时，目标是内存不显著增长、每次操作小于10秒。本轮禁止使用 computer-use。当前结论：**原运行版本不达标，新修复尚在正常流程复测；没有完整八回合通过证据。**

- 使用可见独立开发包，沿原菜单、建房、开局、实际可见候选及合法控件指针/Raycast流程；没有注入牌、资源、随机结果或状态。

- 游戏内每次真实指针回调、地图确认与命令分别写 begin/end；进程外每秒读取系统工作集及私有提交量。没有主动GC。
- `DeltaManaged`是托管使用净变化，不能称为分配量。工作集、私有提交量、托管使用量不得混用。命令嵌套于UI回调，不把二者耗时相加。UI包含正常同步、取证及0.65秒夹具等待。
- 每个包有独立构建输入清单、实际程序集身份、场景及预制体哈希。没有调用界面生成器或覆盖界面资产；正在运行的包没有热换。
