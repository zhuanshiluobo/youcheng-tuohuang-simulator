# 2026-06-21 四人第四回合构建验证记录

## 背景

在修复联机第二回合推进和客户端无效 `PendingChoice` 后，需要重新构建本地模拟器，并验证四人局可以稳定推进到第 4 回合。同时检查四人地图红区开放规则和底部回合栏显示是否与权威 `GameState.Round` 同步。

## 已完成

- 新增 `RoundTrackRule`，将“游戏状态回合数到回合栏索引”的纯规则放入 Domain 层。
- `RoundTrackerController` 改为调用 `RoundTrackRule.GetRoundIndex(state)`，避免 UI 回合栏逻辑和规则测试各自维护一份映射。
- 新增 `MultiplayerLaunchRegressionTests.HostLaunch_FourPlayers_AdvancesToRound4AndSynchronizesRedZoneAndRoundTrack`：
  - 四人座位按 `1,2,3,4` 入场。
  - 两个行动轮完整推进为一个回合。
  - 推进到第 3 回合时断言四人图红区仍关闭。
  - 推进到第 4 回合时断言状态为 `ActionRound1`、`ActionRound == 1`、`CurrentPlayerId == 1`。
  - 第 4 回合断言四人图所有红区地块均开放。
  - 每次推进后断言 `RoundTrackRule.GetRoundIndex(state)` 与当前 `Round` 同步。
- 新增 `LocalhostBuildMenu.BuildLocalhost`，提供命令行和菜单可复用的本地 Windows 64 位构建入口。
