# 2026-06-22 开始界面外部链接书签按钮记录

## 背景

开始界面需要在左下角提供两个外部入口：

- 鹰角网络官方网站：`https://ak.hypergryph.com/boardgame_nomadcity`
- PRTS Wiki 页面：`https://prts.wiki/w/%E6%B8%B8%E5%9F%8E%E6%8B%93%E8%8D%92%EF%BC%9A%E9%93%B8%E5%9F%BA%E8%80%85`

交互要求是常态显示为书签标志，鼠标移入时向右延长并显示提示文案。

## 已完成

- 修改 `Assets/YC/Presentation/StartMenuController.cs`。
- 在 `BuildMenu()` 生成封面后、主菜单按钮前创建左下角外部链接按钮。
- 新增两个链接按钮：
  - 上方书签：标记“官”，悬停展开显示“官方网站”，点击调用 `Application.OpenURL()` 打开鹰角官方页面。
  - 下方书签：标记“W”，悬停展开显示“进入wiki”，点击调用 `Application.OpenURL()` 打开 PRTS Wiki 页面。
- 书签图形通过运行时生成 `Sprite`，未新增外部图片资源。
- 悬停展开逻辑通过内嵌 `BookmarkLinkHover` 组件处理：
  - `IPointerEnterHandler` / `IPointerExitHandler` 切换展开目标宽度。
  - `Update()` 使用 `Time.unscaledDeltaTime` 平滑插值宽度。
  - 展开背景与提示文字分别用 `CanvasGroup` 渐显。

## UI 口径

- 两个按钮锚定在开始界面封面框左下角。
- 默认只露出书签形状，避免遮挡开始页主视觉和中部主菜单。
- 悬停时向右展开，不改变主菜单按钮布局。
- 按钮配色沿用开始菜单深棕底、金色描边和金色文字。
