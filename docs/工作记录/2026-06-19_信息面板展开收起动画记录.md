# 2026-06-19 信息面板展开收起动画记录

## 背景

用户希望左侧信息面板在点击展开时从左侧平滑推出，点击收起时平滑收回。实现方式指定使用普通 `Mathf.Lerp(current, target, Time.deltaTime * speed)`，不要求严格匀速。

## 已完成

- 在 `ExpandableInfoPanel` 中新增面板动画参数：
  - `panelLerpSpeed`：控制宽度靠近目标值的速度，默认 `10f`。
  - `panelSnapThreshold`：控制接近目标宽度时的吸附阈值，默认 `0.5f`。
- 新增动画状态：
  - `targetPanelWidth`：展开目标为 `ExpandedWidth`，收起目标为 `CollapsedWidth`。
  - `isAnimating`：控制 `Update()` 是否逐帧推进动画。
  - `pendingExpandedState`：记录当前动画最终是展开还是收起。
- 将原本瞬时设置宽度的 `SetExpanded()` 改为只设置目标宽度并启动动画。
- 新增 `Update()`，每帧用 `Mathf.Lerp(currentWidth, targetPanelWidth, Time.deltaTime * panelLerpSpeed)` 更新面板宽度。
- 接近目标宽度后直接吸附到目标值并停止动画，避免 Lerp 无限趋近导致动画无法结束。
- 展开时先启用 `contentArea`，避免推出过程中内容缺失；收起时等动画完成后再隐藏 `contentArea`。
- 初始化改为 `SetExpandedImmediate(false)`，避免进入场景时播放一次收起动画。

## 影响范围

- 影响对象仅限左侧 `ExpandableInfoPanel`。
- 面板仍通过改变 `RectTransform` 宽度实现展开/收起，左侧锚点和现有布局结构不变。
- 不改变信息面板数据刷新、模块折叠、滚动区域、玩家资源显示等业务逻辑。
