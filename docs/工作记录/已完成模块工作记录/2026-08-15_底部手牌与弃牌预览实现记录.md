# 2026-08-15 底部手牌与弃牌预览实现记录

## 1. 目标与结果

本次把角色手牌从信息面板职责中独立出来，完成底部手牌预制体、阶段化扇形布局、本地拖动排序、角色牌盖放拖动、弃牌按钮和手牌/弃牌双区模态窗口，并接入既有大图查看与统一窗口关闭逻辑。

最终实现没有修改领域规则、`GameState` 结构、联机消息或存档格式；`CharacterCardPanelPresenter` 继续提供权威展示模型，手牌顺序仅保存在本机本局 UI 实例中。

## 2. 表现与交互落地

- 新增独立 `CharacterHandPanel.prefab` 并嵌套安装到 `GameplayInteractionHud.prefab`，没有增加场景根节点。
- 普通阶段手牌在页面下方以最大 `±14°` 扇形排列，基础尺寸 `180×255`、间距约 `112`、透明度 `0.38`，露出卡高的 `30%`。
- 悬停卡牌完整上提、置顶、缩放到 `1.18`，透明度提高到 `0.82`；移出后立即恢复。
- 本机 `CanCover` 为真时自动展开完整手牌，透明度恢复为 `1`、最大角度收窄为 `±6°`；盖放成功或本机失去盖放权限后立即收起。
- 单击手牌、弃牌或已盖放角色牌继续复用 `ZoomableImageViewerController`。
- 手牌区域内拖动可预览并提交本地插入位置；非法落点和盖放拖动会恢复拖动前顺序，拖动结束后的点击由 `CardPointerInteraction` 抑制。
- 拖到主要行动面板且允许盖放时，继续进入 `CharacterCardCoverDragCoordinator` 的既有确认流程。

## 3. 排序与权威边界

- `CharacterHandPanel` 以 `playerId` 分别保存本机偏好顺序，适配热座切换。
- 偏好表保留已见过的全部角色卡 ID；卡牌弃置后再返回手牌时恢复原相对位置，新牌追加到末尾。
- 排序不会修改 `GameState.HandCardIds`，不会提交命令，也不会写入存档或联机快照。
- 退出对局并销毁 HUD 后，本地顺序不再保留。

## 4. 弃牌预览与关闭路由

- 在主要行动面板左下缘外侧新增 `68×68` 方形“弃”按钮，右上角角标始终显示弃牌数量，包括 `0`。
- 模态窗口使用全屏遮罩阻断背景输入，左侧显示原色手牌，右侧显示灰度弃牌；两侧均为可滚动三列网格，卡牌均可打开大图。
- 新增 `UiGrayscale.shader` 和 `UiGrayscale.mat`，弃牌区域使用专用 UGUI 灰度材质并降低到约 `0.65` 透明度。
- 弃牌为空时窗口仍可打开，右侧显示“暂无弃牌”；弃牌不可排序、不可拖动盖放。
- 右上角关闭、`Esc`、遮罩内右键均复用 `WindowCloseInputHandler`；每次打开重新初始化输入状态，保证关闭后再次打开仍可右键关闭。
- 关闭优先级已固定为“大图 → 弃牌窗口 → 其他对局交互 → 设置菜单”，关闭行为不提交命令、不改变排序。

## 5. 空手盖放投影

当本机进入盖放阶段且真实手牌为空时，`CharacterCardPanelPresenter` 把弃牌堆投影成可盖放手牌，并让弃牌角标显示 `0`。投影只存在于 ViewModel；实际回收与盖放仍由现有领域命令原子完成，失败时按权威状态刷新恢复。

已用牌进入弃牌、锡人收回弃牌、收尾阶段未使用牌返回等变化，均经同一次状态刷新直接更新手牌、弃牌区域和数量角标，没有加入跨区域过渡动画。
