# 2026-06-17 UI 热座与影响力表现调整记录

## 问题背景

本轮根据界面截图和后续表现需求处理三个问题：

- 单机/热座模式下，轮到 Player 2 时右侧行动按钮仍保持不可选。
- 玩家颜色需要统一为蓝、红、绿、黄，并参考素材中的四色影响力色号。
- 地图上已经被玩家放置的影响力需要显示为对应玩家颜色的实心方块，而不是空心圆。

## 本轮目标

- 让单机/本地模式自动控制当前行动玩家，避免 Player 2 回合仍按 Player 1 判定 UI。
- 保持联网模式的本机座位隔离，不放宽客户端越权操作。
- 将默认玩家配色顺序统一为蓝、红、绿、黄。
- 将城市和已放置影响力统一到素材色号。
- 只改变已占用影响力槽位的形态，未占用和高亮槽位继续使用原空心圆。

## 已完成

### 1. 单机热座本机玩家同步

- `MobileCityInteractionController` 新增本地热座同步逻辑。
- 当 `GameLaunchContext` 为空或 `LaunchMode.Local` 时，将 `localPlayerId` 同步为 `session.State.CurrentPlayerId`。
- 同步入口覆盖：
  - `CanEndCurrentAction()`
  - `RefreshAllFromState()`
  - `RefreshActionPanel()`
  - `CanStartActionSelection()`
  - `ShowInitialPlacementChoices()`
  - `IsLocalPlayersTurn()`

该调整使单机热座中 Player 1 结束后，Player 2 回合的按钮状态会按 Player 2 计算。

### 2. 状态刷新路径收敛

- 初始城市放置成功后改为调用 `RefreshAllFromState()`。
- 入场事件选择成功后改为调用 `RefreshAllFromState()`。
- 待选事件属于本机玩家且事件面板不存在时，行动面板刷新会自动调用 `ShowPendingEventCardOptions()`。
- 行动面板状态文案区分：
  - 本机需要处理事件选择。
  - 等待其他玩家处理事件选择。

### 3. 玩家默认配色顺序调整

以下房间创建路径的默认座位颜色均改为蓝、红、绿、黄：

- `Assets/YC/Infrastructure/Multiplayer/LocalRoomService.cs`
- `Assets/YC/Infrastructure/Multiplayer/NetworkRoomService.cs`
- `Assets/YC/Infrastructure/Multiplayer/UnityOfficialRoomService.cs`

`StartMenuController` 的单机入口原本已使用蓝色 Player 1，本轮保持不变。

### 4. 素材色号采样与应用

从 `F:\游城拓荒模拟器\游城拓荒\素材` 中的影响力素材采样中心主体色，得到：

| 颜色 | 素材文件 | 色号 |
|---|---|---|
| 蓝 | `影响力蓝.jpg` | `#0145B2` |
| 红 | `影响力红.jpg` | `#B3001D` |
| 绿 | `影响力绿.jpg` | `#60D201` |
| 黄 | `影响力黄.jpg` | `#FFBE00` |

`MobileCityInteractionController.GetPlayerColor()` 统一返回上述颜色，并支持透明度参数。

### 5. 已放置影响力改为实心方块

- `UguiUtility` 新增 `CreateFilledSquareSprite(int size, float sideLength)`。
- `MobileCityInteractionController` 缓存两套影响力槽位 sprite：
  - 空槽：`CreateCircleSprite(24, 8f, 2f)`。
  - 已占用：`CreateFilledSquareSprite(24, 16f)`。
- 资源点影响力槽位和航道影响力槽位刷新时：
  - 若存在 `InfluencePlacement`，切换为实心方块并使用所属玩家颜色。
  - 若为空槽或高亮槽，切回原空心圆。
