## 2. 相对远端新增的主要功能

### 2.1 城市样式宣告完整交互

- 6 张基础城市样式支持显式选择建设面板槽位，不再由规则层自动挑选匹配设施。
- `CityStylePatternMatcher` 支持 `0°/90°/180°/270°` 四个方向旋转，并明确拒绝镜像和畸形/重复槽位输入。
- 新增独立样式预览与宣告界面：可以切换样式卡、点击或拖动轨迹选槽、右键撤销，并实时显示所需数量、已选数量、旋转角度和禁用原因。
- 宣告成功后原子结算影响力、分数与即时资源奖励，只旋转本次明确选中的设施卡槽位，并记录城市样式影响力标记、解锁的特殊行动 ID 与剩余次数。
- 城市样式完整状态已进入克隆与联网 JSON 往返测试。

### 2.2 设施卡、备用设施与设施入场效果复用

- 公共设施供应区支持直接拖拽建设；建设草稿、合法空槽高亮、非法落点、Esc 取消和提交失败恢复由工作流控制器统一管理。
- 3 张延伸枢纽备用牌与普通设施卡共用卡片尺寸、拖拽虚影、落点解析和取消生命周期，并通过 `ValidateReserveBuild()` / `BuildReserveForFree()` 复用正式建设规则。
- 新增 `FacilitySupplyService`，统一供应区补牌、建设后定点替换和供应牌回牌堆。
- 设施贸易与角色牌出售共用 `ResourceSaleService`；额外建设、免费移动、受授予探索继续调用普通建设、移动和探索链路。
- 护航调度中心与载具仓库的多步影响力操作改为领域层原子校验/写回，失败时不会保留部分移除或调度结果。
- 设施待选弹窗补齐折叠/展开、资源数量输入、延伸枢纽拖拽、地图目标分流和会话 ID 防陈旧提交。

### 2.3 五张基础角色牌的玩家交互收口

- 角色牌从信息面板的只读展示扩展为行动面板发动；手牌和弃牌仍在信息面板查看，弃牌区不可再次盖放。
- 非地图参数进入独立角色牌结算弹窗；设施、放置、替换、移除、调度和城市移动分别复用公共设施供应区或地图目标选择。
- 德克萨斯策略可直接点击设施供应区高亮卡牌；坎诺特策略复用资源出售服务；锡人支持购买方案和逐张弃牌待选；雷蛇、极境等地图效果由 `CharacterMapInteractionCoordinator` 编排。
- 起始玩家双效果、第二效果确认、待选恢复、已使用禁用和未知/扩展牌防御分支均补充表现层与规则层覆盖。

### 2.4 表现层与工作流稳定性

- 新增通用 `CardPointerInteraction` 和 `FacilityCardDragUtility`，统一单击/双击判定、拖拽后点击抑制、拖拽虚影层级和组件禁用时取消。
- `TurnActionPresenter` 扩展建设拖拽、城市样式预览、动态工作流切换、Host 等待语义和宣告失败保留选择。
- `ActionPanelController`、`BuildInfoPanel`、`ExpandableInfoPanel`、事件/设施弹窗和 `UguiUtility` 统一了运行时 uGUI 创建、关闭按钮、布局与输入隔离。
- 样式预览、图片查看器与设置菜单的 Esc 优先级已隔离，关闭上层弹窗不会在同一帧穿透打开设置。
- `MobileCityInteractionController.CharacterCards.cs` 将角色牌 Unity 侧组装和转发从主控制器职责中分离。

### 2.5 命令、自动跑局与回归覆盖

- 设施效果可以通过受授予移动/探索入口复用普通事件、路径、支付和待选流程，同时显式控制是否消耗主要行动。
- `LocalhostAutoplayRunner` 能继续处理新增设施待选、宣告样式显式槽位和相关失败诊断。
- 新增或扩展测试覆盖资源出售、共享卡牌指针、角色牌弹窗/地图目标、城市样式显式选槽、设施供应与延伸枢纽拖拽、受授予移动/探索、影响力原子事务、运行时 UI 布局和城市样式联网快照。
