# 2026-06-19 对局内设置菜单记录

## 背景

用户要求在单机、联机进入对局界面后，于右上角增加齿轮状设置按钮。点击按钮后，设置菜单需要从上方向屏幕中间弹出；菜单主体区域先留空，右下角提供返回主菜单按钮，并在真正返回前弹出二级确认菜单。整体视觉参考现有信息面板。

## 已完成

- 新增 `Assets/YC/Presentation/GameSettingsMenuController.cs`。
- 设置入口使用独立高排序 `ScreenSpaceOverlay` Canvas，不改动 `SampleScene` 场景文件。
- 右上角生成齿轮状按钮，按钮底色、描边和图标色沿用 `UiTheme` 的深色面板和金色体系。
- 点击齿轮后显示半透明遮罩，并将设置菜单从屏幕上方滑入中央。
- 设置菜单主体区域使用空白内容区占位，等待后续音量、画面、快捷操作等设置项接入。
- 菜单右下角增加“返回主菜单”按钮；点击后显示二级确认菜单，确认后加载 `StartScene`。
- 在 `MobileCityInteractionController.Awake()` 中新增 `EnsureSettingsMenu()`，确保单机和联机进入 `SampleScene` 后都会拥有同一设置入口。

## 影响范围

- 单机对局：进入 `SampleScene` 后可通过右上角齿轮打开设置菜单，并可二次确认返回主菜单。
- 联机对局：同样使用运行时菜单入口；当前只负责 UI 和场景返回，不额外修改联网状态同步逻辑。
- 表现层：新增 UI 控制器只依赖 `UiTheme`、`FontUtility`、`UguiUtility` 和 Unity UGUI。
