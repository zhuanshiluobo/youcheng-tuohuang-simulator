# 2026-06-19 探索资源图标显示修复记录

## 背景

用户反馈探索完成后资源图标显示异常：

- Unity 编辑器/模拟器中资源图片过小，无法识别。
- 构建后的 exe 单人模式中资源图片不显示，地块仍保留未探索的绿色圆圈占位。

## 已完成

- 新增四人地图资源点显示硬编码：
  - `Assets/YC/Presentation/Maps/MapResourcePointDisplayDefinition.cs`
  - `Assets/YC/Presentation/Maps/FourPlayerResourcePointDisplayDefinitions.cs`
- `MobileCityInteractionController` 改为按 `FourPlayerResourcePointDisplayDefinitions` 为每个地块创建资源点 renderer。
- 未探索地块先显示与影响力空槽同风格的绿色圆形占位。
- 探索后读取 `GameState.Map.ResourceTokens`，将对应地块的占位替换为资源图标。
- 资源图标加载失败时不再继续显示未探索圆圈，而是隐藏该 renderer 并输出 warning，避免误判为仍未探索。
- 修复资源图标加载失败后缓存 `null` 的问题；现在只缓存成功加载的 Sprite。
- `Originium` 的资源图标文件名从旧的 `土.png` 改为 `源岩.png`。
- 资源图标放大显示：
  - `MobileCityInteractionController.ResourceTokenIconScale = new Vector3(1.55f, 1.55f, 1f)`
  - 该值控制探索完成后图标等比缩放，保持图片比例不变。

## 位置调整入口

资源图标坐标硬编码在：

- `Assets/YC/Presentation/Maps/FourPlayerResourcePointDisplayDefinitions.cs`

每个地块一行：

```csharp
Point("A-01", 0.804f, 0.203f),
Point("B-01", 0.870f, 0.598f),
Point("G-04", 0.276f, 0.187f)
```

坐标含义：

- `x`：从左到右，范围 `0` 到 `1`。
- `y`：从上到下，范围 `0` 到 `1`。
- 往右移动：增大 `x`。
- 往左移动：减小 `x`。
- 往下移动：增大 `y`。
- 往上移动：减小 `y`。

图标大小调整入口：

- `Assets/YC/Presentation/MobileCityInteractionController.cs`
- `ResourceTokenIconScale`
