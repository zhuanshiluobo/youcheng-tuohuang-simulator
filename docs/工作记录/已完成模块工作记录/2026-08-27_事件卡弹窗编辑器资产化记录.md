# 2026-08-27 事件卡弹窗编辑器资产化记录

## 1. 工作目标

将原有文字式事件弹窗改为使用事件卡原图的编辑器资产化弹窗，并把同一流程覆盖到全部正式事件卡。交互要求包括：

- 所属资源点继续跟随实际抽卡地块；
- 收起按钮移到卡片右侧黄色区域且不显示提示文字；
- 原卡选项行变成透明可点击热区；
- 热区常态不保留描边，悬停时显示当前玩家影响力色的空心边框；
- 点击与按压反馈复用主要行动逻辑；
- 资源点标牌颜色跟随事件卡绿、红、黄分类；
- 标牌右边必须是连续梯形斜边，不得显示独立箭头。

## 2. 素材清点与导入

核对 `event_cards_manifest.json` 和 `EventCardDatabase` 后，确认运行时正式事件卡共 22 张：绿色 6、红色 6、黄色 10。

素材目录另有两张未登记的企业选项版，未加入本次运行时目录：

- `采集平台残骸（企业选项版）`；
- `洞穴遗迹（企业选项版）`。

22 张正式图片按运行时 ID 重命名并导入 `Assets/YC/Presentation/Resources/CardImages/Events/`，全部为 `850×600`。`CardVisualCatalogEditorAssetBuilder` 改为遍历三个规范 ID 列表，`CardVisualCatalog.asset` 最终包含 22 个事件贴图引用和 84 个总贴图引用。

## 3. 弹窗实现

`EventChoiceDialog.ShowEventCardOptions(...)` 不再只识别单张测试卡，而是对任意 `card.CardId` 查询 `CardVisualCatalog`。命中事件贴图后统一进入资产化展示。

两选项和三选项分别使用固定透明热区覆盖原图选项行。每个热区继续调用原有选项索引回调，使用 `ActionButtonPressFeedback` 提供与主要行动一致的按压行为。`DeploymentInteractionFeedback` 的四边框模式负责悬停提示，颜色由当前本地玩家影响力颜色注入。

右侧收起按钮沿用 `EffectDialogCollapsiblePanel`，只修改展开态布局和文字可见性，收起后的待选流程、地图目标选择和恢复逻辑没有改变。

## 4. 资源点标牌修正

第一版使用矩形主体和旋转三角 Sprite 拼接，实际显示成了左向箭头，并在主体与三角之间露出背景。这不符合目标梯形。

最终实现删除独立 `Ribbon Wedge` 节点，新增单一透明梯形 Sprite：

```text
Assets/YC/Presentation/Sprites/EventResourcePointRibbon.png
```

Sprite 为 `380×42`，右上顶点 `x=380`、右下顶点 `x=300`，形成连续的右斜边。Prefab 的 `Image` 直接使用完整梯形 Sprite，运行时按 `EventColor` 对整体着色：绿色、深红色或矿黄色。

“所属资源点”文字仍从待选会话元数据提取，因此保持跟随实际地块，不与事件卡颜色或图片文件绑定。

## 5. 编辑器资产化边界

本次通过 Editor Builder 和显式 Prefab 引用固化：

- 事件卡图片由 `CardVisualCatalog.asset` 持久引用；
- 事件弹窗层级由 `EventChoiceDialog.prefab` 保存；
- 梯形标牌 `Image` 由 `EventChoiceDialogView` 显式序列化；
- `GameplayDialogEditorAssetBuilder` 负责重建 Prefab；
- `EventChoiceDialogLayoutBuildReadiness` 禁止恢复箭头拼接，并锁定 Sprite 路径和 `380×42` 布局；
- 源码合同同步更新，避免固定布局无意漂移。

本次使用 Unity MCP 完成素材导入、资产刷新、Prefab 重建、代码执行验证和截图检查。

- 22 张事件贴图均为持久 Unity 资产，尺寸全部为 `850×600`；
- `CardVisualCatalog`：事件 22、总贴图 84；

- 梯形最终修正后 `EventChoiceDialogEditorAssetTests`：`16/16` 通过；
- 绿、红、黄三色资源点标牌运行时测试通过；
- Prefab 检查结果：梯形 Sprite 路径正确、尺寸 `(380, 42)`、`Ribbon Wedge=False`；
- Unity Console 最终 error 为 `0`；

验证为定向编辑器测试和视觉检查，没有在本次重新声明完整 EditMode、PlayMode、Development Build 或真实联机验收。
