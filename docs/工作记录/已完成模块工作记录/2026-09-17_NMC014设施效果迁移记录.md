# NMC-014 设施效果迁移完成记录

日期：2026-09-17

## 目标与结果

已完成设施效果从专用设施 pending/resolve 路径迁移到通用 Effect / Event / Interaction 管线。设施生产路径现在按 `effectId` 解析内容合同，创建稳定的设施内容实例，提交 `FacilityEntryEffectActivated`，再由订阅/Lua 分发子 Effect 或创建通用 Interaction；前端通过 `AnswerInteraction` 回传玩家选择。

生产启动、建设流程和本地自动跑局已经接入迁移后的通用路径；旧设施服务和旧 UI 类型暂时保留，用于向后兼容及既有历史测试覆盖，未再作为生产设施入口路由。

设施内容注册表当前包含 46 条注册，版本为 `1.0.0`，路由键为 `effectId`，handler 约定为 `facility.entry.<effectId>`；每条定义具有非空 definition hash。设施建设通过 `CreateForEffectTree` / `BuildForEffectTree` 使用 resolver family，不再按设施名称特判。

## 执行顺序与失败归属

1. build commit：先完成建设状态变更并绑定 `contentInstanceId`。
2. instance identity/state commit：提交设施内容实例身份、激活次数和行为状态。
3. 发布 `FacilityEntryEffectActivated`。
4. 由 subscription / Lua dispatch 分发行为。
5. 创建并执行 child Effects 或通用 Interaction。
6. 处理 Interaction response；child failure 由子 Effect/Interaction 自身返回并记录，父设施 entry 不吞掉失败。

## 设施实例状态与可见性

实例状态 schema 为 v1，字段包括：

- `ContentInstanceId`
- `FacilityCardId`
- `OwnerPlayerId`
- `CityBoardSlotIndex`
- `ActivationCount`
- `LastActivatedRound`
- `CleanupMarkerRegistered`
- `AppliedBehaviorIds`

单局实例数量上限为 128。稳定 `contentInstanceId` 用于唯一行为和重放幂等。

状态投影遵守隐私边界：公共视图仅公开设施放置身份；owner/host 计数仅向有权限的视图提供，其他玩家和 spectator 对应字段为零或隐藏；候选选项只通过 Interaction projection 暴露，不通过隐藏日志泄露。

## 生产路径清理与兼容边界

已完成的生产路径清理：

- `GameSessionBootstrapper`、`BuildFacilityCommandHandler`、`LocalhostAutoplayRunner` 使用 EffectRegistry 和通用 facility path。
- 生产 bootstrap/autoplay 不再通过 `FacilityEntryEffectService`、`ResolveFacilityEffectCommandHandler` 或 `FacilityPendingChoiceTypes` 作为设施 entry 路由。
- 新增 `FacilityInteractionUiCoordinator` 与 `FacilityInteractionAdapter`，消费通用 `InteractionRequest`，通过 `AnswerInteraction` 提交选择、资源分配、候选目标和 escape/settled 状态。
- 建设和特殊行动 UI 不再依赖旧设施 pending choice gating；自动跑局中旧设施 resolution helper 已移除。

兼容项：`FacilityEntryEffectService`、`ResolveFacilityEffectCommandHandler`、`FacilityEffectInteractionUiCoordinator`、`FacilityEffectPendingChoicePresenter` 及相关旧测试仍保留，供既有兼容测试和历史 event/move 流程使用；`PendingCardSession` 也仍服务于通用 event card 等非设施迁移流程。它们不属于新的设施生产 entry 路径。

本次没有删除产品源文件或目录；仅在 Unity 进程确认退出后按需清理过单一明确路径的临时锁文件，未执行批量删除。
