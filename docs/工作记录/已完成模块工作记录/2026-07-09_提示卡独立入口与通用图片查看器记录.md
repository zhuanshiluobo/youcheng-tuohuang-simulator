# 2026-07-09 提示卡独立入口与通用图片查看器记录

## 背景

原提示卡作为左侧 `ExpandableInfoPanel` 的内容模块展示，占用信息面板纵向空间；规则书的缩放、拖动、翻页和关闭输入又全部耦合在 `RulebookViewerController` 内，无法直接复用于单张提示卡。

本轮目标是把提示卡改为右上角独立入口，抽出可复用图片查看器，并让规则书接入同一模块。同时修正开始页 Esc 设置入口和查看器关闭时的 Esc 输入穿透。

## 实现范围

- `GameSettingsMenuController` 在设置齿轮左侧增加 `64 × 64` 提示卡按钮：
  - 与设置按钮使用相同背景色和金色描边；
  - 两按钮间距为按钮宽度的 20%，即 `12.8` 像素；
  - 内置图形为运行时生成的感叹号气泡；
  - 点击后加载 `Resources/ProjectAssetLibrary/HintCards/提示卡`。
- 新增 `ZoomableImageViewerController` 通用图片查看器：
  - 接受标题、页数和按页纹理提供函数；
  - 支持滚轮缩放和按住图片拖动；
  - 支持右键或 Esc 关闭；
  - 多页模式支持左右按钮和方向键翻页；
  - 单页模式隐藏底部分页/缩放说明文字。
- `RulebookViewerController` 已通过页纹理提供函数接入通用图片查看器，继续使用 28 张规则书页面资源。
- Esc 输入行为调整：
  - 开始页即使隐藏“返回主菜单”按钮，也可按 Esc 打开设置菜单；
  - 图片查看器打开时优先处理 Esc；
  - 查看器记录本帧已消费的 Esc，设置菜单同时检查是否存在打开的查看器，避免同一次按键在关闭提示卡后继续打开设置菜单。
- `ExpandableInfoPanel` 不再创建“提示卡”模块；提示卡仅保留右上角独立入口。
- `GameSettingsMenuControllerTests` 改为与现有表现层测试一致的反射访问方式，避免 EditMode asmdef 直接引用默认 `Assembly-CSharp`。

## 验证结果

- `YC.Tests.EditMode.RuntimeUiLayoutTests`：`7 passed / 0 failed`。
- `YC.Tests.EditMode.GameSettingsMenuControllerTests`：`4 passed / 0 failed`。
- 上述 11 项覆盖提示卡按钮布局、通用查看器缩放与拖动容器、单页底栏隐藏、开始页 Esc 和查看器 Esc 优先级。
- 随后补充了“信息面板不存在提示卡模块”的反向断言。最终这一个断言尚未重跑：当前项目被用户打开的 Unity Editor 占用，未另启第二个 batchmode 实例。
- `git diff --check` 通过。

## 当前边界

- 本轮只调整图片查阅和 UI 输入路由，不改变提示卡图片素材本身。
- `ExpandableInfoPanel.AddImagePreview(...)` 仍保留为通用图片预览 API，只是不再用于提示卡模块。
- 规则书旧查看 UI 构建代码仍作为兼容回退保留；实际打开入口优先使用 `ZoomableImageViewerController`。
- 后续增加单图或多页资料时，应复用 `ZoomableImageViewerController.Configure(...)`，不要再次复制滚轮、拖动和关闭输入逻辑。
