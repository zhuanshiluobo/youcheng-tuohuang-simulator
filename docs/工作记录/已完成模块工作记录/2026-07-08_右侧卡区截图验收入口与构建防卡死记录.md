# 2026-07-08 右侧卡区截图验收入口与构建防卡死记录

## 背景

目标是基于现有 `Assets/YC/Editor/LocalhostBuildMenu.cs`、`StartMenuController` 的 `--yc-dev-start-localhost` 参数和 `tools/tests/CaptureLocalhostWindow.ps1`，补一条构建版截图验收入口：一键构建 Localhost、自动进入单机局面、触发右侧建设/宣告卡区显示并输出截图。

实际推进中还发现：当当前 Unity 项目已被 Editor 打开，或 batch Unity 启动后迟迟不创建 `-logFile` 日志时，旧构建包装脚本只等待 Unity 进程退出，容易长时间卡住。因此本轮同时收口了构建脚本的防卡死行为。

## 实现范围

- `BuildInfoPanel` 新增 `SetExpanded(bool expand)`，供验收入口在运行时稳定展开右侧建设信息栏。
- `MobileCityInteractionController` 新增右侧卡区 smoke 参数：
  - `--yc-dev-right-card-smoke`
  - `--yc-dev-right-card-smoke-build`
  - `--yc-dev-right-card-smoke-declare`
  - `--yc-dev-right-card-smoke-no-dialog`
- smoke 准备逻辑会把本地局面整理到第 1 回合行动轮、当前玩家行动状态、确保建设供应和城市样式供应存在，并按参数打开建设弹窗、宣告弹窗或仅展示右侧卡区。
- `tools/tests/Capture-RightCardSmoke.ps1` 新增右侧卡区截图验收入口，默认：
  - 调用 `tools/tests/BuildLocalhost.ps1` 构建 `Builds\Localhost\tuohuang.exe`；
  - 使用 `--yc-dev-start-localhost` 和右侧卡区 smoke 参数启动构建版；
  - 复用 `tools/tests/CaptureLocalhostWindow.ps1` 截图到 `Logs\Screenshots\right-card-smoke-<dialog>.png`。
- `tools/tests/BuildLocalhost.ps1` 补齐防卡死保护：
  - `-MaxBuildSeconds`：总构建超时，默认 900 秒；
  - `-NoLogTimeoutSeconds`：Unity 启动后未创建构建日志的超时，默认 90 秒；
  - 超时后只停止本脚本启动的 Unity PID；
  - `ProjectPath` 与 `LogFile` 规范成绝对路径，并设置 Unity `WorkingDirectory`；
  - 默认检查 `Temp\UnityLockfile`，若当前项目已被 Unity 打开，则直接报占用 PID 并快速失败，不再启动第二个 batch Unity。

## 使用方式

从仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\tests\Capture-RightCardSmoke.ps1 -Dialog Build
```

可选模式：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\tests\Capture-RightCardSmoke.ps1 -Dialog Declare
powershell -ExecutionPolicy Bypass -File .\tools\tests\Capture-RightCardSmoke.ps1 -Dialog None
```

如果只想复用已有构建包，不重新构建：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\tests\Capture-RightCardSmoke.ps1 -SkipBuild
```

## 验证结果

- PowerShell 语法检查通过：

```powershell
[scriptblock]::Create((Get-Content -Raw -LiteralPath 'tools/tests/BuildLocalhost.ps1')) | Out-Null
[scriptblock]::Create((Get-Content -Raw -LiteralPath 'tools/tests/Capture-RightCardSmoke.ps1')) | Out-Null
```

- 短超时验证通过：`tools/tests/BuildLocalhost.ps1` 在 Unity 启动后 5 秒未创建日志时，会停止自己启动的 Unity 进程并报错，不再无限等待。
- 当前项目已由 Unity Editor 打开时，`tools/tests/BuildLocalhost.ps1` 与 `tools/tests/Capture-RightCardSmoke.ps1` 会快速失败并提示占用 PID，例如：

```text
Unity project is already open for this project (PID=30288). Close that Unity instance before running the Localhost build.
```
