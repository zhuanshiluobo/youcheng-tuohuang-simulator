# 2026-06-15 航道显示控制器接入记录

## 背景

根据 `docs/模块文档/航道位置配置与显示模块文档.md`，本次实现第一版 `MapRouteDisplayController`。目标是把航道显示和航道影响力槽位显示放在表现层，读取现有规则地图和运行时状态，不修改规则层。

## 本次改动

- 扩展 `Assets/YC/Presentation/Maps/MapRouteDisplayDefinition.cs`：
  - 新增 `NormalizedPoints` 作为航道折线点。
  - 新增 `NormalColor`、`CoveredColor` 和 `Width` 作为表现参数。
- 更新 `Assets/YC/Presentation/Maps/FourPlayerRouteDisplayDefinitions.cs`：
  - 为四人地图 22 条航道补齐折线点位。
  - 保留并使用已有航道影响力槽位坐标。
- 新增 `Assets/YC/Presentation/Maps/MapRouteDisplayController.cs`：
  - 按 `MapRouteDisplayDefinition` 生成 `LineRenderer`。
  - 按 `InfluenceSlotPositions` 生成航道影响力槽位空槽标记。
  - 读取 `GameState.Map.RoadRouteIds` 切换公路覆盖颜色。
  - 读取 `GameState.Map.Influences` 显示已占用的航道影响力槽位。
- 新增 `Assets/YC/Presentation/Maps/MapRouteDisplayDefinitionValidator.cs`：
  - 校验 `routeId` 是否存在于规则地图。
  - 校验显示配置是否覆盖规则地图所有航道。
  - 校验航道折线点数量不少于 2。
  - 校验 `InfluenceSlotPositions.Count == InfluenceSlotCount`。
  - 校验归一化坐标在 `[0,1]` 范围内。
- 接入 `Assets/YC/Presentation/MobileCityInteractionController.cs`：
  - 初始化时自动挂载或复用 `MapRouteDisplayController`。
  - 在现有 `RefreshInfluenceDisplay()` 中刷新航道显示状态。
- 新增 `Assets/YC/Tests/EditMode/MapRouteDisplayDefinitionTests.cs`：
  - 覆盖四人地图 routeId 对齐。
  - 覆盖航道槽位数量一致。
- 新增 `Assets/YC/Presentation/Maps/YC.Presentation.Maps.asmdef`，让 EditMode 测试可引用表现层地图配置与校验器。

## 接入点

- 当前场景对象：`SampleScene` 的 `MapRoot` 已挂 `MobileCityInteractionController`。
- 运行时入口：`MobileCityInteractionController.Awake()` 调用 `EnsureRouteDisplayController()`。
- 刷新入口：`MobileCityInteractionController.RefreshInfluenceDisplay()` 调用 `routeDisplayController.Refresh(session.State)`。
- 规则数据来源：`StaticMapDefinitions.CreateFourPlayerMap()` 和现有 `GameState`。

## 验证方式

- 静态检查：
  - `FourPlayerRouteDisplayDefinitions` 中四人地图具备 22 条 `Route("...")` 配置。
  - 配置 routeId 与规则层四人地图路线清单一致。
- 自动测试：
  - 通过 Unity Test Runner 运行 `MapRouteDisplayDefinitionTests`。
  - 期望 `FourPlayerRouteDisplayDefinitions_AlignWithRuleRouteIds` 通过。
  - 期望 `FourPlayerRouteDisplayDefinitions_KeepInfluenceSlotCountsConsistent` 通过。
