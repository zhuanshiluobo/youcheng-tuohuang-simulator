# 2026-06-22 本地联机自动跑局验证入口记录

## 背景

本地联机构建需要一个只用于开发/测试的自动跑局入口，用来减少四窗口手动建房、占位、入场和逐回合结束行动的重复操作。

目标是至少稳定跑到第 8 回合结算点，并输出可用于排查的状态快照。

## 实现内容

- 新增 `Assets/YC/Application/Sessions/LocalhostAutoplayRunner.cs`。
- 自动构建四个已就绪席位：Player 1 到 Player 4。
- 使用 `LaunchMode.Host` 创建 Host 权威初始状态，并使用固定房间号 `DEV_LOCALHOST_AUTOPLAY` 生成事件牌堆 seed。
- 通过 `AuthoritativeCommandDispatcher` 提交命令：
  - Player 1 使用 `SubmitHostCommand`。
  - Player 2 到 Player 4 使用 `ReceiveClientCommand`，并通过 `RegisterClientPlayer` 建立 clientId 到 playerId 的映射。
- 自动初始选点：
  - Player 1：`G-01`
  - Player 2：`A-01`
  - Player 3：`A-02`
  - Player 4：`B-01`
- 如果入场选点打开事件待选项，自动选择第一个选项并提交 `ResolveEntranceEvent`。
- 进入行动轮后，自动将当前玩家标记为已完成主要行动，再提交 `EndAction`。
- 循环推进直到 `GamePhase.FinalScoring`，并断言最终状态为第 8 回合结算点。

## 开发入口

- Unity Editor 菜单：`YC/Dev/Run Localhost Autoplay`
- Editor / Development Build 命令行参数：`--yc-dev-autoplay-localhost`
- 最小验证脚本：`tools/Run-LocalhostAutoplayValidation.ps1`
- 使用说明：`docs/本地联机自动跑局验证.md`

命令行参数只在 `UNITY_EDITOR || DEVELOPMENT_BUILD` 下生效，避免普通正式构建误触发。

## 状态快照

自动跑局输出 `本地联机自动跑局快照`，包含：

- 房间号和事件牌堆 seed。
- 四个席位是否就绪。
- 提交命令数和 Host 接受命令数。
- 当前回合、阶段、行动轮、当前玩家和回合轨索引。
- 已开放地点、资源点数量、日志数量。
- 每名玩家的城市位置、金券、分数和行动完成标记。

## 注意事项

- 这是开发/测试入口，不是玩家正式功能。
- 当前自动跑局重点验证本地联机 Host 权威命令链、入场、回合推进和第 8 回合结算点，不覆盖真实 Lobby / Relay 服务连通性。
- 自动推进行动轮时只标记主要行动已完成并提交 `EndAction`，不模拟完整玩家策略。
