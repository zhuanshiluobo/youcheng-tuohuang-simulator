# 2026-06-19 提示动画与主要行动完成态记录

## 背景

用户基于对局界面截图反馈：顶部提示条需要有渐入和渐出动画，显示后 1.5 秒自动收起；主要行动完成后，提示文案应改为“探索已完成”等对应点击行动名称，右下角主要行动栏变为不可选取，但快速行动仍可点击。

## 已完成

- 在 `MobileCityInteractionController` 中为顶部提示面板增加 `CanvasGroup`，通过透明度控制显示和隐藏。
- 新增提示动画状态：`SetPrompt()` 触发渐入，完全显示后停留 1.5 秒，再渐出收起。
- 提示动画使用 `Time.unscaledDeltaTime` 和 `Time.unscaledTime`，避免受游戏时间缩放影响。
- 新增主要行动完成名称记录，完成部署、调度、探索、城市移动后分别显示“部署已完成”“调度已完成”“探索已完成”“城市移动已完成”。
- 右下角行动面板拆分按钮可用条件：
  - 快速行动区：在行动阶段、本机回合、无待选项时仍可点击。
  - 主要行动区：完成本轮主要行动后全部禁用。
- 面板底部状态文案改为复用实际完成行动名称，不再显示“主要行动已完成，请点击结束本回合”。

## 影响范围

- 单机/热座：完成主要行动后，玩家仍可尝试快速行动入口，主要行动按钮不可再次点击。
- 联机：按钮可用状态仍受本机玩家、当前行动玩家和待选项状态限制；本次不修改命令同步逻辑。
- UI 提示：所有通过 `SetPrompt()` 发出的顶部提示都会套用同一渐入、停留、渐出流程。
