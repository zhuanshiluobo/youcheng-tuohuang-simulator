# 2026-06-20 移动城市目标资源点事件修复记录

## 背景

规则书要求：移动城市移动时，如果目标地块没有资源点指示物，则翻开对应颜色事件牌，放置资源点指示物，并结算一个事件选项。

修复前，`CityMovementService.MoveCity` 只处理移动费用、城市位置、对手影响力移除，以及在出发地块放置己方影响力；目标地块没有资源点指示物时不会抽事件牌、不会放置资源点指示物，也不会触发事件选项。

## 根因

- 探索行动已经在 `ExplorationService` 中实现了抽事件牌、放置资源点指示物和事件奖励结算。
- 入场初始地块也在 `SetupCommandHandler` 中实现了类似事件流程。
- 移动城市服务没有持有 `EventDeckService` / `ResourceTokenService`，因此无法在移动结算中访问牌堆和资源点指示物状态。
- `MoveCityCommandHandler` 原先只返回 `CityMoved` 和 `InfluencePlaced` 事件，没有打开或解析移动城市事件选择的分支。
- 表现层事件选择弹窗只区分探索待选项和入场事件，无法把移动城市事件选项提交回移动城市命令。

## 已完成

- 扩展 `CityMovementService`：
  - 构造函数支持注入 `EventDeckService` 和 `ResourceTokenService`。
  - `CanMoveCity` 在目标无资源点指示物时提前校验对应颜色事件牌堆、事件牌数据和选项编号。
  - `MoveCity` 成功移动后，如果目标地块无资源点指示物，则抽取对应颜色事件牌、放置代表资源点指示物、标记地块开放。
  - 当移动命令直接携带事件选项时，立即结算该事件选项奖励。
  - 新增 `ResolveMoveCityEvent`，用于移动后打开 `PendingChoice` 再选择事件选项的延迟结算路径。
- 扩展 `CityMovementResult`：
  - 带回是否翻出事件牌、事件牌 id、事件颜色、选项编号和事件奖励，供命令层产生事件和 UI 刷新使用。
- 扩展 `MoveCityCommandHandler`：
  - 新增 `MoveCityEventChoiceType = "move_city_event"`。
  - 第一次移动到无资源点目标且未携带事件选项时，写入 `GameState.PendingChoice` 并发出 `CardMoved`、`ResourceChanged`、`ChoiceOpened`。
  - 解析移动城市事件选项时，继续使用 `GameCommandKind.MoveCity` 携带选项编号，不再次移动城市，只结算事件奖励并清空 `PendingChoice`。
  - 若命令直接携带事件选项，则移动、抽牌、放置资源点指示物和事件奖励在同一次命令中完成，并标记主要行动完成。
- 更新 `GameSessionBootstrapper`：
  - 移动城市服务使用对局启动时同一个 `EventDeckService`，确保和初始化洗牌后的 `state.Decks` 保持一致。
- 更新 `MobileCityInteractionController`：
  - 移动后如果产生待选事件，刷新资源点和影响力显示并打开事件选择弹窗。
  - 事件选择分派新增 `move_city_event` 分支。
  - 选择移动城市事件选项时提交 `MoveCity` 命令和选项编号，由命令层统一校验和结算。
- 更新 `MoveCityCommandHandlerTests`：
  - 新增移动到无资源点目标时翻事件牌、放置资源点指示物并打开待选项的回归测试。
  - 新增解析移动城市事件选项后发放奖励、清空待选项并标记主要行动完成的回归测试。

## 当前规则口径

- 目标地块已有资源点指示物时，移动城市保持原有流程：付费、移动、清除本次航道和目标地块上的对手影响力，并在出发地块放置己方影响力。
- 目标地块没有资源点指示物时，移动城市会额外执行事件流程：
  1. 按目标地块颜色抽取事件牌。
  2. 放置事件牌代表资源点指示物。
  3. 打开事件选项或按命令携带的选项立即结算。
- 事件选项的即时资源奖励、`+1 分数`、所有对手获得金券/异铁等已沿用探索服务中已有的基础事件效果口径。
- 2026-06-20 后续更新：基础事件效果口径已从中文文本匹配改为结构化 `EventEffect` 结算，详见 `2026-06-20_探索事件结构化效果记录.md`。
- 仍未实现“额外支付后放置影响力”“在相邻航道放置影响力”等更复杂事件效果；这些已经结构化记录目标范围和费用，但还需要后续 resolver 完成目标选择、费用支付和槽位校验。
