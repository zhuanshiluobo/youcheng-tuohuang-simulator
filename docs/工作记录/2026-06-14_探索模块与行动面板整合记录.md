# 2026-06-14 探索模块与行动面板整合记录

## 工作目标

参考探索模块需求文档和行动实现方案，把主要行动统一到对局界面右下角行动面板，并优先接入已实现的影响力、探索和城市移动能力。每名玩家每轮只能执行一次主要行动；未实现的行动保留按钮占位。

## 已完成

- 新增探索领域模块：`ExplorationService`、`ExplorationResult`、`ExplorationTravelPayment`。
- 新增 `ExploreLocationCommandHandler`，接入 `GameSession` 命令流水线。
- 探索结算已覆盖目标合法性、红区开放、路径存在性、路费支付、事件牌抽取、资源点指示物放置、事件奖励、影响力放置和行动玩家推进。
- 探索命令支持默认最短路径，也支持显式 `routeIds`、`pathLocationIds`、`eventOptionId`、`influenceSlotId`、`paymentRecipients`。
- 新增 `ExploreLocationCommandHandlerTests`，覆盖成功探索、对手路费、己方影响力免路费、余额不足不改状态、已有资源点指示物拒绝、红区未开放拒绝、显式路径等场景。
- `MobileCityInteractionController` 注册部署、调度、探索、城市移动命令处理器。
- `SampleScene` 右下角新增行动面板：
  - 快速行动：使用角色牌、宣告样式，占位提示暂未实现。
  - 主要行动：部署、调度、探索、城市移动已接入；建设、特殊行动保留占位。
- 地图点击按当前行动模式分派到对应流程：城市移动、探索、部署、调度来源选择、调度目标选择。
- 行动按钮会按阶段、当前玩家、`PendingChoice`、是否已执行主要行动、是否已移动城市等状态启用或禁用。
- 根据截图反馈，将行动面板整体上移，避免与“结束本回合”按钮重合。
