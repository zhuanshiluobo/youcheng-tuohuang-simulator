# 2026-06-22 规则书查阅页面接入记录

## 背景

对局界面右上角已有设置齿轮入口，但玩家在对局中不能直接查阅规则书。规则书 PDF 已预先抽取为页面图片，目录为 `游城拓荒/_pdf_extracted_images`，本次目标是在项目内接入规则书页图，并提供对局内查阅页面。

## 本次改动

- 将规则书页面图 `page_01.jpg` 到 `page_28.jpg` 复制到 `Assets/Resources/RulebookPages/`，不把 `contact_sheet.jpg` 作为可浏览规则页。
- 新增 `RulebookViewerController`：
  - 运行时创建独立覆盖层 Canvas。
  - 通过 `Resources.Load<Texture2D>("RulebookPages/page_XX")` 按页加载规则书图片。
  - 支持左右按钮翻页。
  - 支持键盘左右键翻页。
  - 支持鼠标滚轮缩放，缩放范围为 `0.55x` 到 `4x`。
  - 支持 `Esc` 和“关闭”按钮退出规则书页面。
- 扩展 `GameSettingsMenuController`：
  - 在右上角设置齿轮下方新增“规则书”按钮。
  - 点击时查找或创建 `RulebookViewerController` 并打开规则书页面。
- 扩展 `MapTexturePostprocessor`：
  - 对 `Assets/Resources/RulebookPages/` 下规则页关闭 mipmap。
  - 规则页按普通纹理导入，最大尺寸设为 `4096`，避免使用 Sprite 导入口径影响放大阅读清晰度。
  - 地图贴图和资源图标的既有导入口径保持不变。

## 设计取舍

- 规则书页放入 `Assets/Resources/RulebookPages/`，是为了在运行时按页名延迟加载，不需要把 28 张大图作为场景序列化引用。
- 规则书查看器使用独立 Canvas，排序层级高于设置菜单；这样从右上角按钮打开时不依赖设置弹窗状态，也不会挤占右下角行动面板。
- 当前只接入基础左右翻页和滚轮缩放，没有增加页码输入、目录跳转或搜索。后续如果需要目录功能，应在规则书页图之外补充结构化目录数据。

执行 `tools/Run-EditModeTests.ps1` 两次，Unity 编译通过，新增脚本和导入后处理器均未出现 C# 编译错误。

## 后续建议

- 在 Unity 编辑器或构建版中手动确认右上角“规则书”按钮的位置与点击区域是否符合当前分辨率布局。
- 若规则页阅读清晰度仍不足，可进一步提高目标平台导入尺寸或改为从 StreamingAssets 原图按需读取。
- 后续可增加页码跳转、目录页快捷入口和最近打开页缓存。
