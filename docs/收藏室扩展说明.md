# 收藏室：新增材料与展示资产维护

## 当前结构

- 场景：`Assets/Scenes/CollectionRoom.unity`。
- 目录：`Assets/YC/Presentation/Collection/CollectionCatalog.asset`。
- 至纯源石配置：`Assets/YC/Presentation/Collection/Items/PureOriginium.asset`。
- 至纯源石展示预制体：`Assets/YC/Presentation/Collection/Prefabs/OriginiteDisplay.prefab`。
- 通用列表条目：`Assets/YC/Presentation/Collection/Prefabs/CollectionItemView.prefab`。

场景只保留界面、公共旋转中心、摄像机和既有聚光灯区。运行时从目录创建左侧列表和当前选中的一个模型。源石的默认姿态、比例、材质覆盖、内部晶簇和核心辉光已经迁入独立展示预制体。编辑模式下公共旋转中心为空，这是正常状态；进入运行模式即可查看目录中第一件可见藏品。

## 通过外部 Excel 维护配置（推荐）

当前主表为 `ConfigTables/收藏室配置.xlsx`。此文件是项目唯一正式配置表。

1. 在“藏品”工作表编辑资料并保存。停止 Unity 运行，等待编译完成。
2. 使用 **游城 → 收藏室 → 导入项目配置表**。项目外的副本使用 **选择外部配置表并导入**；该操作不会复制回项目主表。
3. 导入成功后运行收藏室查看。**定位项目配置表**菜单定位项目主表。

| 列 | 填写规则 |
| --- | --- |
| 内部编号 | 唯一且固定的数字文本，例如 `01`、`02`。本列为文本，前导零属于编号；不要重新给已有藏品编号。 |
| 稀有度 | 必填，依次为常见、普通、精良、罕见、稀有，对应本体材料 T1–T5；决定背景色，不参与列表排序。 |
| 中文 | 必填的藏品中文名称。 |
| 英文 | 英文名称，可留空，只用于展示，不作为内部标识。 |
| 描述文本 | 藏品介绍，可留空。 |
| 启用 | 是/否。否表示不进入目录，即使已获取也不显示，但不删除资产。 |
| 默认展示 | 是：未获取也显示卡片；否：未获取时连卡片都不出现，获取后才显示。允许多行是，不控制初始选中项。 |
| 获取条件文本 | 给玩家看的提示，例如：达成成就“xxx”。可留空，不自动创建成就或判断获取条件。 |
| 模型路径 | 项目内 Assets/ 开头的 .prefab 路径。可留空，展示区提示“暂无模型”。 |
| 聚光灯颜色 | 保留原列名，含义为背景雾和地板的稀有度基色。模型使用独立中性照明。导入及运行时以稀有度为准，手动填写其他颜色不覆盖标准色。 |

**没有排序列和独立展示编号列。列表按 Excel 行顺序显示，进入收藏室选中第一件可见藏品。内部编号不参与排序。**

新增材料：复制整行，更换内部编号、名称和模型路径。普通可见藏品将默认展示设为是，隐藏藏品设为否。相同编号更新原配置，新编号创建新配置。

### 默认展示与获取条件

- 目前尚未接入成就或存档系统，默认全部未获取。默认展示为否的藏品会隐藏，填写获取条件文本不会自动解锁。
- 未获取且可见的藏品，其获取条件文本追加在描述文本末尾；已获取后不显示此提示。没有新增界面控件或改变布局。
- 隐藏藏品不生成卡片，不计入可见数量，也不向玩家显示名称或获取条件。
- 已提供 CollectionRoomController.SetObtainedItems(IEnumerable<string> itemIds) 作为后续接入口。传入完整的已获取编号集合，例如 new[] { "01", "02" }，安全等待当前切换结束后刷新可见列表。
- 此接口只保存本次控制器实例的内存状态，不判断成就、不读写存档；重新加载场景后需由未来获取系统重新传入。

### 导入规则与报错

- 只支持 .xlsx。“藏品”工作表名和首行十个表头不能改名，允许调换列顺序。旧表需更新为当前十列后导入。
- 启用、默认展示接受是/否、true/false 或 1/0。没有“最多一个默认展示”限制。
- 内部编号为空、重复或含非数字、中文名称为空、开关填写无效、稀有度不在上述五档时拒绝导入。
- 非空模型路径必须指向项目内存在的 .prefab；包括禁用行在内，所有行都校验通过后才写入。
- 不支持公式、Excel 错误值、xls、xlsm 或加密表。空表拒绝导入；需要空目录时保留行并将启用全部设为否。
- 未列出或禁用条目退出目录，但不删除配置资产和模型。
- 导入覆盖表内管理的字段。Icon 和内部反射由配置资产维护，导入不会覆盖；新配置默认不开启内部反射。
- 模型姿态、比例、材质在展示预制体编辑。Excel 不生成模型，不修改场景、预制体或聚光灯区资产。
- 只手动导入，不自动监视 Excel，也不是运行时热更新。

## 手动添加一种材料（不使用 Excel）

1. 制作该材料的展示预制体。
   - 建立一个模型根节点，把需要一起旋转的模型、材质和专属效果放在其下。
   - 根节点的局部位置、旋转和比例就是它在公共展台内的默认展示姿态。旋转中心位于公共展台原点；偏心模型应在预制体内部调整，不要移动公共展台。
   - 不要把摄像机、UI、聚光灯区、公共地板或公共雾复制进去。
   - 控制器会将运行时实例的全部子节点设为公共旋转中心的显示图层，无需修改原模型图层。
2. 在 Project 窗口右键，选择 **Create → 游城 → 收藏室 → 藏品**。
3. 在配置的 Inspector 填写：
   - `Item Id`：稳定且唯一的数字文本，例如 `02`；不能与其他藏品重复。
   - `Display Name`、`English Name`、`稀有度`、`描述文本`：界面资料。Excel 导入会将 `Display Number` 同步为内部编号，无需在表中另填。
   - `Display Prefab`：拖入步骤 1 的预制体。
   - `Use Interior Reflection`：普通材料保持关闭；只有使用现有收藏室水晶着色器、需要晶簇内部反射时才开启。
   - `Icon`：可选。当前保留文字列表样式，条目预制体没有绑定图标控件；将来需要图标时，在条目预制体中制作 Image 并绑定 `Icon` 引用即可。
4. 打开 `CollectionCatalog.asset`，将配置拖入 `Items` 数组；数组顺序就是左侧列表顺序。
5. 设置“默认展示”、可选的“获取条件文本”和稀有度。灯色按稀有度自动绑定；进入时始终选择第一个可见项。
6. 进入收藏室运行，点击新条目，检查比例、朝向、资料、拖拽及复位。停止运行后再在预制体里修正默认姿态。

新增材料不需要改控制器、不需要往场景放模型、不需要复制收藏室场景。当前表保留 01–05 号至纯源石、源岩、固源岩、固源岩组、提纯源岩，新增 06 号 D32钢。D32钢为本体 T5，收藏室稀有度为“稀有”，默认展示，并使用独立预制体 `D32SteelDisplay.prefab`，其模型已由白模替换为冷银蓝金属材质版。02–05 号默认展示为否，尚未填写模型路径，未获取时隐藏。

### D32钢材质版

- 可编辑源文件：`ArtSource/Materials/D32Steel/D32Steel_Finished.blend`。原 `D32Steel_Blockout.blend` 及白模 FBX 保留不覆盖。
- 游戏模型：`Assets/YC/Presentation/Models/D32Steel/D32Steel_Finished.fbx`。保留 21 个分件，增加倒角细分、深色背面与边缘银色分区；独立 UV 图集。
- 游戏材质：`D32SteelFinished.mat` 使用 Standard。四张 2048×2048 贴图位于该模型目录的 `Textures`：BaseColor、Normal、Occlusion、MetallicSmoothness。颜色贴图为 sRGB，其余为非颜色数据；金属度放 R，光滑度放 A（1−粗糙度）。
- 独立藏品预制体挂载自定义 ReflectionProbe，使用 `D32SteelStudioReflection.asset` 柔光环境立方体贴图，只补金属的局部环境反射，不新增场景灯光，不改变背景稀有度色。
- 只替换 06 号独立藏品预制体内的模型，沿用原朝向、包围盒大小和中心；场景、UI 和至纯源石预制体不重新生成或覆盖。
- 造型和颜色参考 [PRTS D32钢](https://prts.wiki/w/D32钢) 单张图标，背面为合理推定，并非官方三维资产。图标的金色稀有度圆环不属于模型。

## 稀有度与背景色

基色改为直接采样 PRTS 的 **带框材料图标稀有度圆环**，不是材料本身的颜色，也不是活动商店表格的浅色底。图标内侧灰色底盘不随稀有度变色；这里将圆环的等级识别色用于收藏室背景。圆环包含抗锯齿、透明度和明暗变化，以下数值是代表主色，不是官方公布的灯光色码。

| 本体材料等级 | 收藏室稀有度 | sRGB 背景基色 | Wiki 取色样本 |
| --- | --- | --- | --- |
| T1 | 常见 | `#A0A0A0` 灰色 | [源岩](https://prts.wiki/w/文件:道具_带框_源岩.png) |
| T2 | 普通 | `#DCE537` 黄绿 | [固源岩](https://prts.wiki/w/文件:道具_带框_固源岩.png) |
| T3 | 精良 | `#00B3FD` 青蓝 | [固源岩组](https://prts.wiki/w/文件:道具_带框_固源岩组.png) |
| T4 | 罕见 | `#D6C5D6` 浅灰紫 | [提纯源岩](https://prts.wiki/w/文件:道具_带框_提纯源岩.png)，用糖聚块、酮阵列交叉核对 |
| T5 | 稀有 | `#FFC802` 亮金黄 | [聚合剂](https://prts.wiki/w/文件:道具_带框_聚合剂.png)，用双极纳米片交叉核对 |

取色方法：原始 PNG 为 183×183；在中心 (91,91)、半径 78–80 像素的圆环区域筛选 alpha≥250 的像素，取背景环主色的众数，避开材料遮挡。T5 不直接用 D32钢取众数，因其模型遮挡大部分圆环，改用露出完整金环的聚合剂。读取日期：2026-10-04。

标准定义在 `CollectionRarityPalette.cs`，Excel 的“填写说明”页也保存了对应关系。配置导入会将稀有度对应色同步到藏品资产，运行时选择藏品仍按同一标准取色。修改稀有度后重新导入即可改变背景色，无需逐个配置灯光。

`SpotlightArea.SetBackgroundColor` 分开管理背景色与模型主光。背景色显式转换到项目色彩空间后传给地板和雾；背景材质保留原有明暗，但去除原橙色散射的乘色偏移。模型使用检查器的“模型照明色”（默认白色）和“模型主光能量比例”（默认 0.2），不再随稀有度染色，也不因原主光强度而整片过曝。背景雾不覆盖位于地板前的实体藏品像素；地板背景亮度独立于模型能量比例，仍跟随原灯强度淡入淡出。背景在阴影和稀薄雾中会变暗，不能将这些区域的像素等同于基色色码。

## 展示与切换

- 一次只保留一个活跃的藏品模型。切换时先停止拖拽和惯性，调用既有 `SpotlightArea.SwitchExhibit`，完全遮黑时替换模型，再按原过渡配置亮起。
- 使用选中藏品的稀有度背景色；空目录恢复进入场景时的原始背景色，不继承上一件藏品背景色。至纯源石与 D32钢均为“稀有”，背景使用 `#FFC802`（RGB 255、200、2）。控制器不写入灯光位置、范围、角度、材质或过渡时长，模型主光为中性照明。
- 切换过程中可继续点选；保留最后一次待切换选择，不同时生成多套模型。
- 复位只恢复公共旋转中心，保留每个藏品预制体中编辑好的默认姿态与比例。
- 离开水晶模型时释放其内部反射资源，普通材料不会继承水晶反射效果。
- 模型未配置时仍可查看资料，展示区提示“暂无模型”，暂时关闭拖拽和复位；仍可切换其他条目或返回。
- 空目录显示“暂无藏品”；空引用会跳过，空 ID 或重复 ID 会跳过并给出警告。
- 列表可滚动。数量指示器显示“当前序号 / 可见藏品总数”，不代表玩家库存数量，也不声称已接入收藏解锁或库存系统。

## 资产所有权

- 界面布局、样式、静态标题与按钮文字由场景和条目预制体编辑。控制器只更新与选中藏品相关的资料、数量和状态。
- 藏品资料以配置资产为准；默认模型姿态和专属效果以展示预制体为准。
- 状态提示及计数格式在收藏室控制器 Inspector 中可编辑，不需要修改代码。
- 条目高度在条目预制体的 `Layout Element` 中修改，条目间距在场景的 `藏品列表内容 / Vertical Layout Group` 中修改。
- 不运行任何 UI Rebuild 或资产生成器。之后运行游戏、普通检查和验证都不会重新生成或覆盖界面资产。
- 背景色修正更新表格、颜色映射、展示与聚光灯区的颜色传递逻辑、背景着色器及藏品配置资产。不重新生成或保存覆盖场景、展示预制体、界面布局和聚光灯区材质资产。
