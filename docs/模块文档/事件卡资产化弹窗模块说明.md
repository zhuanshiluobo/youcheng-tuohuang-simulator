# 事件卡资产化弹窗模块说明

## 1. 模块目标

事件卡弹窗使用原始事件卡图片作为完整背景，在 Unity Prefab 上叠加资源点标牌、透明选项点击热区和右侧收起按钮。运行时只负责绑定当前事件卡、当前地块元数据和玩家交互回调，不重新拼装卡面文字。

当前实现覆盖 `EventCardDatabase` 登记的全部 22 张事件卡：

- 绿色事件卡 6 张；
- 红色事件卡 6 张；
- 黄色事件卡 10 张。

素材清单中的两张“企业选项版”没有登记进 `EventCardDatabase`，因此不会进入运行时 `CardVisualCatalog`：

- `采集平台残骸（企业选项版）`；
- `洞穴遗迹（企业选项版）`。

## 2. 素材与资产映射

原始拆分图和人工映射位于：

- `游城拓荒/素材/事件牌拆分/`；
- `游城拓荒/素材/事件牌拆分/event_cards_manifest.json`。

运行时图片统一存放在外部内容包中：

```text
Assets/StreamingAssets/Content/core/artwork/event/{eventCardId}.jpg
```

所有正式事件卡图片均为 `850×600`。运行时 ID 直接使用 `EventCardDatabase.GreenCardIds`、`RedCardIds` 和 `YellowCardIds`，不从中文文件名或图片内容推断。

事件定义位于 `Assets/StreamingAssets/Content/core/event/{eventCardId}.json`，其中的 `artwork` 字段映射到对应图片。`CardVisualCatalog` 保留为统一查询入口，不持有整套持久化贴图引用，不要求固定的总贴图数量。

生产代码通过 `GameplayDialogRegistry.CardVisualCatalog.GetEvent(cardId)` 获取贴图。`ExternalContentRuntime` 负责读取内容包、按需解码和缓存；同一路径只解码一次，控制器不自行发现文件或调用 `Resources.Load<Texture2D>`。角色卡背和城市板同样由 `pack.json` 的 `sharedArtwork` 提供；城市板预制体使用 `SharedArtworkImage` 绑定该缓存纹理。

## 3. 弹窗结构

主要入口为：

- `Assets/YC/Presentation/EventChoiceDialog.cs`；
- `Assets/YC/Presentation/EventChoiceDialogView.cs`；
- `Assets/YC/Presentation/Prefabs/Gameplay/Dialogs/EventChoiceDialog.prefab`；
- `Assets/YC/Editor/GameplayDialogEditorAssetBuilder.cs`。

`ShowEventCardOptions(...)` 会用 `card.CardId` 查询事件卡贴图。找到贴图时进入资产化展示：

1. 面板尺寸使用图片原始 `850×600`；
2. 原图作为整张卡的背景；
3. 旧标题、说明和文字选项 UI 隐藏；
4. 根据选项数量创建透明点击热区；
5. 显示动态资源点标牌和右侧收起按钮。

若目录缺少贴图，代码仍保留旧的文字弹窗路径作为异常兼容入口；正式 22 张事件卡均应命中资产化路径。

## 4. 所属资源点梯形标牌

### 4.1 数据来源

“所属资源点”文字来自当前待选会话传入的 `metadataLabel`，表示实际抽卡地块，而不是写死在事件卡图片或按卡牌 ID 推断。因此同一张事件卡在不同地块触发时，标牌会跟随实际地块变化。

### 4.2 图形资产

标牌使用单一 Sprite：

```text
Assets/YC/Presentation/Sprites/EventResourcePointRibbon.png
```

Sprite 尺寸为 `380×42`，透明背景，主体是连续梯形：

- 左上、左下均为直角；
- 右上顶点位于 `x=380`；
- 右下顶点位于 `x=300`；
- 右边形成从右上向左下的单条斜边。

Prefab 中不允许存在独立 `Ribbon Wedge`、三角箭头或矩形与三角形拼接。梯形在 UI 中保持 `380×42`，位置为左上锚点、偏移 `(56, 0)`。

### 4.3 颜色规则

梯形 Sprite 本身为白色透明图，运行时由 `EventCardDefinition.Color` 对整个图形统一着色：

| 事件颜色 | RGBA |
|---|---|
| 绿色 | `(0.31, 0.62, 0.20, 0.98)` |
| 红色 | `(0.65, 0.15, 0.10, 0.98)` |
| 黄色 | `(0.82, 0.61, 0.12, 0.98)` |

标牌文字保持白色。颜色不读取玩家颜色；玩家颜色只用于选项悬停边框。

## 5. 选项点击热区

选项热区覆盖原卡图片上的选项行，常态必须完全透明，不保留示意描边或实色填充。

当前固定几何以卡图左上角为坐标原点：

| 布局 | 选项 | X | 顶部 Y | 宽 | 高 |
|---|---:|---:|---:|---:|---:|
| 两选项 | 1 | 90 | 385 | 670 | 72 |
| 两选项 | 2 | 90 | 462 | 670 | 84 |
| 三选项 | 1 | 90 | 380 | 670 | 78 |
| 三选项 | 2 | 90 | 458 | 670 | 50 |
| 三选项 | 3 | 90 | 508 | 670 | 56 |

交互约束：

- `Image.color` 常态为透明；
- 标签文字隐藏；
- `Button.transition` 为 `None`；
- 悬停时只显示四条边组成的空心边框；
- 边框颜色使用当前玩家影响力颜色；
- 按压反馈复用 `ActionButtonPressFeedback`，与主要行动按钮一致；
- 点击仍调用原有 `onChoiceSelected(index)`，不改变事件结算逻辑。

## 6. 收起按钮

资产化事件卡的收起按钮位于卡片右侧黄色区域：

- 展开状态布局为右侧居中，尺寸 `36×220`，偏移 `(-18, 0)`；
- 按钮不显示“收起/展开”文字，只显示白色三角图标；
- 收起、恢复、拖动和地图交互穿透继续使用 `EffectDialogCollapsiblePanel` 原有逻辑；
- 本模块只改变展开态的视觉位置，不改变待选状态和命令提交。

## 7. 修改与验证

修改事件卡图片时，更新内容包中的对应图片及事件定义的 `artwork` 映射即可，无需重建卡图目录或弹窗 Prefab。重新启动运行实例后，在 Unity Editor 中验证：

1. 通过 `CardVisualCatalog.TryValidateConfiguration` 检查内容包和必需的共享图片映射；
2. 运行 `CardVisualCatalogEditorAssetTests`，确认当前启用的卡图可解码、缓存可复用且正式城市板预制体已绑定外部图片；
3. 涉及弹窗交互时，运行 `EventChoiceDialogEditorAssetTests` 和 `DeploymentInteractionFeedbackTests`；
4. 至少目视检查一张两选项卡和一张三选项卡。

测试和运行均不重建或保存界面资产。只有用户明确授权覆盖事件弹窗时，才能手动调用 `GameplayDialogEditorAssetBuilder.RebuildEventChoiceDialogOnly()`；修改梯形 Sprite、固定引用或布局后，以实际 Prefab 和画面为准验证。

关键检查包括：

- 当前启用的事件定义均能映射并解码外部图片；
- `CardVisualCatalog` 不持有旧卡图引用，重复查询复用同一缓存纹理；
- Prefab 只引用单一梯形 Sprite，不存在 `Ribbon Wedge`；
- 绿、红、黄三色标牌均按 `EventColor` 正确着色；
- 点击热区常态透明，悬停边框为空心且可跟随玩家颜色；
- Console 不存在新的编译或运行错误。

## 8. 维护边界

- 新增正式事件卡时，更新外部内容定义、内容包清单和对应 `artwork` 图片，并核对领域目录加载结果；不要只向图片目录塞文件。
- 不要把未登记的企业变体自动加入基础事件牌堆。
- 不要在运行时按中文名称、文件顺序或图片颜色推断卡牌 ID。
- 不要恢复卡面文字的重复 UGUI 绘制；卡图是视觉事实源，透明热区只负责交互。
- 不要用独立三角形拼接梯形；斜边必须来自完整梯形 Sprite。
- 牌面规则数值仍以原始卡图和 `EventCharacterCardCatalog.asset` 为准，本模块只负责表现和输入。
