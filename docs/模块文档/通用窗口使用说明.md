# 通用窗口

预制体：`Assets/YC/Presentation/Prefabs/Gameplay/Dialogs/GenericWindow.prefab`。

控制器：`YC.Presentation.GenericWindowView`。

窗口沿用现有 Frontier31 图片、公共字体和按钮状态组件。米色标题栏、深棕内容面板、磨损外框和黄色确认按钮均引用项目已有资产。默认面板为 960 × 620，使用 1920 × 1080 参考分辨率和原生布局组件，空间不足时由布局收缩。

## 在编辑器中使用

将预制体放在场景根节点；它已经包含独立 Canvas、CanvasScaler、GraphicRaycaster 和背景遮罩。场景需要已有 EventSystem。

- `Panel/Header/Headings`：修改标题和副标题。
- `Panel/Body/Viewport/Content`：内容挂载点，可加入文字、图片或其他布局组件；默认 `Message` 可以修改或隐藏。
- `Panel/Footer`：修改确认、取消文案，或隐藏不需要的操作按钮。
- 根节点 `GenericWindowView`：在 `Confirmed` 和 `Cancelled` 中配置业务事件。
- 修改面板 LayoutElement 可调整首选尺寸，修改布局组件可调整边距和间距。

静态文案和样式以预制体或场景实例为准。运行时只有显式调用 `SetContent` 才会更新本次窗口的动态文案。

## 从代码使用

通过检查器引用预制体根节点上的 `GenericWindowView`，然后实例化：

```csharp
[SerializeField] private GenericWindowView windowPrefab;

private void OpenActionConfirmation()
{
    var window = Instantiate(windowPrefab);
    window.SetContent(actionTitle, actionDescription, actionHint);
    window.Confirmed.AddListener(ExecuteSelectedAction);
    window.Show();
}
```

`Content` 暴露内容挂载点。`ConfirmButton` 和 `CancelButton` 可用于动态控制可交互状态。

`Show()` 显示窗口并把滚动位置复位到顶部；`Hide()` 隐藏窗口，不触发业务事件。确认按钮默认隐藏窗口后触发 `Confirmed`；取消、右上角关闭、右键和 Escape 会隐藏窗口并触发 `Cancelled`。取消按钮获得初始键盘焦点，关闭后恢复原有焦点。

取消勾选 `Close After Confirm` 可以保留确认后的窗口，例如等待业务结果后再关闭。业务方负责复用实例或在不再需要时销毁实例。
