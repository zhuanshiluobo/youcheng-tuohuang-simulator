# 通用窗口使用说明

预制体：`Assets/YC/Presentation/Prefabs/Gameplay/Dialogs/GenericWindow.prefab`。
控制器：`YC.Presentation.GenericWindowView`，源码位于 `Assets/YC/Presentation/CommonUi/GenericWindowView.cs`。

标题、按钮文案、图片、字体、尺寸与布局以实际预制体或场景实例为准。窗口本身已经带有 Canvas、CanvasScaler、GraphicRaycaster 和背景遮罩；场景须有 EventSystem。普通测试和构建不生成或覆盖这些资产。

通过检查器引用窗口实例或预制体。`Content` 是业务内容挂载点，`ConfirmButton` 和 `CancelButton` 可控制本次业务的可交互状态；`Confirmed`、`Cancelled` 用于接收操作结果。

- `Show()` 显示窗口，并把内容滚动位置复位到顶部。
- `Hide()` 隐藏窗口，不触发确认或取消事件。
- `SetContent(title, message, subtitle)` 只设置调用方提供的本次动态内容；未调用时沿用资产中的静态文案。
- `SetInteractionEnabled(false)` 在异步保存等期间关闭交互。调用方在完成或失败后恢复交互。
- `Confirm()` 仅在窗口有效且确认按钮可交互时生效；`closeAfterConfirm` 决定是否先隐藏窗口，再触发确认事件。
- `Cancel()` 在窗口有效且允许交互时隐藏窗口并触发取消事件。关闭按钮、取消按钮、关闭输入组件和启用的 Escape 入口都接入这个方法。

存档窗口使用该公共组件，具体的存档选择、删除、保存进度和错误提示由 `MatchSaveWindowView` 与 `MatchSaveController` 管理。复用与销毁实例由调用方负责。

本文吸收远端通用窗口说明，并按当前存档期间交互守卫修订；没有重新生成窗口，也不代表完成所有视觉场景验收。
