# 游城拓荒 2D Unity 模拟器项目总览

> **唯一当前事实源**。最后核对：2026-09-21（基础设施 Lua 迁移、正式三人图接入与独立运行包；历史 Steam 记录保留原日期，不代表三人验收通过）。若本文件与 README、发布检查清单以外的任何文档冲突，以本文件为准；日期工作记录只保留当时的实现过程和验证快照，不更新为当前状态。

## 1. 项目定位与支持范围

《游城拓荒：铸基者》2D Unity 模拟器优先服务于基础版规则模拟，目标是形成可运行、可验证、可扩展的数字规则系统，而不是完整复刻实体桌游美术。

| 项目 | 当前事实 |
| --- | --- |
| 项目版本 | `v0.4.2-beta`。 |
| 正式规则范围 | 标准四人地图与基础版流程保留，正式三人图已接入。 |
| 三人模式 | 正式三人图已接入（18 地点、19 路线、7 区块）；开发验收进行中，Steam 三账号待验收，构建与全流程尚不能标记通过。 |
| 本地对局 | 四人热座主流程保留；三人热座入口已接入，开发验收进行中。 |
| 联机 | Steam Lobby + Mirror/FizzySteamworks 的 Host 权威 MVP 已接入；Mirror/Telepathy 可作本地多实例验证。 |
| 目标平台 | Windows 开发/验证流程已存在；发布构建须按检查清单重新验证。 |
| Unity 版本 | `2022.3.62f1c1`。 |

## 2. 当前能力与 Lua 迁移边界

2026-09-21：持久 Effect 树、回合主链、四节点入场及 B-01 的 222/事件牌、主要行动部署、十项角色激活入口已经接入新架构。角色五张十项能力由外部 JSON 与 Lua 组合定义；设施 19 组模板按颜色数量展开 46 个实体，其中 14 种入场模板全部使用 Lua 组合，正式脚本不再调用旧 facility_entry 适配。城市样式额外行动已直连通用原语，旧 ScriptStep 执行分支撤下。企业/企业家及永续/一次性具体生命周期按约定留待扩展卡实现。条件式先支付再执行右式；设施交互接入统一请求路由。主要行动建设、探索等仍须改造旧 UI 入口和取消流程。**NMC-014A 尚未验收，NMC-015 不可结案**。当前边界见[基础内容迁移与 UI 接入边界](../设计/基础内容迁移与UI接入边界.md)，验证证据见[本轮回归](../测试/2026-09-21_基础设施迁移与UI边界回归.md)。

以下规则能力包含兼容实现，不能据此推断所有能力都已迁至纯 Lua。

### 规则与流程

- 固定阶段流、命令阶段校验、起始玩家、初始地块入场、`GameSession.Submit` 与可序列化状态。
- 正式三人图与四人地图结构化数据、地图查询、路径搜索、路线费用、红区限制与影响力区块统计。
- 城市移动、部署、调度、探索、建设、采集、结束行动、收尾推进和最终计分。
- 41 张普通设施卡元数据、16 类正式效果契约、2 类备用设施效果契约、设施待选交互与供应槽位补牌。
- 五张标准角色牌的盖放、策略/计谋、待选结算和收尾回收。
- 城市样式四方向旋转匹配、轨迹选块、宣告统一结算、即时奖励和分数轨显示。

### 特殊行动

兼容规则路径包含五种特殊行动；新架构已补上条件式费用顺序、复合动力的移动/航道放置和高效移动的逐段目标重算。费用目录与标记生命周期仍由宿主编排，动员等剩余内容仍需继续核对，不能宣称全部纯 Lua 迁移完成。

- Host 权威命令结算、I/II 级标记生命周期、额外主要行动、角色牌行动轮限制和多步待处理状态均已实现。
- 从公共样式卡预览中拖拽本方可用影响力标记即可发动；复合动力系统先挂入主链，再由左侧支付请求复用材料选择弹窗。
- 地图高亮、事件弹窗、待处理会话恢复与自动跑局已覆盖程序链路。
- 真实 Steam 多账号验收已完成（用户确认）；人工 UI 冒烟与专项三席、标准四席本地多进程验收仍待完成，不是规则效果缺失。

### 表现与资产化

- UI Theme、事件、角色、城市样式、特殊行动、网络运行时根和地图反馈均由持久资产与生产 Bootstrap/Prefab 提供。
- 开始页、地图交互、行动/信息面板、设置与规则书入口、角色手牌/弃牌预览、事件弹窗和卡牌查看器均已接入对局表现层。
- 控制器行数、`new Vector2(...)` 等静态构造数量会随代码版本变化，**不在本文维护为当前指标**；需要时以当前源码及对应架构测试/编辑器检查为准。

1. 正式三人图已接入，开发验收进行中，Steam 三账号待验收；下文历史测试、构建与多账号记录不等于本次三人全流程验收通过。

4. 企业扩展角色与规则暂未录入。
5. 自动化闭环不替代构建产物和人工交付验收。
6. 旧 Pending、RoundAdvance 外观、完整状态兼容 API 与部分 C# 卡面分支仍未清除；完整 Lua API 中的部分规划 Effect 尚未实现且不再假装公开可用。
