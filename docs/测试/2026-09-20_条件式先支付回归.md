# 条件式先支付回归（2026-09-20）

## 范围与规则依据

以《Lua效果系统API初稿》2.6 为准，纠正角色和城市样式把右式选点提前、费用滞后结算的问题。极境策略保持最低资源 +4；本次支付与移动规则属于极境计谋。极境计谋是普通移动的候选修正，不另设突袭结算。

## 已处理的问题

- Lua Condition 的嵌套左右式只编译一层，且 allowDecline 没有进入执行节点；现在递归编译并保存选择属性。
- 通用可选 Effect 原来只有放弃路径；现在通过 continue / decline 选择执行或放弃，仍兼容旧布尔放弃答案。
- 雷蛇和德克萨斯计谋把费用放在最后；现在 Lua Condition 左侧先扣 3 金券，右侧才逐步产生目标。德克萨斯真实移除后再移动，每步重新计算候选，以稳定 InfluenceId 排除重复移动。
- 极境计谋原先调用专用城市修改服务，绕过完整城市移动 Effect；现在 PayResource → 普通 MoveCity，目标限制为相邻、已探索、有本方影响力。
- 锡人策略首次拒绝会提前终止；现在是无条件得 1 分、两次独立可放弃 Condition，价格为 12、15 金券。
- 城市样式原先同一步同时挂付款子节点与内容事件，并提前计算右式候选；现在内容事件位于 Condition 右侧。
- 复合动力原先重复叠加目录已含的 1 源石费用；现在只计一次。组合支付作为左侧请求，整组余额重新验证后原子扣除；移动和事件完成后，Lua continuation 才请求沿途影响力放置。
- 高效移动原先提前取两个候选地点；现在先支付，之后两个 MoveCity 独立、顺序产生实时目标。
- PlaceInfluence 的限定候选支持恢复与复核；显式空范围不可放宽为全地图。
- 原有材料选择弹窗、角色选择弹窗和地图高亮继续复用；支付等待主机确认期间禁止重复提交或重开。

## 层级与恢复边界

- Application 只激活或提交有身份和版本的交互答案。
- Lua 组合 Condition 和基本 Effect；五项角色能力仍保留有明确边界的内容适配。
- Domain 内核拥有支付、节点创建、目标复核、状态提交与恢复；Presentation 只展示投影和反馈。
- `ResourcePaymentChoiceEffectExecutor` 是通用宿主组合支付机制，当前仅由复合动力工厂使用，尚未暴露为新的 Lua 构造器。
- 角色执行器版本提升至 1.2.0，条件式角色内容 1.3.0；城市移动执行器与特殊行动执行器升至 1.1.0，复合/高效移动内容 1.1.0。旧版本节点不能静默使用新执行顺序；恢复须匹配目录版本，当前未提供旧版对局升级器。
