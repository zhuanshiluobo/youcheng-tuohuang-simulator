# 基础设施迁移与 UI 边界回归

## 已实施

1. 载具仓库改成完整 Lua 两分支，移除后调度逐段选择；探索按路线、落点、收费方、事件依次结算。
2. 额外建设和储备建设复用通用选择原语，明确选择支付方式和位置，效果授予建设不扣主要行动次数。
3. 联邦理事处使用 OverrideNextStartPlayer，在回合边界应用并清除；源石工业枢纽使用 GrantMainActions。
4. 设施颜色费用减免由外部 costReductionPerDistinctBuiltColor 定义，查询和支付共用计算，不再由正式目录的固定 effectId 决定。
5. 14 种入场模板全部脱离旧适配；设施 Behavior、旧 facility_entry 和城市样式 ScriptStep 执行分支撤下。
6. 内核同节点同类交互采用持久化累计序号，修复多阶段交互 ID 冲突；设施 renderer 接入统一请求路由。
7. 自动跑局由外层注入 LuaContentCatalog，撤下 Application 到 Infrastructure 的跨层反射，共用同一个回合服务。

新增测试覆盖两种建设支付、储备建设与跳过、资源选择前不提交、恢复与重复提交、路线回退、多收费方选择、起始玩家实际跨回合应用和清除、新 effectId 的数据折扣，以及正式入场脚本不再调用旧适配。
