## 测试中修复

1. 编译：明确 UnityEngine.Application 命名空间，增加可持久化的多分支分组构造接口。
2. 德克萨斯连续移动：同节点的连续请求增加步骤编号，避免回答错配到前一个请求。
3. 坎诺特出售：识别正式 UI 回答的 StableReference 编码，保持全零有效。
4. Choice：登记 branches 参数，执行时只创建所选分支，拒绝混用字符串选项和多选数量。
5. 外部贴图：场景切换/测试清理会使缓存的 Texture2D 失效；缓存现在保护资源并识别失效对象重新解码。UI 测试改验真实外部图像合同，其他 UI 禁止直接读文件/LoadImage 的约束保留。
6. 核心定义 JSON：规范旧目录中的空字符串，保留原 Domain 初始化合同。
7. 角色使用：注册关系按本局 Registry 隔离，旧未完成专用节点明确停止，禁止静默换规则恢复。
