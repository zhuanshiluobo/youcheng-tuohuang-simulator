# 顶栏行动玩家提示定向验收

日期：2026-09-28。Unity：2022.3.62f1c1。

## 结论

本次顶栏行动玩家提示的功能验收通过：2 项 PlayMode 测试通过、0 项失败。检查了两张实际场景生成的 12 张 1920×1080 截图，文字完整、颜色随行动玩家更新，切回本机恢复原色，使用真实粗字体。

黄色文字与既有黄色标签底图的对比较弱；颜色符合用户要求的玩家标记配色，但此项视觉观察仍需保留，不能据此宣称所有配色的可读性均无问题。本轮未更改标签底图或玩家配色。

## 受测来源与范围

- 加载 `Assets/Scenes/SampleScene.unity`、`Assets/Scenes/ThreePlayerScene.unity`，测试各场景实际 `GameplayHudFrame` 实例，包含场景覆盖；不是只检查源预制体。
- 使用独立内存 `GameState` 和 `ActionPanelViewModel` 传入正式 `Refresh`，没有向游戏会话提交命令。三人地图中的黄色玩家用于覆盖颜色显示分支，不代表实际创建了第四个玩家席位。
- 范围是当前行动提示的动态文案、玩家颜色、恢复行为、字体和实际渲染；未验证整局轮转、网络同步、多分辨率及任意长度玩家名。
- 运行测试期间没有调用 UI 生成器、资产 Rebuild 或保存覆盖方法。两张场景和主 HUD 预制体在最终测试前后 SHA-256 一致。

## 验收中修正的问题

首次画面检查发现原 154 宽文本框会把“红色玩家正在行动”的末字截掉。已在源预制体开启字号自适应，最大 20、最小 12，保留原文本框位置和尺寸。修正后的两场景定向测试全部重跑通过，并重新检查了全部截图。

测试脚本显式展开辅助协程，并在 TearDown 检查完成标志，防止辅助协程只加载场景后便提前结束而被误认为通过。最终结论仅使用带完成标志和实际截图的最后一轮结果。
