# 后续扩展目标

## 1. 总体原则

后续扩展目标用于记录方向，但不进入 MVP 阻塞链路。当前优先级始终是基础版规则闭环、日志、回放和测试。只有当规则核心稳定后，才逐步推进 UI、美术、AI、联机和企业扩展版。

## 2. 完整桌面 UI

### 目标

把 Debug 或占位操作升级为可长期使用的桌面模拟器界面。

### 计划内容

- 地图底图显示三人和四人地图。
- 资源点、航道、影响力槽、城市停靠点作为可交互热点。
- 玩家资源面板展示金券、源岩、源石、异铁、至纯源石、VP 和影响力供应。
- 卡牌区展示手牌、盖放角色牌、设施供应区、城市样式牌。
- 行动面板展示当前合法主要行动和快速行动。
- 结算预览展示费用、收益、影响力变化和非法原因。
- 日志面板展示命令与规则事件。

### 进入条件

- Domain 状态机和主要行动已通过测试。
- 基础地图数据稳定。
- 命令校验能返回明确非法原因。

## 3. AI 玩家

### 目标

让 AI 和人类玩家一样通过命令系统操作游戏，先实现可跑通游戏的贪心 AI，再考虑更复杂策略。

### 计划内容

- 获取当前合法命令列表。
- 为命令建立简单评分函数。
- 自动选择主要行动、快速行动和待处理选择。
- 支持随机模拟，用于压力测试和规则漏洞发现。

### 进入条件

- 合法命令枚举稳定。
- 回放系统可复现 AI 操作。
- 基础规则没有频繁破坏性改动。

## 4. 联机同步

### 目标

在规则核心确定性和命令可序列化的基础上，支持本地或远程多人同步。

### 计划内容

- 所有随机来自统一 seed。
- 所有状态变化由命令产生。
- 命令序列可序列化和校验。
- 表现层动画不影响规则状态。
- 支持断线后通过状态和命令日志恢复。

### 进入条件

- 回放系统稳定。
- 命令和状态版本化方案明确。
- 规则核心无 Unity 场景依赖。

## 5. 企业扩展版

### 目标

在不推翻基础版架构的前提下，接入企业扩展版规则。

### 计划内容

- 引入 `RuleSet.Basic` 和 `RuleSet.EnterpriseExpansion`。
- 通过规则开关接入新增阶段、命令、效果触发器、卡牌定义和校验规则。
- 对基础版回放建立回归测试，防止扩展规则污染基础版。

### 进入条件

- 基础版完整规则闭环稳定。
- 效果系统能承载大部分普通卡牌效果。
- 数据结构允许按 ruleset 加载不同定义。

## 6. 动画、音效和表现

### 目标

在规则正确的基础上增强桌面体验，让操作反馈更清楚、更有节奏。

### 计划内容

- 影响力放置、移动和移除动画。
- 移动城市移动动画。
- 卡牌使用和建设反馈。
- 资源获得和支付反馈。
- 关键计分和胜负结算表现。
- 基础音效和提示音。

### 进入条件

- GameEvent 类型稳定。
- Presentation 能从事件驱动动画，而不是反向修改规则。

## 7. 新手引导与规则解释

### 目标

降低玩家理解成本，让模拟器不仅能跑规则，也能解释规则。

### 计划内容

- 当前阶段说明。
- 合法行动提示。
- 非法操作原因。
- 费用和收益预览。
- 关键术语说明。
- 回合流程提示。

### 进入条件

- UI 主要流程稳定。
- Validator 能返回结构化错误原因。
- 日志格式可读。

## 8. 工具与编辑器

### 目标

提升数据维护效率，减少手工录入错误。

### 计划内容

- 地图热点坐标编辑器。
- 卡牌定义检查工具。
- 效果定义校验器。
- 回放查看器。
- 快速造局 Debug 面板。

### 进入条件

- 数据格式稳定。
- 至少完成一轮手工数据录入并暴露维护痛点。

## 9. 明确不提前做的事

- 不在规则闭环前追求完整视觉还原。
- 不在命令系统稳定前做联网。
- 不在基础版测试稳定前接企业扩展版。
- 不让 AI 拥有绕过规则校验的特殊权限。
- 不让表现层动画成为规则状态来源。
