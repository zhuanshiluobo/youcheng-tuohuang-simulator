# MVP 规则闭环计划

## 1. 总体目标

MVP 的核心不是漂亮 UI，而是让基础版游戏能够从开局跑到最终计分，并且每一步都能被命令、状态、事件和日志准确描述。只要规则闭环成立，后续 UI、美术、AI 和联网才有稳定地基。

完成 MVP 后，应能用占位界面或 Debug 工具完成一局 3 到 4 人基础版热座游戏，并得到可复查的最终结算明细。

## 2. 地图图模型

### 目标

把三人和四人地图从图片转化为规则可查询的图结构。图片只作为表现层底图，规则判断必须依赖结构化地图数据。

### 需要建立

- 资源点：id、颜色、所属区块、资源槽、影响力槽、事件槽、是否可停靠城市。
- 航道：id、起点、终点、影响力槽、费用计算所需属性。
- 区块：id、颜色或区域类型、包含资源点、计分值。
- 地图面：三人地图、四人地图及其适用玩家数。

### 完成标准

- 能查询任意资源点的相邻资源点。
- 能查询两个资源点之间是否存在航道。
- 能列出资源点所属区块。
- 能枚举一个区块内用于控制计算的影响力来源。
- 三人和四人地图可以通过同一套接口加载。

### 暂缓内容

- 地图热点可视化编辑器。
- 自动从图片识别节点和航道。
- 精确 UI 坐标微调。

## 3. 玩家与游戏状态

### 目标

建立完整、可序列化的 `GameState`，让任意时刻的局面都能保存、恢复、测试和回放。

### 需要建立

- 游戏阶段、回合数、当前起始玩家、当前行动玩家、行动轮次。
- 玩家列表、座次、颜色、资源、分数、手牌、盖放角色牌、弃牌区。
- 玩家移动城市位置、影响力供应堆、地图上的影响力、已建设施、已宣告城市样式。
- 地图开放状态、事件牌、资源指示物、航道影响力、区控缓存。
- 牌堆、弃牌区、设施供应区、城市样式状态。
- 待处理选择和操作日志。

### 完成标准

- 状态对象不依赖 Unity 场景对象。
- 状态可以序列化为 JSON 或等价结构。
- 每个玩家的资源和影响力数量能够通过测试验证不出现非法负数或数量丢失。

### 暂缓内容

- 存档 UI。
- 云存档。
- 多版本存档迁移。

## 4. 阶段状态机

### 目标

实现基础版固定流程：`Setup -> Entrance -> RoundStart -> CharacterCover -> ActionRound1 -> ActionRound2 -> ResourceCollection -> Cleanup -> FinalScoring -> GameOver`。

### 完成标准

- 状态机只暴露当前阶段允许的命令。
- 8 回合后自动进入最终计分。
- 每轮行动从起始玩家开始，按座次推进。
- 每回合包含两轮玩家行动。
- 阶段推进可被日志和测试验证。

### 暂缓内容

- 企业扩展版新增阶段。
- 可配置流程脚本。
- 联机断线恢复流程。

## 5. 命令校验与结算

### 目标

所有玩家操作都使用命令表达，并经过统一流水线：提交命令、校验、结算、生成事件、记录日志。

### 必备命令

- 选择起始玩家。
- 选择初始资源点。
- 结算入场事件。
- 盖放角色牌。
- 部署影响力。
- 调度影响力。
- 探索资源点。
- 移动城市。
- 建设设施。
- 使用角色牌。
- 宣告城市样式。
- 使用特殊行动。
- 采集资源。
- 处理待选择项。
- 结束行动。

### 完成标准

- 非法命令返回明确原因，不修改状态。
- 合法命令只通过 resolver 修改状态。
- 每个命令都能生成可读日志。
- 每个关键命令都有单元测试覆盖成功和失败路径。

### 暂缓内容

- 撤销已结算命令。
- 网络命令同步。
- AI 命令选择。

## 6. 主要行动

### 部署

目标：放置 1 个影响力到合法资源点或航道槽位。

完成标准：校验行动权、槽位、影响力供应、目标开放性和阶段窗口。

### 调度

目标：移动 1 个影响力并执行 2 次，允许规则许可下的分步选择。

完成标准：每次移动都校验来源、目标、路径和槽位，日志记录两次调度结果。

### 探索

目标：支付路费，结算目标资源点事件，在目标点放置影响力并开放资源点。

完成标准：可枚举路径，可处理支付对象选择，可生成事件选择项，可放置资源指示物。

### 城市移动

目标：支付 3 源石移动城市，并在出发点放置影响力。

完成标准：校验资源、目标、路径和城市停靠规则，按规则处理路径与目标点上的对手影响力。

### 建设

目标：支付设施费用，放置设施牌，结算分数和入场效果。

完成标准：校验费用、设施供应、建设限制和城市面板位置，结算入场效果并记录分数来源。

## 7. 快速行动与卡牌接入点

### 目标

MVP 保留快速行动窗口，并先接入能支撑基础版流程的最小角色牌和城市样式能力。

### 完成标准

- 主要行动前后都能执行任意数量合法快速行动。
- 使用角色牌会检查本回合盖放牌、费用、窗口和使用次数。
- 宣告城市样式会检查条件并标记本回合状态。
- 效果系统至少支持获得资源、支付资源、得分、放置影响力、移动影响力、抽牌、标记城市样式等基础操作。

### 暂缓内容

- 所有复杂卡牌特例。
- 华丽卡牌动效。
- 卡牌收藏或构筑系统。

## 8. 采集、收尾与最终计分

### 采集资源

目标：两轮玩家行动后，玩家选择可采集资源点并支付连接路费获得资源。

完成标准：同一采集阶段同一航道只支付一次路费，不能使用本阶段刚获得的金券支付本阶段路费。

### 收尾

目标：结算收尾阶段效果，复位城市样式标记，传递起始玩家，推进回合。

完成标准：回合 1 到 8 可稳定推进，不产生卡死或跳阶段。

### 最终计分

目标：结算区块控制、剩余资源、设施、城市样式和平局判定。

完成标准：输出最终分数明细，平局依次比较剩余金券和剩余至纯源石，仍相同则共同胜利。
