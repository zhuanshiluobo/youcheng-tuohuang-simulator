# 数据与素材整理计划

## 1. 总体目标

数据与素材整理的目标，是把 `F:\hby\游城拓荒` 下的规则资料和素材逐步转换为模拟器可加载、可测试、可维护的结构化资源。MVP 阶段先保证规则数据完整，视觉素材用于占位和识别，不追求最终美术表现。

- 规则书：`F:\hby\游城拓荒\规则书`
- 总体架构：`F:\hby\游城拓荒\总体架构`

- 素材：`F:\hby\游城拓荒\素材`
- 三人地图：`F:\hby\游城拓荒\素材\地图\三人.jpg`
- 四人地图：`F:\hby\游城拓荒\素材\地图\四人.jpg`

## 3. 数据优先级

### 第一优先级：地图规则数据

建立三人和四人地图的结构化定义：

- 地图 id、名称、适用玩家数。
- 资源点列表。
- 航道列表。
- 区块列表。
- 初始可选绿色资源点。
- 影响力槽位数量。
- 城市可停靠点。

完成标准：不依赖地图图片，也能完成路径、采集、探索、区控和城市移动规则判断。

### 第二优先级：基础资源与图标映射

整理基础资源类型：

- 金券。
- 源岩。
- 源石。
- 异铁。
- 至纯源石。
- VP。
- 影响力。
- 城市移动、部署、调度、建设、快速行动、特殊行动等行动图标。

完成标准：每个规则资源都有稳定 id、显示名和可选图标引用。

### 第三优先级：卡牌定义

按类型整理卡牌数据：

- 角色牌：策略效果、计谋效果、费用、使用窗口。
- 事件牌：颜色、事件选项、奖励、惩罚、资源指示物。
- 设施牌：颜色、费用、分数、入场效果、限制关键字。
- 城市样式牌：宣告条件、宣告奖励、特殊行动和计分规则。

完成标准：卡牌文字和效果参数分离，牌面图片不作为规则来源。

### 第四优先级：效果定义

采用轻量数据化效果：

- 触发器：角色牌使用、事件结算、设施建造、设施入场、城市样式宣告、特殊行动、采集、收尾、最终计分。
- 条件：资源、阶段、玩家状态、地图状态、设施状态、城市样式状态。
- 费用：资源和金券。
- 操作：获得资源、支付资源、得分、放置影响力、移动影响力、移除影响力、移动城市、抽牌、翻牌、建设设施、标记城市样式。

完成标准：普通效果可以通过枚举类型和参数表达，特殊效果允许挂专用处理器。

## 4. Unity 资产归类建议

后续导入 Unity 项目时建议使用：

```text
Assets/
  Data/
    Maps/
    Cards/
    Effects/
    Scoring/
  Art/
    Board/
    Cards/
    Tokens/
    UI/
```

### Maps

存放地图结构定义和热点坐标。三人、四人地图必须共享同一套读取接口。

### Cards

存放角色牌、事件牌、设施牌和城市样式牌定义。规则定义与牌面图片引用分离。

### Effects

存放效果定义，避免把效果散落在行动 resolver 和 UI 组件中。

### Scoring

存放区块分值、资源折算、设施计分和城市样式计分规则。

### Art

存放从 `素材` 目录整理出的图片资源。MVP 阶段只要求可识别，不要求最终视觉品质。

## 5. 命名规范

- 规则 id 使用英文稳定 id，例如 `source_stone`、`facility_core_command_tower`、`map_three_players`。
- 中文显示名放在 `displayName` 或等价字段中。
- 图片文件保留原始中文名也可以，但规则数据引用应使用稳定 id。
- 地图节点建议使用区域和序号，例如 `B-01`、`G-03`。
- 航道建议使用两端节点组合，例如 `B-01_B-02`。

## 6. 暂缓内容

- 完整 OCR 自动录入。
- 自动切牌和图片识别。
- 复杂素材打包和图集优化。
- 多语言本地化。
- 面向玩家的卡牌收藏浏览器。

## 7. 验收标准

- 能从结构化地图数据完成路径、费用、区控和采集测试。
- 每种基础资源都有 id、中文名和图标映射。
- 卡牌规则效果不依赖图片识别。
- 数据变更能通过单元测试或回放测试发现规则破坏。
