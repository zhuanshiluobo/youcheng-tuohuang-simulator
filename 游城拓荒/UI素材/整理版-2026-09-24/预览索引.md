# UI 预览索引 · 2026-09-24

本目录的 PNG 均为源包原样副本。Frontier 主界面与各专用窗口的静态拼装由源包提供；选项窗口的两张图是视觉样例，精确位置以配置和原说明为准。它们均不是本次 Unity 运行截图。

当前采用关系是主界面内容基线 2.2 + Frontier 组件及顶栏 3.1。其他窗口还保留历史主题，需要按新版映射适配，不能将下方历史预览当成已完成新版换肤的证明。
