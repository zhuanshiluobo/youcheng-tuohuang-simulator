# CardViewer v3.6：贴图与文字布局

独立的卡牌查看窗口。快速行动列表仍承载全部快速行动；其中“使用角色牌”调用本窗口的使用模式。设施牌、手牌、弃牌区和盖放区的查看共用普通查看模式。

## 素材复用

本包的 `assets/window.png`、`button-primary.png`、`button-secondary.png` 与最初 `Card-Picker-UI-v1.zip` 中的对应文件字节一致。没有重新绘制背景，也没有将按钮或文字合并进背景。

原窗口底图已包含边框、背景纹理以及约局部 `y=701` 的分隔线。它是已有的合并底图，不能当成新增的独立九宫格边框使用。按下表等比展示整套窗口；卡牌和按钮在其上独立排列。

`preview/originals/` 里的原始卡图仅供演示。角色样本使用图包中的坎诺特；设施样本使用未知科技；盖放样本显示卡背。这些样本不代表一局游戏中的真实可用行动。运行时应传入游戏自己的卡图。

## 卡牌比例

设卡图或图集单元的原始尺寸为 `(cw,ch)`，容纳区为 `(x,y,w,h)`：

```js
const scale = Math.min(w / cw, h / ch);
const width = cw * scale;
const height = ch * scale;
const left = x + (w - width) / 2;
const top = y + (h - height) / 2;
```

`600×850` 的竖卡最终显示为约 `393.882×558`，局部左上角约 `(690.059,126)`。其他比例按自身尺寸计算；不可强制压成 `12:17`，也不可用 cover 裁掉卡面。

两种模式共享这个容纳区，按钮显隐不会推动卡牌。卡面本身已经有完整设计，本窗口不再叠加选中勾、槽位装饰或编号。

## 按钮的透明边距

两张原始按钮 PNG 画布均为 `1983×793`，经过校准的可见矩形为 `(35,102,1916,582)`。不要把整张含透明边距的 PNG 直接当作按钮的点击区域。

将源可见区域映射到 `280×84` 的目标按钮：

```js
textureLeft = buttonX - 35 * 280 / 1916;
textureTop = buttonY - 102 * 84 / 582;
textureWidth = 1983 * 280 / 1916;
textureHeight = 793 * 84 / 582;
```

最终裁切到按钮目标矩形，点击区域也是该矩形。按钮文字独立居中；普通、悬停、按下、不可用通过运行时着色表达，键盘焦点额外加轮廓。本包不声称提供各状态的新绘制贴图。

## 屏幕适配与接入

```js
const uiScale = Math.min(screenWidth / 1920, screenHeight / 1080);
const offsetX = (screenWidth - 1920 * uiScale) / 2;
const offsetY = (screenHeight - 1080 * uiScale) / 2;
```

整套逻辑画布等比缩放并居中，遮罩铺满实际屏幕。不要分别拉宽底图、卡面和按钮。背景外的遮罩用于关闭窗口；窗口内部点击不会关闭，也不会穿透到主界面。

交互与入口约定见 `INTERACTION.md`，数据结构见 `integration/viewer-schema.json`。`integration/card-viewer.js` 与 CSS 是可复用的浏览器参考组件；其他引擎可使用同样的显隐逻辑和 `layout.json` 坐标。

本补丁是独立窗口资源与参考实现，不会修改主界面的快速行动列表、游戏规则或用户工程。
