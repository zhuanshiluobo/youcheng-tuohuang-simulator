# 主界面按钮补丁 v3.2

适用于 `FrontierUI-v3-Patch` 内部版本 v3.1，重新制作右下三个页签、六个主要行动按钮，以及底栏的撤销和结束行动按钮，共 11 个按钮喵。

按钮分成三类设计：紧凑扁平的页签、强调图标的主要行动块，以及低调的撤销和醒目的结束行动按钮，只共享石墨灰、象牙白和工程黄的配色与质感喵。

各类按钮都使用完整轮廓，去掉旧版缺角造型喵。

## 内容

- 按钮底板、独立图标和状态贴图，文字由游戏运行时绘制喵。
- 正常、悬停、按下和禁用状态，以及页签的选中状态喵。
- 按钮映射、坐标和接入说明见 [BUTTON_PATCH.md](BUTTON_PATCH.md) 喵。

## 使用范围

本补丁只更新这 11 个按钮的外观与预览接线，保留原有底栏结算槽、其他主界面模块和已有窗口喵。

“设施供应区”按钮不属于这次替换范围喵。

解压素材不等于已经接入游戏规则，实际游戏仍需根据按钮映射绑定文字、点击事件和可用状态喵。

## 应用到已有预览

保留已解压的 `FrontierUI-v3-Patch` 内部 v3.1 目录，在本补丁目录运行下列命令，将引号中的路径替换为基线目录喵。

```bash
python tools/apply_patch.py "已解压的FrontierUI-v3-Patch目录"
```

脚本校验基线关键文件，备份被覆盖的旧文件，再安装新素材与预览覆盖文件，具体备份位置会打印在终端中喵。

安装后的新素材位于基线目录的 `button-assets-v3.2/`，原始卡面与城市面板继续复用基线文件喵。

`preview/` 提供静态预览和可离线打开的 `button-sheet.html` 状态展示页喵。
