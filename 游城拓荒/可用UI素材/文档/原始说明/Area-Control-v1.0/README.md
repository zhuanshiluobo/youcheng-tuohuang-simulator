# 区控页面素材包 v1.0

页面显示各区的分值、当前各玩家影响力和当前影响力空格数。四人地图为八行，三人地图为七行、不显示 G 区；玩家列按实际参与者生成，颜色绑定玩家身份，不绑定列序号。

## 贴图拆分

- `assets/window/`：页面底板、透明边框、全屏遮罩。
- `assets/header/`：标题栏底图、细黄标记和区控图标。
- `assets/table/`：表头底板、交替行底图、横/竖分隔线、分值徽章。
- `assets/player-markers/`：企业合作区原有的绿、黄、蓝、红四种方块和中性空方块。逐文件复制，未重绘、未换色。
- `assets/region-squares/`：从 `Region-Squares-v1.0` 拓展包逐文件复制，分别对应 A/B/C/D/E/F/G/R。页面已实际引用这些素材。

所有运行时贴图不带区名、标题、分数、影响力数字或关闭提示；这些文字单独绘制。每个玩家单元格由原合作方块与数字文本组成。最后一列使用中性空方块和“空格数”，避免混淆为第五名玩家。

## 空格数的数据口径

`emptySlotCount = 该区槽位中 isEmpty === true 的数量`。

空格数读取槽位真实状态，不用“槽位总数减去影响力总和”反推；影响力数值可能受到效果修正，非玩家组件也可能占用槽位。是否为空由游戏规则层判定，本 UI 只统计和显示。

`data/map-regions.json` 列出两张地图的每个槽位 ID 及区域归属，沿用之前地图定位包的资源点、航道 ID。资源点与航道的槽位均纳入统计，B-01 按普通资源点处理，不包含其入场奖励。

| A区 | 9 | 9 |

## 接入

1. 窗口底板、边框、标题栏、表格独立摆放。透明边框用九宫格 `[20,20,20,20]`；2× 素材使用 `[40,40,40,40]`，不直接拉伸整框。
2. 玩家标记和区域方块保持 1:1 比例。推荐区域方块显示 40–48、玩家方块显示 28–36；按界面密度调整。方块本身不做九宫格拉伸。
3. 所有彩色方块以 sRGB、白色 Tint、Alpha 1 使用，不叠加预览中的淡色滤镜；颜色应与 `data/palette.json` 一致。
4. 数字、分值与区名均是独立文本。四人地图 E/F 为 4 分，其余为 3 分；三人地图同样保留 E/F 的 4 分。
5. 不生成关闭、确认、返回按钮。页面打开后，由全屏遮罩捕获下一次完整点击/触摸释放并关闭，同时吞掉事件，避免点到后方主界面。不要把打开页面的同一次 pointerup 当作关闭事件。

`logic/region-control.mjs` 是与引擎无关的数据整理示例；`preview/four-player.html` 与 `three-player.html` 可离线查看实际素材的拼装。页面中的任意位置点击都会关闭预览，刷新可重新打开。PNG 预览仅供核对，不是整页烘焙运行时贴图。
