# 新增信息入口按钮 v1.0

包含“区控”和“游戏盒”两种按钮。区控为蓝灰色，游戏盒为暖棕色，与原主要行动的石墨绿灰区分。沿用旧按钮完整轮廓、象牙白线性图标和细双线边框。

## 素材

| 内容 | 文件 | 原始尺寸 |
| --- | --- | --- |
| 按钮底图 | `assets/bases/region-{state}.png`、`game-box-{state}.png` | 256×64 |
| 独立填充 / 边框 | `assets/layers/fill/`、`assets/layers/frame/` | 256×64 |
| 图标 | `assets/icons/region-light.png`、`game-box-light.png` | 64×64 |
| 图标颜色 | `light`、`muted`、`dark` | 同一几何尺寸 |
| 分隔线 | `assets/divider.png` | 2×40 |

`state` 为 `default / hover / pressed / disabled`。所有底图均不含文字和图标。可直接用完整底图；使用拆分图层时按填充、边框顺序叠加，不能再叠一份完整底图。

按钮底图提供 1×、2× PNG 和 SVG；按九宫格缩放，1× 切片 `[12,12,12,12]`，2× 切片 `[24,24,24,24]`，顺序为左、上、右、下。推荐按钮高度 48–64，最低 44；边框与角不随按钮宽度被拉粗。

## 图标大小

| 按钮逻辑高度 | 图标方形画布 | 建议文字字号 |
| ---: | ---: | ---: |
| 48 | 32×32 | 20 |
| 56 | 36×36 | 22 |
| 64 | 40×40 | 24 |

64×64 是源文件画布，不是强制显示尺寸。区控图形有效范围为 54×53，游戏盒为 50×51；在 36×36 画布中可见图形约 28–30。两个图标已按相近视觉重量绘制，并留足安全边距。

图标另有 32、40、48、64、128 像素 PNG：分别为 `@0.5x`、`@0.625x`、`@0.75x`、无后缀和 `@2x`。始终等比缩放，不能跟随按钮底图做九宫格拉伸。禁用状态同时换为 `muted` 图标与低对比文字，避免只有底图变暗而图标仍像可点击。

文字运行时绘制，普通状态推荐 `#EEEBDD`。贴图以 sRGB 导入，保留 Alpha。`assets.json`、`buttons.json` 提供尺寸、状态和绑定关系。`preview/` 是使用本包实际 PNG 拼装的尺寸与状态检查图，不是游戏运行时贴图。
