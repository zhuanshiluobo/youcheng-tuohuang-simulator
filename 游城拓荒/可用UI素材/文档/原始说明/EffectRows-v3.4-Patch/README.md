# 通用效果条目增量补丁 v3.4

本补丁更新 EffectRows 的视觉样式：底图改为暖灰棕与轻微纸面纹理，边框改为米灰色细线，工程黄用于可执行入口与交互强调，以贴合现有主界面的暖色调喵。

选择执行的选项、其他玩家的永续效果明细和快速行动继续共用同一可切换模式的条目，底图、边框、玩家标记与右侧状态图标仍分别提供喵。

v3.4 是视觉更新，保留 v3.3 的模式、字段、插槽、交互和布局约定，素材引用继续兼容 `v33-` 标识喵。

左上玩家面板的查看入口沿用展开／收起控件，明细向下展开，后面的玩家面板顺次下移，同时压缩“我的城市”区域的高度喵。

## 使用入口

- `EFFECT_ROW_PATCH.md`：模式、状态、条目尺寸、左侧展开布局和引擎接入说明喵。
- `prefab-contract.json`：数据字段、模式约束、布局参数与示例数据喵。
- `assets/`：条目底图、独立边框、图标及玩家标记素材喵。
- `preview/`：新版外观预览、旧版对照与交互示例喵。

本补丁提供可复用的界面组件规范、SVG／PNG 素材与 HTML 预览，不是 Unity 的二进制或 YAML `.prefab` 文件喵。

## 三种用法

| 模式 | 左侧玩家标记 | 右侧状态／操作 |
| --- | --- | --- |
| 选择执行 `choice_execute` | 固定隐藏喵。 | 固定使用 `use` 图标，由规则层决定可用或禁用喵。 |
| 永续明细 `persistent_detail` | 可放零、一或两个拼色方块喵。 | 可不放图标，也可显示只读状态或可执行图标喵。 |
| 快速行动 `quick_action` | 可放零、一或两个拼色方块喵。 | 按具体效果显示只读状态、使用图标或隐藏喵。 |

左右区域隐藏时回收宽度，正文自动填满，不保留空白列喵。

`used` 与 `unused` 是只读状态，`use` 才是操作入口，禁用的 `use` 与已使用状态明确分开喵。

预览中的卡名、效果文字、数量与可用状态均为排版示例，不构成游戏规则结论喵。

## 查看与应用

直接打开 `preview/effect-rows.html` 即可查看三种模式的离线交互演示，无需先安装到主界面喵。

完整主界面可在已应用 v3.2 按钮补丁的 v3.1 基线上直接安装本版，也可从已安装 EffectRows v3.3 的同一主界面升级，无需先安装 v3.3 喵。

在本补丁目录执行下列命令，参数指向完整主界面根目录喵。

```bash
python tools/apply_patch.py "FrontierUI-v3-Patch完整目录"
```

目标目录需包含既有主界面和卡牌资源，不是单独的 v3.2 或 v3.3 增量补丁文件夹喵。

安装脚本会校验受支持的基线与补丁文件，并在替换前备份目标文件，检测到不匹配的修改时会停止喵。

集成素材安装到 `effect-assets-v3.4/`，主界面使用的条目渲染模块为 `preview/effect-row.mjs`，包内通用源码仍为 `components/effect-row.mjs` 喵。

新旧补丁包分别保留，升级不会覆盖原先下载的交付包喵。

实际游戏接入请阅读 `EFFECT_ROW_PATCH.md`，由现有规则层处理执行请求、使用状态与玩家标记数据喵。
