# 房间页与说明页 UI 素材包 v1.1 · 地图上下排列

地图改为上三人图、下四人图，模式／扩展包／当前配置放在地图右侧。两张地图完整等比显示。保留房主的“设置密码”入口，以及说明页和非房主的“准备／取消准备”按钮。正式贴图的文字与图标分开，便于调整尺寸、位置和文案。

## 查看与导入

1. 解压后打开 `PREVIEW.html`，切换查看房主、满 4 人、关闭座位、非房主两种准备状态、说明页、密码弹窗与控件表。这些图使用包内实际 PNG 拼装。
2. 导入 `assets/` 中需要的 PNG。主要贴图提供 1×、2×；原有玩家方块保留 64×64 原图。两种分辨率应绘制为相同逻辑尺寸。
3. 按 `assets.json` 或 `ASSET_MANIFEST.md` 设置九宫格边界；贴图填充、边框、文字和图标分别叠加。
4. 使用 `ROOM_UI_GUIDE.md` 查看布局与交互规则，`layout.json` 查看具体坐标，`button-bindings.json` 查看控件和图标对应关系。

## 本包包含

- 全屏底图、高清整屏边框、独立顶栏与底栏。
- 模块纸面、模块框、标题条、座位信息条、头像底图与框。
- 浅色、黄色、深色三组按钮，每组普通／悬停／按下／禁用四态；完整底图和分离的填充／边框同时提供。
- 换位、移除、邀请、热座、人机、关闭座位、复制、说明、密码、准备、开始、返回等独立图标。
- 地图选项框、选中／禁用状态、勾选框、输入框，以及说明页的纸面、关闭控件、竖直滚动条。
- 引擎无关的 UI 状态辅助函数与针对地图规则、权限、座位变更的检查结果。

## 已确认规则

地图由房主手动选择；未满 4 人可以选择三人图或四人图。**仅在 4 个座位都有玩家时强制四人图**。空座位、等待邀请的位置、关闭座位不计数；人数减少后保留当前地图。没有独立的“游戏人数”选择控件。

颜色固定在四个座位上，换位后使用新座位的颜色。移除玩家让位置变为空座，不会关闭位置；已有人位置不提供“关闭座位”。房主右下角为开始游戏，非房主为准备／取消准备。密码设置入口仅房主可见，已有密码时文案为修改密码。

## 文件用途

`assets/` 是正式 UI 皮肤；`sources/` 是 SVG 共用的图像来源，移动 SVG 时请保留相对路径，PNG 不依赖它。`preview/` 为拼装检查图与展示用原图，不是应烘焙进底板的界面内容。预览里的地图、头像来自已有图包；扩展包名称和说明正文是示例。

`components/room-ui-state.js` 是 UI 规则接入参考，不是联网房间服务或引擎预制体。`PREVIEW.html` 是静态状态预览切换器，不发送邀请或修改真实房间。已检查素材、布局状态函数及文件引用，尚未在用户的游戏引擎内导入测试。
