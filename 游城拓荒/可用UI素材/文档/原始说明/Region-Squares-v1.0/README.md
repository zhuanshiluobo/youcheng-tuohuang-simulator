## 文件

- `assets/framed/region-A-64.png` 等：64×64 透明边角方块，内部色面为 48×48。`@0.5x` 为 32×32，`@2x` 为 128×128。
- `assets/flat/`：没有边框的纯色色块，64×64 和 128×128；可用于完全平面的图例。
- SVG：可编辑源文件，框的原始像素直接内嵌，颜色以精确十六进制值绘制。
- `palette.json`：区色、分值、两种地图的区域顺序及采样依据。
- `verification/`：从两张原地图无损裁出的图例，供核对。

## 颜色口径

原图为 JPEG，色块内存在少量压缩波动。本包在色块内部 17×17 像素中选取出现次数最多的原始 RGB 三元组，不平均近似、不使用预览图取色。七个共同区域已在三人原图交叉核对；G 区仅存在于四人地图。

E 区使用 `#EBA93B`，G 区使用 `#439E72`，这是原图内部主色的复核结果。三人地图使用 A、B、C、D、E、F、R，不能把 R 替换成白色。

导入时使用 sRGB、保留 Alpha；UI Tint/Color 设为白色，Opacity 为 1，避免额外颜色滤镜或有损纹理压缩。方块保持等比缩放，不做九宫格拉伸。透明边角不是纯色内部的一部分。
