# 游戏盒 UI 图包 v1.0

用于查看放回游戏盒的组件。沿用已确认的暖纸底色、深色标题条和细边框，窗口、顶栏、模块均可单独调整。当前包包含 27 类 UI 贴图、1× / 2× PNG、SVG 源文件、拼装预览、布局参数与接入说明。

## 从这里开始

- `preview/main.png`：使用本包 PNG 实际拼装的界面预览。
- `preview/asset-sheet.png`：底板、边框、图标等拆分展示。
- `PREVIEW.html`：解压后用浏览器打开，可查看两类牌堆、滚动 Token、点击空白关闭。它是接入参考，不是引擎预制体。
- `GAME_BOX_UI.md`：布局、文字位置、事件牌尺寸、滚动条和交互说明。
- `ASSET_MANIFEST.md` / `assets.json`：文件映射、尺寸、九宫格切片参数。
- `layout.json` / `prefab.json`：参考布局和组件层级。
- `components/game-box-layout.js`：与引擎无关的牌堆及 Token 布局计算。

## 本版行为

角色牌合并为一个混合正反面的牌堆；事件牌单独堆叠。两类牌堆都沿用弃牌区的单击查看方式。玩家标记显示在原企业合作方块内；合作企业板仅显示当前玩家放回的一张；Token 按原比例换行，超出时在右侧滚动。页面没有确认或关闭按钮。

## 事件牌尺寸说明

当前可用文件没有事件牌原图，无法核实其真实宽高。包内事件示意图明确标为占位图，300×450 只是该占位图的尺寸。接入时读取实际单张事件 Sprite 的宽高，独立等比适配，不能套用角色牌的 600×850。

事件牌展示上限与角色牌分别配置；当前参考布局使用 200×250 的事件牌展示上限，以保持已确认预览中的紧凑程度。这是界面单位，不是事件牌实际规格。已验证竖版、横版、方形、宽横版、窄竖版的比例和旋转边界。实卡尺寸仍需以项目原图为准。

## 导入范围

`assets/` 是正式 UI 贴图：文字、计数、卡面均未烘焙在内。原有四种玩家方块保持原文件，不通过放大伪造 2× 版本；其余主要贴图提供 2× PNG。`dim-overlay.png` 为可平铺／拉伸的 4×4 半透明色块。

`preview/`、`example-data.json` 只用于看效果。这里的角色和企业板来自现有原图，事件和部分 Token 为示意内容；请接入真实游戏数据及素材。不要把整张预览图作为运行时 UI 底图。

## 验证范围

已检查实际贴图拼装、透明边框、PNG 尺寸、原玩家方块一致性，以及布局函数的比例、边界、层级和滚动范围。`QA.json` 与 `geometry-QA.json` 记录结果。离线演示完成语法与引用检查，未进行浏览器自动交互测试或游戏引擎集成测试。
