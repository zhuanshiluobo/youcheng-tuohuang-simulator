# CardViewer v3.6.2

本次修复素材路径交付问题，已补齐旧文件名替换图。详见 `REPLACE_BUTTONS.md`。

卡牌居中显示的独立查看窗口，复用最初角色牌选择窗口的背景；底部按钮已重新设计为哑光米灰与暖棕色。

- **使用角色牌**：从快速行动调用，底部依次显示计谋、策略、取消。
- **普通查看**：设施牌、手牌、弃牌区和盖放角色牌共用；上述三个按钮全部隐藏。
- 卡面等比显示，盖放卡显示哪一面由游戏传入；窗口不自行翻牌。

解压后直接打开 `PREVIEW.html` 查看两种模式及不同入口。演示中的操作只产生界面事件，不执行游戏结算。

| 文件 | 内容 |
|---|---|
| `assets/` | 原选牌背景；新版按钮 SVG 与 1×/2× PNG，含四种状态 |
| `PREVIEW.html` | 离线交互预览 |
| `preview/` | 静态预览与原始卡图样本 |
| `LAYOUT.md` / `layout.json` | 贴图、卡牌与文字的坐标及缩放 |
| `INTERACTION.md` | 入口、按钮显隐、禁用和关闭行为 |
| `integration/` | 可复用的 HTML/CSS/JS 参考组件与数据规范 |

本包新增一个通用窗口，不覆盖已有主界面素材。

按钮增量变化见 `BUTTON_REVISION.md`。本包已包含更新后的完整查看组件，无需同时叠加旧按钮。
