# 游戏内选择玩家窗口 v1.0

显示玩家头像、名字和标记颜色，支持单选、多选及精确选择人数。浅纸面底板与区控／游戏盒一致；头像框、四色方块沿用既有素材；确认与取消使用修订后的 CardViewer v3.6.2 按钮。

- 打开 `PREVIEW.html` 可离线体验单选、多选、三位玩家、不可选玩家及必须完成选择的状态。
- `preview/multiple.png` 为实际贴图拼装预览；另有单选、未选择、三位玩家和禁用状态图。
- `assets/` 为独立底板、边框、头像框、选项状态、玩家色块和按钮，不含文字、头像或玩家数据。
- `assets.json` 提供 1×／2× 文件与九宫格参数；`layout.json` 提供位置与尺寸。
- `PLAYER_SELECT_GUIDE.md` 说明布局、状态与调用方式；`components/player-selection.js` 是引擎无关的选择逻辑参考。

包内头像和主界面仅供预览，运行时换成真实玩家头像与场景。确认只返回玩家 ID，不执行游戏效果。SVG 保留 `sources/` 相对路径；PNG 不依赖 sources。

已检查 PNG、透明框、四色原图、布局边界、脚本语法与选择规则；未在用户游戏引擎内导入，也未进行浏览器自动化测试。
