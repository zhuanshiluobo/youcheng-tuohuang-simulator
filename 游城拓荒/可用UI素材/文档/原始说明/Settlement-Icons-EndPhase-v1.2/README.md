# 收尾阶段结算图标补丁 v1.2

新增 5 个 settlement icon，对应本次提供的 5 张牌的收尾阶段效果。延续 Settlement-Effects-v1.0 与 Settlement-Icons-Extra-v1.1 的 24×24 画布、1.7 px 圆角线条和三种配色。

这些图标表示结算按钮的功能入口；费用、数量、每阶段次数和可用条件由文字与状态显示。原卡上的资源、金券、分数、影响力动作等规则图示继续使用原素材。

## 对应关系

| 按钮建议文案 | 图标 ID | 来源 | 时机 |
| --- | --- | --- | --- |
| 据点补给 | `ui-outpost-payout` | 第三回合 · 建设据点 | 每收尾阶段一次 |
| 标记兑换 | `ui-marker-redeem` | 第五号企业家 | 收尾阶段任意次 |
| 基金投资 | `ui-fund-invest` | 蒂亚戈 · H · 罗德里格斯 | 每收尾阶段一次 |
| 声望兑分 | `ui-reputation-score` | 第一回合 · 降本增效 | 收尾阶段任意次 |
| 特勤行动 | `ui-tactical-dispatch` | 第五回合 · 特勤小组 | 每收尾阶段一次 |

卡面效果摘要：

- **据点补给**：移除1个资源点上的帮派影响力；你和该资源点上有影响力的对手获得1次该资源点对应的资源。
- **标记兑换**：移除此牌上3个标记；选择放置影响力，或获得1个卡面所示资源。
- **基金投资**：支付4金券；掷2个骰子，获得1声望，选择其中1个骰子并发动点数对应的效果。
- **声望兑分**：支付3声望，获得1分。
- **特勤行动**：支付1指令，执行1项未使用的战术行动。

“据点补给”“标记兑换”“声望兑分”“特勤行动”为按钮建议短名；“基金投资”沿用卡面名称。“据点补给”的图形以据点、减号和双向分发表示清理与共获；结算对象仍由卡面规则限定。

第五号企业家的两种收益共用“标记兑换”入口，点击后选择收益；如果项目把两种收益分别放在两个按钮上，可以复用此图标，由文字区分。不要把两个收益误实现为同时获得。

“降本增效”的基金投资减费是常驻修正，与该牌收尾阶段的声望兑分入口分开处理；基金投资按钮上的费用应显示应用修正后的实际值。“特勤行动”只调用未使用的战术行动；图标本身不表示刷新或重复使用。

## 文件与尺寸

每款提供 3 色 × 3 尺寸，共 **45 张透明 PNG**，以及 **15 个 SVG**。

| 后缀 | 颜色 | 对应按钮 |
| --- | --- | --- |
| `dark` | `#38372E` | 米色可用按钮 |
| `light` | `#F0E4C7` | 深色或处理中按钮 |
| `muted` | `#A9A392` | 深灰色不可用按钮 |

`assets/icons-endphase/<ID>-<色版>.png` 为 24×24；`@2x.png` 为 48×48；`@4x.png` 为 96×96。所有 PNG 保留透明背景。SVG 与 icons-sprite.svg 使用相同几何图形。

结算条中继续等比显示为 **22×22 逻辑像素**，搭配 **44 px 高按钮**，图标与文字间距 **8 px**。按屏幕缩放率选择 PNG 精度，或直接用 SVG。不要做九宫格或非等比拉伸。纯图标按钮应保留完整悬停说明。

## 接入

将 `assets/icons-endphase/` 放到项目现有图标目录中。示例沿用原 settlement strip 参数：

```js
strip.add({
  id: 'closing:fund-invest',
  label: '基金投资',
  icon: 'assets/icons-endphase/ui-fund-invest-dark@2x.png',
  monochrome: true
});
```

图标不包含次数或费用数字。可使用独立徽标表示“本阶段已用”；任意次效果的按钮仍需根据当前费用与条件决定是否可用。

`icons.json` 包含中文名称、来源、时机和每种色版的路径。`preview/overview.png` 直接使用本包导出的 PNG 与现有按钮底图拼装，展示大图和 22 px 实际显示效果。
