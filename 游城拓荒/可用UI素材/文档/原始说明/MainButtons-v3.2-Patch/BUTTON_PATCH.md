# 主界面按钮增量补丁 v3.2

本补丁基于主界面 v3.1，只替换右下页签、主要行动与底栏控制的 11 个按钮喵。

## 1. 外观与分层

按钮按用途分成三类设计，去掉旧按钮缺角的造型，但不强求使用同一套外形细节喵。

| 类别 | 设计重点 |
| --- | --- |
| 右下三个页签 | 紧凑、扁平的单边框，强调当前页面与切换关系喵。 |
| 六个主要行动 | 以独立图标作为识别重点，使用双框的操作块轮廓喵。 |
| 底栏两个按钮 | 撤销采用低调的轻描边，结束行动使用双边框黄底，两者比页签更圆润喵。 |

从底到顶依次绘制按钮底板、独立图标、运行时文字，再按需要叠加焦点提示喵。

图标与文字不烘焙进底板，缩放按钮时保持图标等比，文字继续使用项目字体喵。

三类按钮共享石墨灰、象牙白和工程黄的配色与质感，图标与边线的复杂度按用途分别处理喵。

## 3. 状态规则

| 状态 | 呈现与事件 |
| --- | --- |
| `default` | 普通可用状态，接收点击喵。 |
| `hover` | 鼠标悬停时加强边线或底色，保持原有语义喵。 |
| `pressed` | 按住时降低亮度并加强内侧压边，松开后回到当前状态喵。 |
| `disabled` | 使用禁用底板、图标和文字色，并阻止鼠标、触摸及键盘触发喵。 |
| `selected` | 页签当前选中状态，持续显示，不能以悬停状态代替喵。 |
| `selected-hover` | 鼠标悬停在当前页签时使用，继续保留选中语义喵。 |

页签的选中状态与鼠标状态分别保存，鼠标离开后仍应显示选中底色喵。

禁用状态优先于其他状态，按钮是否可用由游戏规则层决定喵。

撤销只在规则层明确允许时启用，不能因为按钮已有贴图就默认可用喵。

仍有必须完成的结算、支付或选择时，结束行动保持禁用，并可显示简短原因喵。

底栏结算槽与撤销、结束行动各自独立，展开结算内容时不覆盖两个按钮喵。

## 4. 接入与缩放

底板源尺寸为 256 × 80，图标源尺寸为 64 × 64，双倍分辨率 PNG 使用 `@2x.png` 后缀，SVG 可用于需要更高分辨率的导出喵。

底板使用九宫格缩放，四边切片边距均为 12 个源像素，`@2x` 贴图对应 24 个像素，保持拐角与描边宽度稳定喵。

底板源素材的 `contentInset` 元数据为左 18、上 12、右 18、下 12，实际目标按钮的图标和文字坐标以 `button-roles.json` 为准喵。

图标提供 `light`、`dark`、`muted` 三套颜色，分别用于深色底板、黄色或浅色底板、禁用状态喵。

按钮底板按目标框绘制，图标保持等比，不将按钮整图连同文字一起横向拉伸喵。

按钮点击区域与表中的目标框一致，纯装饰层不拦截输入喵。

原有按钮事件、选中页签、行动合法性和结算流程继续由现有游戏逻辑管理，本补丁不新增玩法规则喵。

“设施供应区”、顶栏、城市面板、企业合作及其他窗口不属于这次按钮补丁的替换范围喵。
