## 2. 不能作为保留旧 UI 素材的理由

- `prompt/企业扩与感染者基础实装/执行记录/局内九项问题界面返工方案.md:84`—`:92` 明确旧企业包三张图的绑定授权已撤销；`selection-module-paper.png`、`selection-button-default-fill.png`、`selection-button-frame.png` 只是临时留档且未引用。不能作为“用户替换”例外加入可用库。
- `prompt/企业扩与感染者基础实装/执行记录/局内企业与持续区域界面-执行记录.md:91`—`:105` 明确旧企业包的框、纸底、确认/取消不能替代当前增量主题；仍禁止把 MainButtons 3.2、MainFrame 3.5 扩大到整窗。但企业/科室对应按钮已由本轮用户明确授权使用 3.2，不能以该历史记录恢复 3.1。
- `prompt/企业扩与感染者基础实装/执行记录/局内页面第三轮返工方案.md:248` 明确第二轮 `outer-frame=2.5`、固定 Text[] 自制标记等断言已失效；“第二轮验收方案”的保留表不是最新依据。
- `UiSharedComponentTheme` 的 primary/secondary/disabled 不得借企业/科室用途标准全局改成 MainButtons 3.2。`04-主界面按钮3.2增量规范.md:18`、`:51` 限定目标按钮；`prompt/UI换新/执行记录/2026-09-27_UI-011_对局窗口整合.md:19`—`:28` 逐页记载设置、日志、一般查看器、调度、终局使用 3.1 按钮，本轮用户进一步确认这是纠正早期缺角按钮错用的要求。9 月 28 日个别页面记录及本轮 A02 授权均不改变该通用范围。
- `prompt/UI换新/00-共同执行约束.md:41` 与 `06-效果条目3.4与主框3.5增量规范.md:51` 要求保留的是原 ZIP/说明/历史证据，不表示这些被替换图片仍可作为 agent 的素材候选。原档案可保留在受限目录，新库只收当前用途有效资产。
- `prompt/UI换新/执行记录/2026-09-24_UI-001_接入基线.md:47` 的 turn-tag、redzone-paper“兼容保留”不是明确用户自行替换行为，不能据此继续向 agent 推荐旧顶栏图。
- 企业合作等级改成文字彩色圆点、效果行高度扩大至 136 均已被用户纠正并撤回（`prompt/企业扩与感染者基础实装/执行记录/局内企业与持续区域界面-执行记录.md:159`）。
