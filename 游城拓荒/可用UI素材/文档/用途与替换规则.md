# UI 素材用途与替换规则

核定日期：2026-10-08。本文中的路径均从本素材库起算；链接按本文位于 `文档/` 编写。先确定控件的业务用途，再从 [可用素材索引](../清单/可用素材索引.json) 查允许用途、源包成员和当前文件。不能凭文件名相似、颜色接近或“项目已经引用”判断可用。

优先级为：用户最新明确修改及其开发记录 → 本库当前用途标准与已记录用户修改 → 对应版本的用途/参数说明。2026-10-08 用户对本次审计的确认已直接写入下表和 [当前用途标准与实际参数](当前用途标准与实际参数.md)：A01、A02、U02、U03 是相应目标的当前标准，旧映射在这些角色上失效，不作为待确认豁免处理。当前表及清单中的用途期望优先于先前开发文档的日期和通用替换映射。原始说明保留来源用法与参数，不能据其旧映射推回已失效素材；包内新版本仍需服从当前用途标准。常规开发只使用本库；历史文档中的原档案路径不构成访问授权。

找不到合适素材时，记录目标控件、所需语义/状态、查过的允许素材以及缺少的内容并反馈。不得跨用途套图、从受限档案回捞、重画相似图、用纯色块/默认控件默默兜底，也不能把缺图当成已完成。

## 2. 导入与分层不能混用

| 情况 | 正确处理 |
| --- | --- |
| 1x/2x/4x | 是采样精度，不是不同控件大小。逻辑尺寸不变；源像素切片随倍率变化。文件名不能代替实际图片尺寸/参数。 |
| slices | 原清单通常为左/上/右/下；Unity Sprite border 为左/下/右/上。明确源像素、目标逻辑角区和 PPU/Image 倍率，不能直接把源 48 当作逻辑 48。 |
| 3.5 框 | 1x 主框源边距 24，底栏/槽框 12；2x 为 48/24，目标逻辑角区仍 24/12。透明中心不填充；bottom-bar-clean 普通铺底，不按框处理。 |
| 3.2 按钮 | 底板 256×80，1x 四边切片 12；2x 为 24。图标原图 64×64，始终等比。内容位置按 button-roles。 |
| 已有用户指定卡框、按钮与普通窗口外框 | 主界面角色牌/企业家 2.2 卡框、企业/科室 3.2 按钮及暂保留的普通窗口 module-frame，实际导入与 Image 参数见 [当前用途标准与实际参数](当前用途标准与实际参数.md)。按实际场景/预制体及覆盖逐项承接；不得以包内基准值为由批量重置、统一倍率，尤其不恢复 outer-frame 倍率 3。 |
| 填充/边框与整底 | 同一按钮“合并底板”与“fill＋frame”择一，不叠成双重描边；3.5 九宫格整框与八片框也择一。背景、框、文字、图标、状态和命中层分别管理。 |
| CardPicker/window | 旧合并底板含纹理、边框、分隔线，应依专用说明整体等比；不能当纯透明九宫格框切。卡槽和按钮按源可见框映射，透明画布不是点击区。 |

不要运行包内安装器、重建预览脚本或 Unity 生成器来“验证”。原文中的脚本仅为历史交付信息；普通测试/运行不得覆盖已搭好的场景与预制体。

## 4. 字体与完成判据

常规文字用 FangZhengHeiTiJianTi-1；强调文字用 HanYiCuHeiJian-1，不追加伪 Bold；“计谋/策略”等特殊词按项目明确字体角色；卡面效果数量/费用、主 HUD Discard Count 与企业合作 0—5 用 Novecento NarrowBold；弃牌列表数量及回合/页码等纯 UI 数字用 Novecento wide Normal Regular。七项 HUD 数字的旧 Regular 期望已由 2026-10-08 用户最新指定替换，见当前用途标准 F01。`msyh.ttc` 保留作为已指定特殊字词来源。具体页面后来有明确文字配置时承接该配置，不由运行时代码重写静态字体或文案。字体文件仍从可用索引按来源查询。

完成素材接入应说明：控件用途、所用索引条目/当前路径、模式与状态、切片/裁切/倍率、当前用途标准及相关用户修改，以及实际场景/预制体来源。测试验证引用、行为与动态数据；静态位置、样式和文案以当前资产为准。贴图有引用、编译通过或测试通过均不能替代实际画面对照。
