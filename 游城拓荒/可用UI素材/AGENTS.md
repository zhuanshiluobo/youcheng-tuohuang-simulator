# 可用 UI 素材规则

先读 README.md 与文档/当前用途标准与实际参数.md，按清单/当前用途标准.json 的当前期望选材，再查素材用途索引及对应原参数。用户已覆写的期望不是旧默认规则之外的例外，不得用旧包映射恢复已被撤销的期望。

贴图和字体只允许使用资产目录内、且可用素材索引明确匹配目标控件的文件。程序化组件只允许使用组件目录内、且清单/可用组件索引.json登记的文件与依赖，按其限定用途接入。参考目录中的生成器、示例和验证源码不属于可用组件，不得整包复制或自动执行。参数和原始说明只保留使用依据，其中旧路径、旧按钮、已撤回的布局和示例不能恢复可用资格。出现冲突时，以最新用户记录和本库限定用途为准。

缺少素材时反馈具体缺项，禁止跨用途替图或去受限原档案找图。常规校验不得访问 ../UI素材，不得运行旧导入/生成脚本或覆盖 Unity 资产。
