# 企业家卡面效果与Effect式

本文件转录企业家目录的5张能力牌、20张双面抉择牌的40个效果面、3种城市化区域及1张费用提示卡，供后续实装使用。**企业家是感染者扩展内的可选模式**，使用房间已有模式选项；模式关闭时不装配下列能力、组件、抉择与计分。本次只写文档，没有修改代码、内容配置、场景、预制体或原图。

来源编号、原图和SHA256见[素材清单](素材清单.md)。补充依据为[感染者规则书20241111](../规则书/游城拓荒感染者-规则书20241111.pdf)印刷第2至6、8、10页，分别对应PDF第2至4、5、6页。正文的卡面文字只转录规则，不转录背景故事。规则书已有明确解释的事项不再作为待确认项；尚未明确的边界集中见[实装准备与待确认事项](实装准备与待确认事项.md)。

## Effect式约定与共享裁定

下文是文字规格，**不是可直接运行的Lua**。`RegisterRule`、`GainCommand`、`GainReputation`、`FundInvestment`、`OperateFacilityStack`、`ExchangeBlueprint`等名称是组合流程或建议合同，不代表宿主已公开这些API。

| 写法 | 语义 |
| --- | --- |
| `[A,B]` | 先完整结算A及响应，再执行B；逗号及不同“立即”行不自动改成条件式 |
| `Condition(A,B)` | 卡面红箭头：左侧真实支付/移除完成后创建右侧；普通右侧失败不回退已经完成的左侧 |
| `Choice(A/B)` | 只创建所选分支；`可选`允许不执行该项 |
| `Repeat(n,A)` | 按次选择与执行，中途状态改变须更新候选 |
| `RegisterRule(来源,时点,规则)` | 注册所选面的剩余游戏能力；保留来源、触发事件和次数记录 |
| `本回合收尾` | 已登记的一次义务，不因提前恢复使用轨道而丢失或重复 |
| `收尾任意次` | 可以重复选择，直到放弃或真实费用不足；与“收尾一次”不同 |
| `GainCommand/Reputation(n)` | 指令/声望是能力牌上的真实玩家标记；取得可以拒绝，供应不足不能生成虚构标记 |
| `PayCommand/Reputation(n)` | 从对应能力牌移出实际标记；通常支付返还目的地需固定，明确写“回盒”时直接回盒 |

源岩、源石碎片、异铁、至纯源石、金券沿用已有资源。指令和声望分别是能力区中的真实玩家标记，不是新增资源；帮派是独立标记类型。黑色影响力图标沿用基础操作资格，涉及己方、非帮派、资源点或原位置时按卡面额外过滤。企业特效直接选特效；单纯升级才选择企业。合作等级封顶5，满级升级成功无效果；分数没有下限。普通操作空集合成功结束，不完整Effect跳过并记日志，但真实条件费用不足不能当作已支付。

### 模式的公共流程

开局抽取合作企业候选后、决定初始企业前，从末位玩家起逆时针各选择1位未被选择的企业家，拿能力牌、该企业家的4张抉择牌和配件，执行设置。未选企业家及组件退出本局。每张抉择对应第1、3、5、7回合，A/B是同一张卡的两面，不能按8张独立卡发牌。

上述四个回合的供应裁牌后、盖角色前，按正常行动顺序公开选择对应抉择的一面：登记该面的持续规则及行动，再执行立即效果。需要作用于本面立即效果的费用规则必须已生效；艾格尼丝第三回合B面的指令加价就是规则书明确的例子。未选面不执行，也不注册。旧回合已选面保留到游戏结束。

带未使用/已使用轨道的行动，每回合只能使用一次。轨道需要真实玩家标记；供应无标记时，规则书要求取回自己1枚影响力放在未使用处。收尾效果完成后才把已使用标记回未使用处。频率键按“来源卡＋行动”，不能因使用入口变化、重连或不同玩家行动窗口而重置。

## 艾格尼丝 史密斯

目录名“指令姐”，能力来源A01。能力：获得指令，解锁战术行动。取得/支付指令通过能力牌上的玩家标记记录；可以不取得，没有玩家标记不能取得。

`取得指令 → 可选 MovePlayerMarker(己方供应→指令区)`；`支付指令 → MovePlayerMarker(指令区→支付目的区)`。

战术行动有两种入口：支付2指令，作为快速行动执行；或作为特殊行动执行并获得10金券。**特殊入口是获得10金券，不是支付10金券。**两种入口共用同一战术行动的每回合一次额度（规则书印刷第5页）。特殊入口仍占对应主要行动中的特殊行动；快速入口按游戏的快速行动窗口运行，不额外生成任意主要行动预算。

`Choice(快速入口:Condition(PayCommand(2),执行战术) / 特殊入口:[执行战术,GainResource(金券,10)])`。卡面本身的额外费用仍需支付。收尾调用未使用战术与这两种入口的组合边界见J-Q05。

## 蒂亚戈 H 罗德里格斯

## 保罗 蒂尔曼

目录名“保罗”，能力来源P09。拥有4枚帮派标记；放置影响力时可以选帮派标记替代普通玩家标记。帮派影响力属于你，具有独立类型和真实有限供应；不属于岩蹄公司，不能放在要求玩家标记的诗怀雅牌上。

### 城市面板及供应的两类叠放

规则书印刷第6页明确城市面板被覆盖的旧设施仍存在：旧设施仍参与唯一设施和面板设施颜色数量判定。旧设施不能用于城市样式、附属能源邻接或7A紧急动员；建设城市化区域时，旧设施不再与核心指挥塔十字相邻。需要分别查询“全部仍存在设施”和“当前可参与效果的顶层设施”，不能在现有单层列表中删旧牌或把所有层同时判邻接。

设施供应叠放是另一种区域结构：下层牌不可直接选择，包括德克萨斯策略。取走顶层后，下层的揭露、何时补槽及整叠移牌边界见J-Q04。海德4级刷新则明确把供应里**所有层的牌**洗回设施牌堆，再按用户已批准的整批洗补流程处理，不只洗6张顶牌。

减价提示M01是5A/5B的辅助表现，不是开局全员拥有的新独立能力。减价生效后，对手向银行付1金券可替代1个三类建设资源；马丁本人不受益。多枚替代如何选择及与其他减费的顺序见J-Q03。

## 终局规则的执行合同

规则书总览仍是企业家特殊计分→区控→剩余资源。有些绿色计分条款修改区控算法或在企业家计分时发资源，不能把全部绿色条款简单转成结束时一次`GainScore`。

建议先登记所有计分修正，形成最终地图与设施视图；企业家特殊计分按该视图执行（例如M07获得的异铁会进入后续剩余资源计分）。需知道控制者的条款用同一份应用修正后的区控查询结果，随后只正式入账一次区控分，再按各玩家自己的资源计分配方入账。规则上下文、选择格子、资源快照、逐项分数和结算完成标记均持久化。

区块影响力修正、并列控制优先、区块价值修正和“每控制/每有帮派额外得分”是四类不同合同。P07只替换保罗的资源公式；T01是额外奖励，不替换公式。A02的并列规则不可把无人有影响力的0比0当作占领；此边界为实装建议，正式裁定见J-Q09。缺候选与不完整式继续沿用已批准日志规则，不宣称尚未完成的模式已可玩。

具体改动、状态合同、余项与验收见[实装准备与待确认事项](实装准备与待确认事项.md)；基础部分仍见[感染者扩规格](../感染者扩/卡面效果与Effect式.md)。
