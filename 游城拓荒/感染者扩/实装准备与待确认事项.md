# 感染者扩实装准备与待确认事项

感染者扩素材包含企业、角色、授勋、设施和城市样式，并引入岩蹄公司影响力、流形额外盖牌及多种持续区域。已找到并核对完整感染者规则书，设置、获取池和回合总览已补齐；不再把它们列为缺规则书。企业家属于感染者包内的模式模块，由用户房间已有的模式选项控制，本文件分别列出基础部分和企业家模式，不新增企业家扩展包。企业家主卡面已在独立目录转录，当前仍需补齐具体卡牌运行合同及模式有效定义/组件配方。

## 已确认的感染者基础装配

规则书印刷第2页明确感染者扩必须在企业扩加入的前提下游玩。依赖企业扩是正式规则，不再是建议；企业家模式关闭时仍可玩感染者基础部分。

感染者罗德岛显式替换企业版槽位，岩蹄安保和梅兰德基金会加入原企业池，共10家候选；按企业人数规则抽选，公开4家。两个罗德岛不得同时生效。岩蹄入选时准备8枚公司标记和2份终身安保合约；基金会入选时准备4张授勋牌。

9种主角色的获取池已核定：阿米娅每玩家初始各1张，其余8种合入原企业8张干员牌堆，共16张共享干员。缪尔赛思的3张流形由能力取得；4张授勋是基金会各1张奖励池。普通设施追加临时聚居点3张、三色罗德岛办事处各1张，共6张。样式追加2种I级、1种II级，继承抽I级4张、II级2张的设置，分别形成10选4和5选2的池。

普通特派在感染者规则下统一抽3张，选择1入手、其余洗回，展示回盒一张己方手/弃牌；可全部洗回得1分。罗德岛4级的“选择抽取干员”仍沿用此流程，只改变抽取组的形成方式。阿米娅发动特派时自身不能作为回盒目标，流形可以按规则替代回盒角色。

## 感染者基础部分对流程的改变

| 时点 | 基础部分必须改变的行为 |
| --- | --- |
| 开局组牌 | 上述企业替换、设施/样式追加、干员合并与初始阿米娅；建立公司、合约、授勋、流形实例区 |
| 每回合盖牌前 | 三人由起始玩家裁1张供应设施并立即补原空槽；二人沿用两人各裁1张的附录，不重复追加三人规则 |
| 角色盖放 | 缪尔赛思只增加本人额外流形槽，流形仍是角色；不能在额外效果触发后无限继续多盖 |
| 玩家两轮行动 | 角色、授勋、设施入场与宣告子树按卡面插入；公司标记的候选、费用与控制权采用无玩家所有者主体 |
| 正常采集 | 终身合约可额外选公司影响力资源点，不重复采集；公司路费付银行；雷姆额外采集不属于此阶段，不获得合约额外选点权 |
| 收尾 | 有盖放状态角色时，该角色与全部角色弃牌一起回手，替换基础“未使用角色牌”的判断；持续区不参与这次手/弃牌回收 |
| 区控计分 | 终身合约允许公司影响力按1名/2名合约玩家规则计入控制权；无主公司标记不默认分配给发动者 |

先执行红区开放回合升级，再人数对应供应裁牌；之后才进入盖牌。企业家模式开启时，中间另插入下节抉择流程。整个对局仍8回合，每回合两轮玩家行动，采集、收尾后进入下一回合。

## 企业家模式：同包内单独按模式装配

用户已在房间设置里提供模式选项。后续读取该选项形成固定`modeId`或等价配置（字段名为建议），不能用新增`expansionId=entrepreneur`代替，也不能启用感染者包后默认执行企业家流程。

| 模式插入点 | 仅在企业家模式开启时执行 |
| --- | --- |
| 初始设置 | 准备5种企业家能力、20张抉择牌、帮派标记4枚、企业家特殊设施9张、新核心指挥塔1张及企业家骰子3枚 |
| 决定初始企业之前 | 从末位玩家起逆时针选择企业家并领对应能力、4张抉择牌和额外组件；未用组件退出本局 |
| 第1、3、5、7回合盖牌前 | 人数供应裁牌后，按行动顺序选择该回合抉择牌A/B面，公开并结算，保存剩余游戏订阅 |
| 行动/收尾 | 启用对应企业家战术、特殊行动、每回合一次标记轨道和持续能力；设置时供应无标记则拿回自己1枚影响力放未使用处，收尾触发后恢复已使用轨道 |
| 第8回合收尾后 | 先结算企业家特殊计分，再执行区域控制和剩余资源计分 |

企业家原图已在另一个目录找到：49图包含5能力、20双面抉择的40面、3种城市化区域和减价提示，均见[企业家Effect规格](../企业家/卡面效果与Effect式.md)和[素材清单](../企业家/素材清单.md)。规则余项、组件配方及代码改动集中于[企业家准备事项](../企业家/实装准备与待确认事项.md)，不再列为缺主卡面。标准感染者基础部分的牌池、收尾、特派、公司及合约不依赖模式定义；模式关闭不能执行企业家入场、奇数抉择、帮派能力或特殊计分。
