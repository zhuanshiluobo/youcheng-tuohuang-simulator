## 已确认的感染者基础装配

规则书印刷第2页明确感染者扩必须在企业扩加入的前提下游玩。依赖企业扩是正式规则，不再是建议；企业家模式关闭时仍可玩感染者基础部分。

感染者罗德岛显式替换企业版槽位，岩蹄安保和梅兰德基金会加入原企业池，共10家候选；按企业人数规则抽选，公开4家。两个罗德岛不得同时生效。岩蹄入选时准备8枚公司标记和2份终身安保合约；基金会入选时准备4张授勋牌。

9种主角色的获取池已核定：阿米娅是每玩家新增的初始手牌，各1张；先与原7张组成8张手牌，再从手牌秘密回盒2张，保留6张，裁牌候选包含阿米娅。其余8种合入原企业8张干员牌堆，共16张共享干员。缪尔赛思的3张流形由能力取得；4张授勋是基金会各1张奖励池。普通设施追加临时聚居点3张、三色罗德岛办事处各1张，共6张。样式追加2种I级、1种II级，继承抽I级4张、II级2张的设置，分别形成10选4和5选2的池。

普通特派在感染者规则下统一抽3张，选择1入手、其余洗回，展示回盒一张己方手/弃牌；可全部洗回得1分。罗德岛4级按用户裁定简化为从干员牌堆直接选1张替换自己的1张手牌：旧手牌展示回盒，新干员入手，不再选3张抽取组，不带普通特派的未选洗回或放弃得分步骤。阿米娅发动普通特派时自身不能作为回盒目标，流形可以按规则替代回盒角色。刻俄柏转交只移动本牌，不进入任何特派流程。

感染者印刷第2页公共设置直接准备16张共享干员及3张流形，不以罗德岛是否入选为条件；阿米娅在无罗德岛的局也能特派。企业印刷第17页规定开局秘密回盒牌在局内不能查看，包括原持有者；普通特派公开换出不受此隐藏方式影响。

## 感染者基础部分对流程的改变

| 每回合盖牌前 | 三人由起始玩家裁1张供应设施并立即补原空槽；二人沿用两人各裁1张的附录，不重复追加三人规则 |
| 角色盖放 | 缪尔赛思只增加本人额外流形槽，流形仍是手牌与角色；赫拉格另新盖1张，不替换旧盖牌，新增实例本轮禁用 |
| 玩家两轮行动 | 角色、授勋、设施入场与宣告子树按卡面插入；阿米娅在使用角色页面的底栏结算槽点击，将当前快速行动改为双发；公司标记的候选、费用与控制权采用无玩家所有者主体 |
| 正常采集 | 终身合约可额外选公司影响力资源点，不重复采集；公司路费付银行；雷姆额外采集不属于此阶段，不获得合约额外选点权 |
| 收尾 | 有盖放状态角色时，该角色与全部角色弃牌一起回手，替换基础“未使用角色牌”的判断；持续区不参与这次手/弃牌回收 |
| 区控计分 | 终身合约允许公司影响力按1名/2名合约玩家规则计入控制权；每区块公司枚数除以2向下取整，奇数余1无用；无主公司标记不默认分配给发动者 |

先执行红区开放回合升级，再人数对应供应裁牌；之后才进入盖牌。企业家模式开启时，中间另插入下节抉择流程。整个对局仍8回合，每回合两轮玩家行动，采集、收尾后进入下一回合。
