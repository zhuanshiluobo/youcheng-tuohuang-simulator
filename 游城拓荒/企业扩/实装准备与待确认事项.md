# 企业扩实装准备与待确认事项

企业扩需要完整的企业合作、干员与科室玩法，并改变开局牌池和入场流程。本目录与共用素材已覆盖规则书所列卡面：8家企业、8张干员、3张科室、公路，以及山、玛恩纳、三色企业办事处、6种新增样式和2张替换事件。本文已落实用户在主规格中的批准与修正；卡面齐备不代表运行规则已实现。本次只整理文档，不改变现有玩法。

- [素材清单](素材清单.md)：本目录8个原图及共用目录6个相关拼版、13个新增卡面位置、现有切片ID、牌背和校验值。

## 开局应改成的流程

依据本地规则书 PDF 第 18、19 页，印刷页 16、17。先装配本局扩展、替换事件并形成牌池，再随机抽样式和设施供应，最后执行玩家入场。

1. 事件洗牌前，用企业扩的洞穴和遗迹、采集平台残骸替换基础同名牌，不能把替换牌作为额外一张混入。
2. 基础与企业扩合计 12 种样式按等级分池，由 Host 随机抽 I 级 4 张、II 级 2 张，公开本局供应。不能直接把全部有效样式放到场上。
3. 将企业扩3张设施加入普通设施牌堆；公路按用户裁定使用无限供应。取出8家企业板洗混。企业办事处不能继续作为无入场效果的占位牌使用。
4. 每人初始角色由 5 种基础角色加山、玛恩纳组成，干员和流形牌不进入初始手牌。
5. 初始资源点选择之前，每人抽 2 家企业选 1 家；三人局从未被抽取的企业补 1 家，共 4 家企业公开，其他企业退出本局。
6. 所有玩家在每家公开企业的 0 级各放自己的标记，再把初始企业提升至 1 级。只处理到达格的即时奖励；特效格仅解锁。
7. 罗德岛入选时准备干员牌堆；莱茵生命入选时准备科室并由选取者激活一张，三人随机补入则随机激活。
8. 初始资源点选择后，各自秘密将 2 张手牌回盒。仅给其他玩家显示数量，不能在公开投影或日志暴露牌名。
9. 红区首次开放的回合，在角色盖放前，起始玩家起按顺时针顺序，每人选 1 家企业提升 1 级。四人第 4、三人第 5、二人第 6 回合；只发生一次。

二人变体以三人规则为基础：初始企业按玩家顺序各抽4选2；初始点排除B-01；选完初始点后非起始玩家可立即放1个影响力；起始玩家初始10金券，非起始玩家18金券及3分。每回合盖牌前从本回合起始玩家起，两人各裁1张供应设施回盒并立即补至6张；红区第6回合开放，特派抽3张。依据基础规则书PDF第25页、印刷页23；完整时点见游戏流程变化，不能仅改允许人数就宣称支持二人局。

上述红区升级是回合入口插入点，不是初始入场的一步：开放处理后、角色盖牌前依玩家顺序完成；与二人供应裁牌同回合出现时，先执行红区升级，再执行供应裁牌。

## 已批准的组合与规则

- 特派使用牌堆顶候选选择、移动角色牌和洗牌组合；接受时移动入手并展示回盒一张角色，放弃时洗回并得1分。
- 海德先移动旧供应全部牌到牌堆，再洗牌，再向6个空槽依次移动牌堆顶卡；此过程中不边清边补。
- 雷神、工程科、泥岩等直接调用建设效果链；正常/免费决定费用，不给Build添加主要行动占用选项。
- 结构科5→4结算4级条件奖励；雷姆额外采集仅本人执行，该阶段不获得金券。
- 多萝西的4枚仅限制首次放入；公路供应无限。
- W二人局自动确定唯一对手，仍由你选择该对手1枚影响力并替换，跳过第二位对手；仍支付4金券。
- 本轮统一直接选择企业特效；同一家企业先升级再触发时以当前等级+升级量生成特效候选，从所选特效取得企业，不先选企业。不同企业的两式仍独立。
- 银灰与W直接选择影响力，逐步排除已处理的原所有者；候选空时操作成功结束。银灰由发动者选，每玩家最多移除1枚，空玩家跳过。
- 公路放置不包含移除；官方牌显式先移除后放路。已为公路不可选，空航道可选，多玩家响应按玩家顺序；DIY单独放路保留被覆盖标记在地图区域。

## 正常建设补牌的只读核对

按用户批注检查了[BuildFacilityService.cs](../../Assets/YC/Domain/Facilities/BuildFacilityService.cs)与[FacilitySupplyService.cs](../../Assets/YC/Domain/Facilities/FacilitySupplyService.cs)：`PayAndRefillForPlacement`支付后调用`ReplaceBuiltCard`，先找到被建设卡的列表位置；牌堆有牌就把顶牌写回该位置，无牌则删除旧项。`Refill`只在供应列表少于6张且牌堆非空时追加。现有路径是在替换被明确取走的卡，不能据“没有IsEmpty判断”直接认定覆盖了另一张正常供应卡。

目前供应是紧凑卡ID列表，没有6个独立区域/空槽状态；`MoveFacilityCard`公开执行分支也只支持供应移到牌堆底的有限场景。按批准方案后续应改成：

1. 6个供应槽有稳定区域ID；移走卡后保留空槽，不挤动其他槽位。
2. 补牌统一调用移动设施牌Effect；宿主在提交前检查目标槽为空、来源为当前牌堆顶且来源实例仍存在，防止覆盖、复制或抽取错误卡。
3. 正常建设保存待放置实例与已付/已补状态，补原槽完成后继续城市放置、得分和入场链；恢复不再支付或补牌。
4. 海德先固定旧供应集合再整批移走；仅刷新后的牌参加免费建设。森蚺和可露希尔仍逐张取走并补原空槽，第二张可选新补出的牌。
5. 牌堆为空时空槽保持为空，重复补牌请求返回已完成或无牌结果，不制造占位卡。

这是后续代码改动规格；本次只读取上述代码，没有改动服务、Effect或牌区状态。

## 企业扩优先验收案例

先实现企业等级和两个简单资源特效，再实现共享科室与干员，最后开放完整开局选择。验证应覆盖实际内容装配，不能只使用未启用示例。

| 案例 | 必须成立的结果 |
| --- | --- |
| 约翰老妈升至 3 级 | 只解锁特效，无即时得分；后续触发才加 1 分。 |
| 黑钢升至 3 级 | 立即得 1 分，不新解锁 3 级特效。 |
| 莱茵切换科室 | 全局板切换，只有本次发动者处理对应等级奖励。 |
| 莱茵合作1级切换 | 科室正常切换，没有对应1级奖励，不阻塞、不错误调用2级奖励。 |
| 结构科升至5级 | 降至4级并结算4级条件奖励，不递归再次发动5级，不免费发至纯源石。 |
| 干员特派接受或放弃 | 抽牌私密；未选牌洗回；接受时展示并回盒一张角色，放弃时得 1 分。 |
| W 已登记收尾后被特派换出 | 收尾仍移除 2 个己方影响力。 |
| 可露希尔拿两张设施 | 每次取走后立即补原槽；名称不同；公共供应和牌下区没有同一实例。 |
| 异客支付复合费用 | 一次费用总共至多消耗 2 枚标记，不替代金券、至纯源石，也不能出售标记。 |
| 雷神牌堆建设取消 | 仍洗混；同一效果恢复不得再洗一次。 |
| 雷姆额外采集 | 只对本人执行独立采集，不在此阶段发金券；之后正常采集资格仍有效。 |
