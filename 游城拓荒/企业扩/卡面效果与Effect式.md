# 企业扩卡面效果与Effect式

本文件把企业扩目录及[共用素材目录](../素材/)中的企业扩卡面转成文字和 Effect式，供后续内容定义、Lua 组合、交互及测试使用。当前只形成规则规格，没有启用扩展，也没有修改代码或 Unity 资产。整理日期为 2026 年 10 月 1 日；本次补充同时落实用户在本文写入的批准与修正。

来源编号、原图链接、尺寸和拼版位置见[素材清单](素材清单.md)。企业板以 `E01` 的 2 行 4 列拼版为准，干员以 `E06` 的 2 行 4 列拼版为准；`E09` 至 `E14` 是共用素材目录的原始拼版。另复核了[本地规则书](../规则书/《游城拓荒：铸基者》规则说明书（新）.pdf)的 PDF 第 10、11、13、18 至 24 页，以下引用同时写明 PDF 页码与印刷页码。

## Effect式阅读约定

下文是**文字规格，不是可直接运行的 Lua**。函数采用便于阅读的位置参数；实际实现必须按当前宿主的具名参数、候选、continuation 和版本合同编写。

| 写法 | 含义 |
| --- | --- |
| `[A, B]` | 有序 Effect 列表，A 结算及响应结束后再执行 B。 |
| `Condition(左侧, 右侧)` | 红色箭头的条件式。先完成左侧支付、移除等要求，再创建右侧。不得把右侧成功作为扣除左侧的前提。 |
| `Choice(A / B)` | 选择一个分支，只创建所选分支。 |
| `Repeat(n, A)` | 按次执行，每次重新选择；“至多”允许提前停止。这是规格写法，当前公开宿主没有 Repeat。 |
| `选择(范围, 数量)` | 可持久化交互，结果以稳定实例 ID 保存；范围由宿主复验。 |
| `收尾一次` | 本玩家每个回合收尾阶段至多一次；登记、是否使用及完成结果必须能恢复。 |
| `本回合收尾` | 仅本回合的一次延迟结算；牌后来离场也保留已经登记的义务。 |

图标统一翻译：棕色石块为**源岩**，红黑晶体为**源石碎片**，蓝色星状物为**异铁**，黑金矿石为**至纯源石**，黄色票券为**金券**，黄色数字六边形为**分数**。绿色向下箭头是放置影响力，红色向上箭头是移除影响力，蓝色横向箭头是移动影响力；橙色向下箭头落在四色底座上的图标是城市样式宣告标记，不是地图部署。

`你` 指发动效果的玩家；对手不包括你。“玩家标记”来自有限供应，不能凭空生成，也不能仅以 UI 数字代替。获得、支付、转移资源分别记录来源和去向。

### 现有能力和待补能力

已公开的 `GainResource`、`PayResource`、`GainScore`、`LoseScore`、`Choice`、`Condition`、影响力操作、`Build`、`MoveCity`、`MoveFacilityCard`、`MoveCharacterCard` 等可作为基础，但其全部参数组合并未实现。

本文件中的 `UpgradeEnterprise`、`ActivateEnterpriseSpecial`、`SwitchDepartment`、`DispatchOperator`、`PlaceRoad`、`ShuffleFacilityDeck`、`OperateToken`、`Repeat` 采用项目设计文档已有名称，**目前没有可用的完整公开宿主链**。持续性牌的场上区域、跨阶段订阅、特殊费用替代及一般化卡区移动也需要补全。不可仅因已有 effectTypeId 或 schema 字段就将卡牌标记为已实现。

其中 `DispatchOperator` 在本文是可复用的**组合流程名称**，按用户批准拆成选牌、移动角色牌和洗牌 Effect；不要求另造一个不可拆分的特派原语。`Build` 表示直接调用建设效果链，正常或免费只描述费用，不带“占不占主要行动”的选项。只有卡面明确写“主要行动”时，才使用主要行动链或行动额度。

## 企业合作公共流程

依据 PDF 第 19、20、24 页，印刷页 17、18、22。

`UpgradeEnterprise(玩家, 企业, 1)` 应先移动合作等级，再处理到达格：有“企业特效”标签只解锁，不发动；无该标签立即处理奖励。解锁过的特效可供后续触发，不只限当前格。等级范围为0至5；已满5级的升级正常结算为无效果，不重复给5级奖励。连续升2级从4级起时，第一步正常结算到5级，第二步无效果；仍继续之后的兄弟Effect。

`ActivateEnterpriseSpecial(你, 范围)` 直接从范围内的企业特效中选择一项并结算，候选显示企业名、特效等级和效果文字，结果保存企业实例ID与特效ID；**不先选择企业再选择特效**。“触发特效”不等于“升级”。多个玩家同时升级时，发动玩家先结算，其他玩家按顺时针顺序结算；途中有选择和入场效果，要完整等待子树。

### 特效选择与同企业升级组合

| 场景 | 一次选择的范围 | 选择后执行 |
| --- | --- | --- |
| 单独触发任意企业特效 | 本局所有企业中，你已解锁的真实特效；仅有指定企业/等级时额外过滤 | 直接执行所选特效，不另开企业选择 |
| 同一家企业先升1级再触发 | 各企业真实特效等级≤`min(5,你在该企业当前等级+1)` | 从所选特效取得企业E，先`UpgradeEnterprise(你,E,1)`并等其奖励结束，再执行同一个所选特效 |
| 同一家企业先升2级再触发 | 同理，范围等级≤`min(5,当前等级+2)` | 从所选特效取得E，逐级升级2次后执行该特效 |
| 升级与触发可选不同企业 | 升级保留自己的企业选择；后续触发直接选当前已解锁特效 | 两个独立Effect，不能用“等级+1”把后者绑到前者 |
| 一家企业的全部已解锁特效 | 直接呈现按企业归组的特效集合，选择整组及其执行顺序 | 触发时冻结集合，顺序结算；后续新增解锁不加入 |

`选择同企业升级后特效(增量N)`是本文的组合规格简称，不是现有公开构造器。先按每家企业自己的等级生成平铺候选；选择结果一次保存`E、特效ID、等级范围快照`，再创建升级与触发子节点。普通奖励格、空白格和科室奖励都不能伪装成特效候选。选择只约束范围，不提前升级；实际奖励和资源支付仍按原Effect顺序执行。

### 成功无效果、分数与式子不完整

用户裁定分数**没有下限**。`LoseScore(你,N)`实际减N，允许负分；作为条件左侧时，不能因当前分数不足N而阻止右侧。例如0分使用约翰老妈2级特效，变为-1分并获得20金券。

没有可触发的企业特效时，触发节点直接成功结束，不弹空选择，不阻塞父链。用户给出的例子是仅约翰老妈有初始合作等级、尚未升级时直接建设企业办事处；设施仍完成建设和得分，入场触发成功但没有实际效果。

用户要求“如果有任意effect式子不全就跳过执行并且输出到日志”。运行时缺失或不完整的Effect式只跳过该式，记录来源、节点、缺失项与原因，再继续正常流程；不以缺省目标、缺省数值或虚构节点补齐。跳过记录应可恢复，不能重连后反复执行或重复记录。无候选成功、满级无效果、式子不完整跳过分别保留结果原因，不能在日志里伪装成实际移除、支付或升级。

此规则不把真实条件支付失败改成支付成功：条件左式不完整时跳过整个条件式，不能凭空创建右式；右式在左式已完成后不完整时，只跳过右式并记日志，已完成的支付不回退。普通非条件影响力操作则按下一节的空集合成功规则结算。

### W与银灰直接选择影响力

两牌都由发动者直接选择影响力实例，不先选玩家。每步完成后更新候选及已处理所有者集合，下一步使用新局面；候选集合为空时自动成功结束相应影响力操作，不提交空交互，也不制造实际操作记录。

- 银灰：候选为所有玩家（含自己）中尚未被本次移除处理过的玩家的合法影响力。选一枚移除后，排除该玩家其余影响力；没有影响力的玩家直接跳过。移除段完成后继续放置2枚，不把整个技能变成条件式，也不要求无影响力玩家补足目标。
- W：候选为对手的合法影响力。替换一枚后，排除该原所有者的其他影响力；最多处理2名不同对手。二人局自然只执行唯一对手的1枚；剩余集合为空就成功结束替换段。仍先支付4金券，不能因替换段无候选而退费。

以上是企业扩玩家影响力范围。感染者规则另允许W选择岩蹄安保影响力、禁止银灰选择它，接入时按[游戏流程变化](../可选扩展包游戏流程变化.md)和感染者规格增加主体过滤，不能把无玩家归属的公司标记映射成玩家0。

莱茵生命是共享科室板：到达 2 至 5 级时处理当前科室对应奖励，科室奖励不属于企业特效。切换科室影响所有玩家之后的奖励来源；由莱茵 1 级特效切换时只给发动玩家处理对应等级奖励，其他玩家不因切换自动获奖。

合作等级为1时仍正常切换科室，新科室没有1级奖励，因此不执行奖励节点。

## 合作企业板

每板 0 级均为玩家标记起始区，没有即时奖励。表中的“奖励”只在到达该等级时结算；“特效”只在明确触发时结算；“说明”不是可发动的效果。空白格保留为空白，不能补造效果。

`[选择尚无公路的航道R, 按玩家顺序RemoveInfluence(R上全部影响力并保存实际移除结果), PlaceRoad(R), 对实际被移除影响力的不同玩家各GainScore(1), GainScore(你,1)]`

先显式移除并完整处理响应，再放路；`PlaceRoad`本身不移除。“被移除的玩家”按玩家去重，不是每枚影响力得1分；按牌面两句独立结算，你若也有影响力被移除，会得到该项1分及最后的1分。多萝西收留离场实例不撤销移除事实。公路无限供应，既有公路不可选，空航道可选；空航道无人获得移除奖励，你仍获得最后的1分。

计谋“商业网络”：支付2金券，选择1家企业，将你在该企业的合作等级提升1，然后触发该企业一项你已解锁的特效。

`Condition(PayResource(你,金券,2), [选择同企业升级后特效(增量1,范围≤该企业当前等级+1), 从所选特效取得企业E, UpgradeEnterprise(你,E,1), 执行所选特效])`

两步必须同一家企业，因此按用户裁定只选一次特效，E由特效归属取得。候选包括本次升1级可解锁的特效，最高按5级截断；实际先升级并结算到达奖励，再执行保存的特效ID，不能提前发动。范围为空时右侧组合成功无效果结束并记录原因。玛恩纳策略的两式独立，不套用此绑定。来源规则书PDF第21页、印刷页19。

### 宣告和使用公共规则

图案坐标采用左上原点，x向右、y向下；整体允许平移和旋转0/90/180/270度，禁止镜像。每格必须由对应颜色的未用于其他样式宣告的设施满足；彩色设施按通用规则可视为任意颜色。宣告必须消耗一个实际玩家供应标记，登记所用设施实例并结算卡面分数，不能只核对颜色总数。

宣告规格为`[校验并记录未用设施匹配, OperatePlayerMarker(供应→样式宣告区), GainScore(你,卡面分数), 首次宣告解锁该特殊行动]`。I级第一次标记放未使用区；II级第一次放2区，后续重复宣告的标记放宣告条件旁，不能恢复已经消耗的使用次数。六牌均没有宣告时立即执行特殊行动的符号，不把其行动内容当作宣告奖励。

使用特殊行动前检查玩家已宣告、次数剩余、该样式本回合未使用及本行动轮限制；提交使用后将相应标记移到已使用区。I级收尾恢复未使用，II级收尾移到下一较低次数区，降至0后不可再用；单种样式每玩家每回合至多一次。`X`取该玩家在该样式上的全部玩家标记数量，包含重复宣告标记，并在本次特殊行动开始时保存。上述公共规则依据PDF第10、11、13页、印刷页8、9、11。

### 城建开拓区

建议ID `city_style_city_construction_frontier`。特殊行动：失去1分，从设施牌堆选择1张设施并建设，之后必须洗混设施牌堆。

`[LoseScore(你,1), Build(你,设施牌堆候选,正常费用), 无论建设结果均ShuffleFacilityDeck]`

牌面没有免费字样，也没有条件箭头；不能改成免费的牌堆建设或额外主要行动额度。洗牌采用结束处理，不能仅挂在建设成功分支。

跟雷神5级特效一样。

### 拓荒者据点

建议ID `city_style_pioneer_outpost`。特殊行动：在你移动城市所在资源点放置2个你的影响力，再移动X个你的影响力。

`[保存X=己方在本样式上的标记总数, Repeat(2,PlaceInfluence(你,本次执行时移动城市所在资源点)), Repeat(X,MoveInfluence(你))]`

放置目标限定当前城市所在资源点，之后移动按普通影响力规则；不是再次移动城市，也不是只能移动刚放的两枚。

### 核心商业区

建议ID `city_style_core_commercial_area`。特殊行动：从4金券、1源岩、1异铁、1源石碎片中选择一项获得，再执行1次特殊行动以外的主要行动。

`[Choice(GainResource(金券,4) / GainResource(源岩,1) / GainResource(异铁,1) / GainResource(源石碎片,1)), ExecuteMainAction(你,允许建设/探索/移动城市,即时子树)]`

即时主要行动按正常费用及规则执行，不能再选特殊行动，不能替换成任意额外主要行动预算后退出本次子树。

### 大型企业园

建议ID `city_style_large_enterprise_park`。特殊行动：选择1家企业，连续提升2级合作等级。

`选择企业E → Repeat(2,UpgradeEnterprise(你,E,1))`

两次使用同一企业，逐级处理奖励与解锁；满级边界沿用企业统一合同。

### 警备队辖区

建议ID `city_style_security_district`。特殊行动：从下列3个选项中选择2次，依次执行；使用此行动的行动轮中不能使用角色牌。

| 分支 | 卡面效果 | Effect式 |
| --- | --- | --- |
| A | 支付2源岩、1异铁，替换1个影响力 | `Condition(PayResource(你,{源岩:2,异铁:1}),ReplaceInfluence(合法目标,己方供应))`；复合费用按一次足额支付提交 |
| B | 放置1个你的影响力，获得1源石碎片 | `[PlaceInfluence(你),GainResource(源石碎片,1)]` |
| C | 移除1个影响力，获得2异铁 | `[RemoveInfluence(合法目标),GainResource(异铁,2)]` |

完整规格：`[校验本行动轮尚未使用角色牌并登记本轮角色禁用, Repeat(2,Choice(A/B/C))]`。卡面未要求不同选项，允许重复；第二次在第一次完整结束后的局面重新选择。只有A有条件箭头，B/C后续资源不能擅自改成“前项成功才给”。角色限制要覆盖行动轮前后，不能先使用角色再用此行动，也不能借额外行动绕过禁用。

### 拓荒指挥中枢

建议ID `city_style_pioneer_command_hub`。特殊行动：本行动轮可额外执行1次特殊行动以外的主要行动，且使用角色牌时可以使用其策略和计谋。

`[GrantMainActions(你,本行动轮,额外1次,允许建设/探索/移动城市), 本行动轮角色使用权限=可按所选顺序依次执行策略及计谋]`

这是行动轮状态许可，不是立即执行两个角色能力；仍只能使用本回合盖放的角色一次，两模式之间不插入主要或快速行动。已经用过角色牌后不能通过此许可把弃牌重新发动；角色牌自身回盒、持续留场及两模式的去向需统一等待角色使用结束。次数与双模式许可在该行动轮结束时失效，II级样式轨道的剩余次数按公共规则处理。
