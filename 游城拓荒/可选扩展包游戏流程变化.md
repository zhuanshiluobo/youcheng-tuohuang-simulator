# 可选扩展包游戏流程变化

本文件回答“扩展对游戏流程改了什么、插在何时、按什么顺序执行”。只形成规则与实装规格，没有修改代码、场景或运行内容。

来源为[基础及企业规则书](规则书/《游城拓荒：铸基者》规则说明书（新）.pdf)PDF第18、19、25页（印刷16、17、23），以及[感染者规则书20241111](规则书/游城拓荒感染者-规则书20241111.pdf)的印刷第2至10页，企业家卡面另见[企业家规格](企业家/卡面效果与Effect式.md)。感染者PDF为6页双页跨页排版，用户指出的“游戏流程总览”在**PDF第6页左侧、印刷第10页**；该页是回合主干顺序的依据。企业特效、分数、影响力候选和公路的边界采用用户已验收后的裁定。

## 本局配置与规则来源

用户已在房间设置中分别提供“扩展包”和“模式”选项。**企业家属于感染者扩展的一部分，由模式选项控制；不是另一个扩展包，也不与感染者基础流程混用。**下表区分这两个维度。

| 扩展包选择与模式 | 生效流程 |
| --- | --- |
| 基础 | 基础设置、角色盖放、两轮玩家行动、采集、收尾和8回合后计分 |
| 基础＋企业 | 加企业组牌、初始企业及等级、秘密裁角色、红区开放前升级；行动内增加企业/干员/持续牌等子树 |
| 基础＋企业＋感染者，企业家模式关闭 | 只应用感染者基础部分：新增牌池、岩蹄/基金会、角色及普通回合变化；跳过企业家选择、抉择牌、企业家能力与计分 |
| 基础＋企业＋感染者，企业家模式开启 | 在感染者基础部分上加入同包的企业家模块：企业家选择、能力与组件、抉择牌、相应收尾与特殊计分 |

启用扩展集合、房间模式、人数、替换版和随机结果由Host在开局固定。企业家模式要求企业＋感染者启用；未启用感染者时不能生效。实际选项名称及布局以用户已有房间资产为准，本次不新增或覆盖界面。客户端不能各自按素材目录推导牌池，也不能在对局中临时改扩展或模式。

## 初始设置：先装配牌池，再生成本局供应

| 时点 | 企业扩改动 | 感染者在企业基础上追加的改动 |
| --- | --- | --- |
| 放地图、设置基础指示物 | 沿用人数对应地图及基础设置 | 沿用；公司、流形、授勋等专属区另行建立 |
| 洗切事件牌 | 企业版洞穴遗迹、采集平台残骸分别替换基础同名槽位，再洗牌；不多加同名牌 | 规则书没有另列感染者事件替换，保留企业替换结果 |
| 抽城市样式 | 基础＋企业共12种，I级8选4、II级4选2 | 新增2种I级、1种II级先加入相应池；按继承的4＋2抽取，合计池为I级10种、II级5种，不能抽完后才加入3张 |
| 建立普通设施牌堆及供应 | 加入红/蓝/黄企业办事处各1张，洗牌后补6槽 | 加入临时聚居点3张、罗德岛办事处三色各1张，共6张普通设施；企业家特殊设施与新核心指挥塔只按可选企业家组件使用，不洗入普通牌堆 |
| 资源供应与辅助物 | 保留基础资源及有限玩家标记；公路无限供应是用户裁定 | 资源类型沿用基础；至纯源石计数器、50分标记仅辅助表现，不生成额外资源或分数 |
| 合作企业池 | 准备8家企业供入场抽取 | 用感染者罗德岛替换企业罗德岛，加入岩蹄安保、梅兰德基金会，形成10家候选；不是同时留两份罗德岛 |
| 干员及专属池 | 罗德岛入选时建立企业8张干员共享牌堆；莱茵入选时备3张科室 | 新增8张干员与企业8张合为16张共享干员池；流形甲乙丙各1张独立备在池旁，由能力取得，不作为全员初始牌 |
| 玩家配件 | 基础5种角色＋山、玛恩纳，每位玩家7张初始角色 | 每位玩家额外加入本颜色阿米娅1张；其他8种感染者角色进入干员池，不发给所有玩家 |
| 可选企业家备件 | 无该流程 | 开启时准备5种能力牌、20张抉择牌、帮派标记4枚、特殊设施9张、新核心指挥塔1张和企业家骰子3枚；每玩家按企业家领取组件，其他组件退出本局 |

样式10选4及5选2、共享干员16张是按规则书“加入对应池／合并干员”与企业原数量得到的装配结果；它们不是新版另行随机数量。规则书的3张临时聚居点复用现有I17卡面生成3个实例，不能以目录只有1图改成1张。

## 开局入场：按总览的顺序

1. 决定起始玩家和玩家顺序，抽取合作企业候选。
2. 若开启企业家模式，从末位玩家开始逆时针选择企业家，领取对应能力、4张抉择牌及额外组件，执行能力牌上的设置；这个窗口在决定初始企业之前。关闭该模式则跳过整步。
3. 决定初始企业：三/四人每人抽2选1；三人再从未抽取企业中随机补1家，共公开4家。所有玩家在公开企业0级放标记，各自初始企业升至1级。二人各抽4选2，两家初始企业都升至1级；公开企业仍4家。
4. 按入选企业准备组件：罗德岛共享干员池、莱茵科室、岩蹄安保8枚公司标记和2份终身安保合约、基金会4张授勋牌。三人随机补入莱茵时随机激活科室；本人选择莱茵时本人选科室。
5. 决定初始资源点，按基础和人数规则完成城市及影响力入场。二人禁选B-01，非起始玩家随后可立即放1个影响力。
6. 秘密回盒角色、保留初始角色。企业原规则为7张回盒2张、保留5张；感染者额外加入阿米娅，见下方口径说明。公开投影和客户端日志只显示裁牌数量，不显示牌名。
7. 获得初始资金，进入第1回合。二人起始玩家10金券，非起始玩家18金券及3分；三/四人沿用基础资金配置，不从扩展卡面生成初始资源。

**初始裁牌的剩余口径**：印刷第2页明确“将阿米娅加入手牌”，第10页仍写“保留5张基础角色牌”。因此不能把感染者总手牌直接固定为5张。企业7张保留5张，再加阿米娅得到通常6张；阿米娅是否可参与秘密回盒2张，正文没有明示，保留为I-Q02余项，实装前应固定配方与裁牌范围，不能临时由客户端决定。

## 每回合入口：所有前置子树结束后才盖牌

总览给出的顺序是：

`红区首次开放时的企业升级 → 2/3人供应裁牌 → 可选企业家抉择 → 角色盖放 → 玩家行动第1轮 → 玩家行动第2轮 → 采集 → 收尾`

| 入口子树 | 条件与具体顺序 | 完成后推进条件 |
| --- | --- | --- |
| 红区开放前企业升级 | 只发生一次：四人第4、三人第5、二人第6回合，从起始玩家起按顺时针，各选1家企业升1级。开放回合允许本阶段按正常规则处理奖励/解锁 | 全体选择及到达奖励子树已完成；满级无效果仍记完成，恢复不能重复升级 |
| 二人供应裁牌 | 每回合盖牌前，两名玩家从起始玩家起，各选供应1张回盒；每次立即补原空槽至6张或牌堆耗尽 | 第一人的补牌完成后第二人才选，可选到刚补出的牌 |
| 感染者三人供应裁牌 | 每回合由起始玩家选供应1张回盒，再立即补原空槽；这一步在企业家抉择之前。四人无该追加规则 | 移牌与补牌已完成；不能误做全员各裁1张 |
| 可选企业家抉择 | 仅第1、3、5、7回合，按正常行动顺序，各自取本回合双面抉择牌，公开选择A/B之一。先登记本面持续费用/规则，再执行立即效果；艾格尼丝3B立即取得指令也需每枚付2金券 | 立即效果及选择结束，所选面、剩余游戏能力、使用标记及特殊计分来源已保存；另一面不执行 |
| 角色盖放 | 企业标准仍盖1张普通角色；缪尔赛思能力可额外盖1张流形，额外槽只允许流形 | 每个实际盖牌实例和隐藏投影已保存；不能给全员无条件开放第二槽 |

二人供应裁牌来自基础附录；三人裁牌是感染者印刷第4页的追加。来源、人数和次数分别配置，组合启用时不能把两条相加成同一玩家重复裁牌。

## 两轮玩家行动：主干保留，Effect内允许增加子树

每回合仍执行两轮玩家行动。直接调用建设、探索、移动等效果链的卡牌不能被改成任意主行动额度；明确写“额外主要行动”的样式才登记行动轮额度和允许类型。

| 行动内窗口 | 应新增或改变的流程 |
| --- | --- |
| 触发企业特效 | 直接选择特效；同企业先升N级再触发，以各企业当前等级+N生成候选，从特效取得企业。无候选成功结束；升/触发不同企业的玛恩纳保持两个独立Effect |
| 多项同时触发 | 凯尔希先冻结集合再依所选顺序结算；中新解锁不加入。多玩家奖励与响应按规定玩家顺序，完整等子树结束 |
| 影响力选择 | W、银灰直接选实例，每步排除已处理原所有者；空集合成功结束。岩蹄公司无玩家归属、视为对手影响力；W可选、银灰不可选 |
| 特派 | 企业通常抽2，企业二人抽3；感染者全局改为抽3。普通特派从顶部候选选1入手、未选洗回，展示回盒己方1张角色；可放弃全洗回得1分。阿米娅发动中不能回盒自身；罗德岛4级允许选择抽取的干员 |
| 建设与设施入场 | 先支付/补原供应槽，再放城市、得分、等待入场。办事处入场触发可能嵌套新建设；供应、牌下和牌堆来源分开，恢复不能重复付款、补牌或入场 |
| 角色使用及去向 | 普通能力按角色使用结束规则弃置；一次性模式回盒；持续模式在场注册。阿米娅和拓荒指挥中枢提供双模式许可，但不允许重复使用同一已结束实例 |
| 行动轮限制 | 警备队辖区、综合企业办公区等整轮禁角色，已用角色不能再发动；额外行动及双模式许可按该轮清理，不能绕过禁令 |
| 宣告城市样式 | 先匹配未用设施、放玩家标记及得分，再结算感染者样式宣告奖励和设施响应；新兴建筑群建设、城区管理中心回收II级标记、临时聚居点回盒获券在此窗口执行 |
| 公路及地图标记 | 官方效果显式先移除再放路；放路原语不清除。既有公路不能选、空航道可选。单独DIY放路覆盖的玩家标记保留地图区域，退出影响力统计但不回供应 |
| 可选企业家能力 | 黄色剩余游戏效果按其声明时点触发；每回合一次行动用真实标记及未用/已用轨道。战术快速/特殊入口共用次数，投资组合费用合并支付；马丁图纸与供应/城市层叠分别建模。设置时供应无标记，按规则拿回自己1枚影响力放未用处；收尾触发完再恢复轨道。详见企业家逐式规格 |

## 采集与收尾：感染者覆盖基础回收规则

| 时点 | 规则及需要保存的状态 |
| --- | --- |
| 正常采集开始 | 缪尔赛思仍盖放而未使用的流形可回手，只处理这些流形实例；不能误回收普通盖牌或其他手/弃牌 |
| 正常采集选点 | 基础按己方影响力/城市所在资源点选点。拥有终身安保合约者可额外选有岩蹄公司影响力的资源点；同时有公司与己方影响力也只采一次 |
| 支付路费 | 公路免费；岩蹄公司路费付银行。Host保持采集开始支付能力快照、已付航道和结果，不能用新采金券继续付路费 |
| 雷姆额外采集 | 仅本人执行独立子会话，不切换全局阶段、不消耗随后正常采集资格、不在该阶段获得金券；规则书印刷第9页明确它不是正常采集阶段，不能仅凭合约选公司点 |
| 收尾触发 | W等本回合延迟义务、泥岩/多萝西/诗怀雅/林/嘉维尔等持续牌、剩余游戏授勋及可选企业家能力按时点与顺序触发；“每收尾一次”不能多付费重复使用 |
| 角色回收 | 仅企业沿用基础“有未使用盖牌时回收”。感染者覆盖为：若收尾时有盖放状态的角色，该角色与角色弃牌区全部回手；这是盖牌状态检查，不只检查是否尚未用过某能力，赫拉格第二轮重盖牌也能触发回收 |
| 样式及使用轨道 | I级已使用恢复，II级降到剩余次数；重复宣告不重置II级次数。企业家每回合一次的已使用标记也在收尾回未使用 |
| 到期与持久区域 | 到期锁定、行动轮权限、订阅注销按来源规则处理；持续牌和牌上标记不被普通弃牌回收清空；负分原值保留 |

## 第8回合收尾后计分

按总览：`可选企业家特殊计分 → 区域控制计分 → 剩余资源计分`。未开启企业家模式时第一段跳过；不新增“感染度胜负条件”。

企业家终局修正需要先登记，区控相关奖励统一查询修正后的最终控制者，再只正式入账一次区控。马丁3A在特殊计分阶段获得的异铁进入后续资源计分；保罗7A只替换本人资源公式，第五号7A另加至纯奖励。马丁3B等终局选择须等待完成，不能沿用无交互同步结算；详细合同见[企业家终局规格](企业家/卡面效果与Effect式.md)。

岩蹄公司影响力没有玩家所有者。区域控制计分时，有终身安保合约的玩家可将每2枚公司影响力视为自己的1枚；有2名合约玩家时，这每2枚同时视为两人的各1枚。帮派影响力与企业家特殊计分按其能力另行处理，不能把地图区域里被公路覆盖的普通标记算回影响力。

## 本次补齐后仍需准备的内容

感染者完整设置及主干流程已找到，不再列为缺规则书。企业E-Q01至E-Q09均已有用户裁定。企业家目录49份原图已完成5能力、20双面抉择的40面、3种城市化区域及减价提示的转录。当前剩余资料与合同包括：初始裁牌中阿米娅资格的口径、公司影响力与W两名不同对手约束的组合、具体卡上标记不足/绑定/锁定区域边界，以及企业家特殊设施配比、新塔/枢纽配方、供应层叠和特定行动组合边界。

企业家功能是**感染者包内的模式模块**，使用房间模式选项，不新增企业家扩展包ID。卡面、素材和准备事项已独立写在[企业家目录](企业家/实装准备与待确认事项.md)；接下来按规格完善定义和执行合同，未完成它不应阻止模式关闭的感染者基础玩法。所有新状态都要有快照、克隆、公开/私密投影和恢复记录；不完整Effect跳过并日志记录，不等于自动宣称同包内所有模式已实现。

逐卡规则见[企业扩Effect式](企业扩/卡面效果与Effect式.md)、[感染者扩Effect式](感染者扩/卡面效果与Effect式.md)、[企业家Effect式](企业家/卡面效果与Effect式.md)；具体代码改成什么见[实装改动清单](可选扩展包实装改动清单.md)。
