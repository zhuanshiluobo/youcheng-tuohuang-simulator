# 模块拆分与多 Agent 开发顺序

本文件已去重。完整模块、依赖链、波次和当前进度统一维护在：

- `游城拓荒/项目总览.md`

## 当前推荐开发顺序

1. 真实地图数据录入。
2. 入场流程补齐。
3. 合法命令枚举。
4. 首个主要行动。
5. Debug 对局入口。
6. 采集、收尾、最终计分。
7. 卡牌与效果系统。
8. 正式 UI。

## 当前可并行模块

### 地图 Agent

写入范围：

- `Assets/YC/Domain/Maps`
- `Assets/YC/Data/Maps`
- 地图相关测试。

任务：

- 真实四人图数据。
- 三人图数据。
- 区控服务。
- 地图热点坐标。

### 命令/玩法 Agent

写入范围：

- `Assets/YC/Application`
- `Assets/YC/Domain/Rules`
- 命令相关测试。

任务：

- 入场后续命令。
- 部署、探索、城市移动、建设。
- 采集、收尾、计分。

### UI/工具 Agent

写入范围：

- `Assets/YC/Presentation`
- `Assets/Scenes`
- UI 相关资源。

任务：

- Debug 对局入口。
- 地图交互热点。
- 玩家面板、行动面板、日志面板。

## 协作约束

- 所有规则状态只能通过命令结算修改。
- Presentation 不直接写 `GameState`。
- 所有新增规则至少配 1 个成功测试和 1 个失败测试。
- 每个 agent 必须有明确写入范围。
- 不回滚他人改动。
- 不批量删除文件或目录。
