# 收藏室聚光灯区

## 资产结构与所有权

聚光灯区.prefab 是收藏室固定设施的父预制体，下面嵌套四个中文子预制体：聚光灯、体积雾、地板、遮罩。体积雾内部包含光束雾和贴地雾。
这些对象不属于藏品，切换展示模型时不要销毁、重建或重新配置它们。SpotlightArea 不持有藏品引用，也不会写入藏品、相机或 UI 参数。

## 调节入口

在收藏室场景层级选择「收藏室 → 聚光灯区 → 聚光灯」：

| 想改变的效果 | 修改位置 |
| --- | --- |
| 灯的位置 | Transform → Position（位置）；X 左右，Y 高度，Z 前后 |
| 灯的朝向 | Transform → Rotation（旋转） |
| 光束及地面光斑宽度 | Light → Spot Angle（聚光角）；越大越宽 |
| 明亮中心范围及边缘渐变 | Light → Inner Spot Angle（内角）；接近外角时边缘更硬 |
| 灯能照到多远 | Light → Range（范围）；不是单独的地面光圈半径 |
| 灯光颜色、亮度 | Light → Color、Intensity |
| 阴影深浅 | Light → Shadows → Strength |
| 地板自身受光亮度 | 地板材质 → 地面受光强度 |
| 地板底色 | 地板材质 → 哑光地板 |
| 阴影边缘柔化 | 地板材质 → 投影边缘柔化 |
| 光束雾与低雾浓度 | 对应材质 → 雾密度 |
| 贴地雾覆盖区域 | 体积雾 → 贴地雾 → Transform |

不要用「光束雾」的 Transform Scale 调光束宽度：它只是自动匹配灯光范围的采样盒，每次刷新都会联动。宽度的唯一入口是聚光灯的 Spot Angle。
地板光斑与体积雾共用灯的位置、方向、内外角及距离截止。光斑是光锥与地板相交的受光区域，斜视时呈椭圆，不是另外画上去的固定圆环。
地板范围目前约 46.4 × 46.4；扩大到超出这个实际地板范围时，应调地板本身尺寸。超出相机画面则只是离开视野，不能靠拉伸预览 UI 来容纳。

## 当前保存值与场景覆盖

子预制体「聚光灯」的源资产：位置 (0, 3.7, 0)，旋转 (90, 0, 0)，强度 10，外角 40，内角 4，范围 15。
验收时实际收藏室场景存在外角 38、范围 10 的覆盖值，予以保留，其余以当前检查器为准。没有把源预制体的旧值覆盖回场景。
地板位置 (0, -0.67, 0)，旋转 X 337.22，缩放 (0.232, 1, 0.232)；材质受光强度 0.48。
光束雾密度 0.22，贴地雾密度 0.12。灯和地板的现有配置没有为修复受光而提高数值，修正位于地板着色器内部。

在场景中调节并保存，结果是场景覆盖。希望所有实例复用时，再有意识地应用到对应预制体，或进入预制体模式修改后保存。验收应看实际收藏室场景，不能只看源资产。

## 遮罩与换藏品过渡

遮罩对象的 PreviewFadeMask → Opacity：0 完全透明，1 完全遮黑。
遮罩位于现有预览专用层，只覆盖渲染该层的相机，当前主界面相机不渲染此层，所以不盖住 UI。Scene 视图若显示该层，也会显示遮罩。

父对象 SpotlightArea 中：
- Fade Out Seconds：渐暗时间，当前 0.45 秒。
- Dark Hold Seconds：全黑停留时间，当前 0.15 秒。
- Fade In Seconds：重新亮起时间，当前 0.65 秒。
- Preview Next Color：手动预览过渡时使用的新灯色。
- On Fully Dark：全黑时触发的可配置事件。

播放模式下，通过 SpotlightArea 组件菜单「预览渐暗并换色亮起（运行模式）」预览完整过渡。
以后接入收藏品管理器时调用：

```csharp
spotlightArea.SwitchExhibit(nextColor, () =>
{
    // 这里已完全遮黑。由收藏品管理器替换模型，不替换聚光灯区。
    ReplaceDisplayedCollectible();
});
```

这是接入口示意；尚未替你增加藏品切换菜单或改写藏品管理器。也可以用 On Fully Dark 事件接切换逻辑，避免同时在回调和事件中重复切换。
过渡使用不受 timeScale 影响的时间；渐暗时同步降低灯强度并提高遮罩不透明度，全黑后切模型、改灯色，再渐亮并恢复原强度。过渡进行中会忽略重复请求，不排队。
光的位置、角度、范围、地板参数和雾参数不会从藏品读取。改变的持久照明参数只有灯色，强度在过渡结束时恢复。

## 已核验

- 地板能够显示椭圆受光区域和真实模型软阴影。
- 运行时扩大外角至 60°、灯位向右移 0.6，地板和雾联动。
- 全黑回调中遮罩为 1、灯强度为 0，预览像素最大 RGB 为 0。
- 换色后遮罩为 0、灯强度恢复 10；UI 不被遮罩覆盖。
- 本轮施工完成、运行验证前，范围外 105 项组件快照与施工前一致；预览交互区保持 1228 × 872。此后编辑器中的其他界面编辑不由本功能覆盖或回退。
- 临时测试退出播放后恢复；旧光照控制脚本和停用的旧补光灯已清理。
